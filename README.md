# Таблиці води та пари / IAPWS-IF97

Автономний статичний калькулятор з українським UI. Відкрийте **index.html** у сучасному браузері — сервер, інтернет і встановлення пакетів не потрібні. У файлі вже є всі стилі, JavaScript та WebAssembly. Той самий файл у `dist/index.html` готовий до GitHub Pages.

## Можливості

- P–T, P–h, P–s, P–x, T–x, h–s; насичення за P або T з обома фазами.
- Ентальпія h, ентропія s, густина ρ, питомий об’єм v, внутрішня енергія u, Cp, Cv, швидкість звуку.
- Динамічна в’язкість: IAPWS R12-08, **промисловий варіант μ₂ = 1**, як рекомендовано для IF97.
- Теплопровідність: IAPWS R15-11 §3, **включно з критичним доданком λ₂** і офіційною промисловою кореляцією стисливості при TR.
- 32 показники: додатково енергії Гельмгольца/Гіббса, Z, ізентропний показник, аналітичні похідні, коефіцієнти Джоуля–Томсона, кінематична в’язкість, температуропровідність і число Прандтля.
- Поверхневий натяг рівноважної межі рідина–пара: IAPWS R1-76(2014), 273,16–647,096 K, без екстраполяції.
- Сухість x: частка 0–1 або 0–100%.
- Тиск МПа/кПа/Па/бар/атм, температура °C/K, енергія кДж або Дж; одиниці входу перемикаються з перерахунком значення. Тиск **абсолютний**, не манометричний.
- Десяткова кома або крапка, контроль діапазону, CSV з неокругленими результатами, контрольні приклади, адаптивний інтерфейс.

## Поточний інтерфейс

Табличний інтерфейс із блакитно-сірою темою: вкладки, введення над таблицею, налаштування праворуч і історія станів унизу. Є очищення історії, CSV поточного стану та всього журналу, друк, перемикання теми та довідка. Групи властивостей і бічні панелі згортаються. Висоту журналу можна змінювати перетягуванням роздільника або клавішами ↑/↓. Колонка констант і заголовок таблиці залишаються доступними під час прокручування. Повний екран працює в браузерах із підтримкою Fullscreen API. Історія автоматично зберігається в localStorage поточного браузера (до 500 станів); енергетичні колонки історії завжди у кДж.

Це незалежна реалізація, не продукт MegaWatSoft. Код, торгові позначення та графічні ресурси Steam Tables Online не включені. IAPWS-95 ще не реалізовано; відповідний перемикач вимкнений. Процеси й діаграми мають власний інтерфейс; повна тотожність усім функціям аналога не заявляється. Підтримуються вісім режимів із переліку вище, не всі 16 режимів аналога.

## Модель і межі

Основні рівняння IAPWS R7-97(2012), а не апроксимації через теплоємність або ідеальний газ:

| Область | Реалізація |
|---|---|
| 1 | Gibbs, Eq. 7, аналітичні перші й другі похідні |
| 2 | Gibbs, Eqs. 15–17, аналітичні похідні |
| 3 | Helmholtz, Eq. 28; Newton з контролем стабільної гілки за заданими P–T |
| 4 | Насичення, Eqs. 30–31; рівноважні властивості фаз і масовий ступінь сухості |
| 5 | Gibbs, Eqs. 32–34 (редакція з верхньою межею 50 МПа) |

- 273,15 ≤ T ≤ 1073,15 K: 0 < P ≤ 100 МПа.
- 1073,15 < T ≤ 2273,15 K: 0 < P ≤ 50 МПа.
- Насичення: 273,15 ≤ T ≤ 647,096 K, P від 0,000611212677444… до 22,064 МПа. Нижня межа — тиск насичення IF97 при 273,15 K, **не** тиск потрійної точки 611,657 Па.
- Межа 2/3 — офіційне рівняння B23, 1/3 — 623,15 K, 2/5 — 1073,15 K.
- Транспортні значення показуються лише до 1173,15 K в допустимих діапазонах тиску IF97; за вищої T стоїть «—» з поясненням. Екстраполяції не подаються як стандартні значення.
- Лід і окрема формуляція метастабільної пари не реалізовані. Поблизу 273,15–273,16 K показується пояснення можливого метастабільного стану відносно льоду.

### Інверсії й неоднозначність

P–h / P–s / P–x / T–x: спочатку перевіряється двофазний інтервал. У суміші h, s, u, v визначаються масовим балансом фаз; **ρ = 1/v**, а не середнім густин. Cp/Cv, w, μ, λ суміші не усереднюються: «—». Властивості окремих фаз наведено в таблиці. На кінцях x = 0 і 1 наведено однофазні властивості насиченої рідини/пари.

В однофазній області інверсія виконується бісекцією основних рівнянь, окремо в кожному регіоні. Критерій нев’язки: 2×10⁻⁸ кДж/кг для h або 2×10⁻¹¹ кДж/(кг·K) для s. Це числова збіжність, а не фізична невизначеність IF97. Значення з офіційних backward-таблиць T(p,h)/T(p,s) можуть трохи відрізнятися: тут розв’язуються основні рівняння, а не відтворюється backward-поліном.

h–s: чисельне розв’язання основних рівнянь через P–h, зі стартовим тиском SEUIF97, демпфованим Newton і резервним пошуком у логарифмі тиску. Перевіряються нев’язки h < 10⁻⁶ кДж/кг та s < 2×10⁻¹¹ кДж/(кг·K). Резервний пошук охоплює 10⁻¹²–100 МПа; надзвичайно низькі тиски, розриви меж або незбіжність можуть дати явну помилку. Це інверсія основних рівнянь, а не відтворення офіційного backward-полінома p(h,s). У критичній точці P–x/T–x відхиляються, бо x не визначений.

Похідні й транспортні показники двофазної суміші не усереднюються; поверхневий натяг описує межу між рівноважними фазами. CSV поточного стану включає всі 32 показники; CSV історії зберігає компактний набір 13 числових колонок.

Рівняння різних областей IF97 мають малі дозволені неузгодженості. Якщо виникає перекриття й кілька коренів інверсії, UI пояснює це, показує корінь з нижчою T і температури інших коренів. Якщо значення потрапляє в розрив, видається помилка; штучної інтерполяції немає.

На лінії насичення P–T не визначає x: показуються обидві фази, властивості суміші не вигадуються. У критичній точці ρ = 322 кг/м³, x невизначений, Cp і λ не подаються як скінченні числа. Надзвичайно близько до критичної точки похідні IF97 чутливі; у разі незбіжності видається явне повідомлення.

```sh

```

`build` створює/оновлює автономні `index.html` і `dist/index.html`. Обидва відстежуються в Git, щоб можна було використати готовий файл без збірки. Редагуйте файли `src/`, а не згенерований HTML.

## Підготовка GitHub та GitHub Pages

Код розміщено у приватному репозиторії `lamerroma/water-steam-if97`. Сайт GitHub Pages не опубліковано. Його запуск потребує окремого погодження; для приватного репозиторію доступність Pages залежить від тарифу GitHub.

1. У репозиторії вже є вихідний код, тести, `.github`, `vendor`, LICENSE та атрибуція. Абсолютних URL для assets немає.
2. У Settings → Pages → Build and deployment виберіть **GitHub Actions**.
3. Після окремого рішення про публікацію запустіть Actions → **Publish GitHub Pages (manual)** → Run workflow з потрібної гілки.
4. Workflow перевірить тести, збере автономний HTML і опублікує `dist/`. URL буде в результаті deploy job.

Pages workflow запускається **лише вручну** (`workflow_dispatch`), не на push. CI перевіряє тести й відтворюваність збірки на push/PR без публікації. GitHub Actions потребує мережі лише під час CI/публікації; готовий калькулятор її не потребує.

Можна також розмістити `index.html` на будь-якому статичному хостингу або надіслати єдиний файл. Для GitHub Pages project site підтримується шлях `/repository-name/`, бо немає кореневих посилань на assets.

## Турбіна, випаровування та діаграми

- Турбіна: однофазний паровий вхід P–T, вихідний тиск, ізоентропний ККД у %, витрата у кг/с. h₂s = h(p₂,s₁); h₂ = h₁ − η(h₁−h₂s); робота = h₁−h₂, потужність у кВт = витрата × робота. Модель адіабатична, без механічних/генераторних втрат та змін кінетичної/потенціальної енергії.
- Випаровування: адіабатичне дроселювання h₂=h₁. Для рівноважної суміші витрати пари й рідини = mx та m(1−x). Для однофазного виходу баланс сепарації не показується. Вхід P–T на насиченні відхиляється як неоднозначний. Нагрівання з підведенням тепла й багатоступенева сепарація не моделюються.
- Вихід процесу можна перенести до загальних властивостей, журналу та CSV. У формах процесів перемикаються МПа/бар/кПа, °C/K, кг/с або кг/год; таблиці результатів і CSV перемикаються між SI та англійськими одиницями; перемикач енергії загального калькулятора на них не діє.
- T–s та h–s: насичення, сім ізобар 0,01–100 МПа, точки журналу з підказками та завантаження автономного SVG. Точки обчислюються за IF97; лінійні сегменти служать лише для малювання. Графіки мають початкові канонічні діапазони: s 0–11 кДж/(кг·K), t 0–800 °C або h 0–4500 кДж/кг. Вони не охоплюють всю область 5; доступні масштабування кнопками/колесом, переміщення перетягуванням/стрілками та вибір позначених точок мишею або Enter.

Розрахований процес наноситься кнопкою «Нанести процес на h–s діаграму» й доступний також на T–s. Зелений відрізок з’єднує вхід і фактичний вихід; пунктир — вхід та ізоентропний вихід турбіни. Це з’єднання кінцевих станів, не модель проміжного шляху реальної турбіни. На графіку зберігається останній успішний процес до кнопки «Прибрати процес» або заміни проєкту; останній процес відновлюється з JSON/localStorage. Вибрану точку можна перенести до загальних властивостей. SVG зберігає поточний масштаб.

## Збереження проєкту

Автоматично зберігаються журнал (до 500 станів), введення загального калькулятора, чернетки форм процесів, останній успішний процес, тема, енергетичні одиниці та масштаб UI. Збереження локальне для браузера й адреси сторінки; при очищенні даних браузера воно зникає. Приватний режим або file:// можуть обмежувати localStorage: для перенесення використовуйте Файл → Експорт/Імпорт проєкту JSON. Імпорт замінює поточний проєкт, максимальний розмір 2 МБ; стани й процеси перераховуються з входів за IF97. Масштаб діаграми й геометрія панелей не зберігаються. CSV процесу доступний після успішного розрахунку.

Турбіна має три режими: потужність за ККД і витратою; витрата за потужністю та ККД; ККД за потужністю й витратою. Потужність задається у кВт або Btu IT/h. Нульові входи зворотних режимів та ККД поза (0,1] відхиляються. Випарник: режим насиченого конденсату використовує x₁=0 за вхідним тиском; температура поля в цьому режимі не використовується. Нові режими зберігаються у чернетках, результат — у канонічних входах проєкту. Старі JSON-проєкти сумісні.

## Фізична ексергія потоку

ex = (h − h₀) − T₀(s − s₀), кДж/кг. Опорний стан води h₀/s₀ визначається IF97 за явно заданими абсолютним P₀ та T₀; початково 0,101325 МПа / 25 °C. Це фізична ексергія потоку, без хімічної, кінетичної та потенціальної складових. Налаштування в правій панелі застосовуються кнопкою «Оновити довкілля»; неоднозначний опорний стан на насиченні відхиляється. Показник наведено у загальних властивостях і таблиці фаз; CSV записує ex, P₀, T₀ та визначення. Проєкт зберігає застосоване довкілля; старі файли отримують початковий опорний стан. Таблиці процесів і компактна історія не мають окремої колонки ex — вихід можна відкрити у загальних властивостях.

## Діелектрична проникність

Статична відносна діелектрична проникність εr (безрозмірна), IAPWS R8-97, рівняння (3)–(5), (7). Густина отримана з IF97; офіційна R8-97 рекомендує IAPWS-95 для перетворення P–T у густину. Ця відмінність показана у примітках; не заявляємо тотожності P–T результатам IAPWS-95. У UI використовується перетин меж IF97 та R8-97: T ≤ 873 K та P ≤ 100 МПа, без екстраполяції. У двофазній суміші εr невизначена, значення фаз показуються окремо. CSV містить dc. Тести використовують усі 10 точок таблиці 4 з її заданою молярною густиною, перетвореною в кг/м³; не густину IF97 за табличним тиском.

### Англійські одиниці

Вхідні дані: psi (абсолютний тиск), °F, Btu IT/lb та Btu IT/(lb·°R). У процесах також lb/s, lb/h і Btu/h. Панель налаштувань перемикає результати, таблиці насичення, історію й CSV між SI та англійськими одиницями; проєкт JSON зберігає вибір. Обчислення завжди виконуються в канонічних SI. Btu означає International Table Btu, не thermochemical Btu. Перетворення спираються на [NIST SP811](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b9): lb = 0.45359237 kg, ft = 0.3048 m, Btu IT = 1055.05585262 J.

Діаграми перемикають підписи осей, ізобар, точок і SVG між SI (кДж або Дж) та англійськими одиницями, зберігаючи геометрію і масштаб. Поля довкілля та константи IF97 залишаються в явно позначених SI. Метадані довкілля у CSV також MPa/K. CSV історії використовує вибрані одиниці результатів (температура SI — °C), CSV поточного стану і процесу — K для SI, °F для англійських. Перемикач кДж/Дж стосується основних властивостей та історії SI; процеси SI використовують кДж/кг і кВт.

## Пакетні розрахунки

Вкладка 7 розраховує рівномірну серію 2…500 точок за першим або другим параметром для всіх режимів. Початок і кінець включені, можливий спадний діапазон. Для насичення змінюється лише перший параметр. CSV (до 1 МБ, 500 рядків) має заголовок `mode,a,b,unit_a,unit_b,name`; name необов’язковий. Роздільник кома або крапка з комою, лапки підтримуються, десяткова кома дозволена у полях CSV з роздільником `;` або у лапках. Числа без розділювачів тисяч.

Коди режимів: pt, ph, ps, satp, satt, px, tx, hs. Коди одиниць показані у формі; приклад:

```csv
mode,a,b,unit_a,unit_b,name
pt,3,300,MPa,K,Рідина
px,0.1,0.5,MPa,fraction,Суміш
satp,1,,MPa,,Насичення
```

Помилки окремих станів не приховуються; структурно пошкоджений CSV відхиляється повністю. Результати можна зберегти в CSV або додати до журналу; насичення без x додає дві фази. CSV результатів використовує K у SI і °F в англійських одиницях. Серія й текст CSV тимчасові: для збереження додайте успішні стани до журналу й експортуйте JSON.

## Журнал та резервні копії

Назви станів (до 80 символів) редагуються прямо в журналі й зберігаються під час введення. Кнопка ↗ відкриває властивості без додавання дубліката, × видаляє рядок; «Скасувати видалення» відновлює останню операцію, включно з очищенням. Скасування діє до перезавантаження або імпорту. Файл → Назва проєкту зберігається у JSON. Старі проєкти версії 1 залишаються сумісними.

Зміни автоматично зберігаються локально. Якщо localStorage відмовляє, меню Файл показує незбережені зміни, браузер отримує попередження перед закриттям (показ діалогу залежить від браузера). Збережіть JSON як резервну копію; імпорт замінює поточний проєкт.

## Насос, компресор і теплообмінник

Вкладка 8: насос для рідкого входу, компресор для парового входу, p₂>p₁, 0<η≤1. Ідеальний вихід визначається P–s, робота стиснення (h₂s−h₁)/η, потужність m·work, фактичний вихід — P–h. Це модель IF97 без наближення v·Δp.

Теплообмінник: задаються два входи P–T, вихідні тиски, дві додатні витрати та теплова потужність Q≥0. h_hot,out=h_hot,in−Q/m_hot; h_cold,out=h_cold,in+Q/m_cold. Втрати у довкілля відсутні, змінами кінетичної/потенціальної енергії знехтувано. Перевіряються кінцеві температури протитечії; ця необхідна перевірка не доводить відсутність внутрішнього pinch. UA, площа, профіль уздовж апарата і коефіцієнти теплопередачі не розраховуються. Тиски на виходах не вищі за входи.

Процеси підтримують вибір одиниць, CSV, додавання кінцевих станів у журнал, діаграми та JSON. У теплообмінника на діаграмі гарячий потік зелений, холодний синій; це відрізки між кінцевими станами.

## Друк і перевірка релізу

Файл → «Звіт для друку HTML» зберігає автономну таблицю журналу в обраних одиницях, із layout A4 landscape. Відкрийте її й надрукуйте засобами браузера. Звичайний «Друк» також має print CSS. Перевірено HTML-звіт у браузері; системний діалог/фізичний принтер не автоматизовано.

CSP готового калькулятора містить `connect-src 'none'`; WASM вбудовано. Запуск і розрахунок перевірено через локальний статичний HTTP під цією політикою. Інструмент браузера блокує file://: запуск подвійним кліком і старі браузери залишаються ручними перевірками. Немає backend чи runtime мережевих залежностей.
