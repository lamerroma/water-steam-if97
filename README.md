# Теплофізичний калькулятор

**Онлайн-калькулятор властивостей води й пари за IAPWS-IF97 та IAPWS-95 та
інженерних розрахунків. Українська й англійська, працює без інтернету.**

[Відкрити калькулятор](https://lamerroma.github.io/water-steam-if97/) ·
[Швидкий старт](docs/QUICK_START_UK.md) · [Установлення й офлайн](docs/PWA_UK.md) ·
[Документація](docs/README.md) · [Журнал змін](CHANGELOG.md)

Багатофайлова PWA: сервер лише віддає статичні файли, усі розрахунки виконує
браузер. Після підготовки кешу програма працює офлайн. Автономний HTML
залишається форматом експорту звітів.

## Можливості та межі

| Розділ | Моделі й документація |
| --- | --- |
| Вода й пара | Власні JS-ядра IAPWS-IF97 та IAPWS-95, а також CoolProp HEOS; інверсії, транспортні властивості, pKw, показник заломлення, похідні (∂ρ/∂h)p, (∂ρ/∂p)h, dpₛ/dT |
| Насичення | 15 способів задати стан: P, T, P–x, T–x, а також h, s, u, v, ρ рідини чи пари й теплота пароутворення; таблиці насичення |
| Метастабільна пара | Додаткове рівняння IF97 при P ≤ 10 МПа між лінією насиченої пари та лінією 5 % рівноважної вологості |
| Екстраполяція IAPWS-95 | P–T до 5000 K і 100 ГПа з попередженням поза перевіреною областю (T ≤ 1273 K, P ≤ 1000 МПа) |
| Функції | Формули на кшталт `h(p=10 бар; t=250 °C)`, діапазони, змінні, CSV; [опис](docs/WATER_FUNCTIONS_UK.md) |
| Газові таблиці | NASA7 та восьмикомпонентна BSW2003; [P03](docs/STEAMTABLES_P03_UK.md) |
| Дисоціація | Дослідна калорична поправка VDI4670; [обмеження P04](docs/STEAMTABLES_P04_UK.md) |
| Інші речовини | Лід Ih, важка й морська вода; реальні чисті речовини та вологе повітря CoolProp |
| Процеси й звіти | Турбіна, flash, насос, компресор, теплообмінник, цикли, діаграми T–s, h–s, P–h, дослідження параметрів, порівняння станів і звіти |
| Трубопровід | Витрати, Reynolds, втрати тиску однофазної рідини; [порівняння з fluids](docs/FLUIDS_PIPE_UK.md) |
| Паросистеми | 12 розрахунків: діаметр і втрати тиску паропроводу, лінія конденсату, клапан Kv/Cv (IEC 60534-2-1), діафрагма (ISO 5167-2), витікання, конденсатне навантаження, сепаратор, повітря в парі, вартість пари, ККД котла, окупність; [опис](docs/STEAM_SYSTEMS_UK.md) |
| ht / fluids | Каталог, виклики функцій і робота з об'єктами; [інструкція](docs/PYTHON_LIBRARIES_UK.md) |

Тиск у математичних ядрах абсолютний; кожна форма й експорт позначають свої
одиниці. У невизначених станах і поза областю моделі програма показує пояснення
замість вигаданих чисел. Імпортовані проєкти повторно обчислюються з входів.

Орієнтири функціонального покриття: Steam97Web (властивості води й пари),
калькулятори паросистем TLV та бібліотеки функцій для таблиць на кшталт
WaterSteamPro. [Стратегія](docs/PRODUCT_STRATEGY_UK.md) ·
[Матриця відповідності Steam97Web](docs/STEAMTABLES_PARITY_MATRIX.json) ·
[План розвитку](docs/DEVELOPMENT_MASTER_PLAN_UK.md).
Пряма числова відповідність P03/P04 оригіналу ще не підтверджена: під час збору
Steam97Web вимагав реєстрації. Імпорт ht / fluids також не означає перевірки
всіх їхніх функцій або наявності спеціальних форм для всього API.
[План покриття бібліотек](docs/HT_FLUIDS_INTEGRATION_UK.md).

Розділ «Навчання» (навчальні приклади, лабораторні, контрольні й курсові з
реакторною моделлю, схема АЕС) прибрано: застосунок зосереджено на розрахунках.
Старі проєкти відкриваються без цих вкладок; блоки звітів із них пропускаються.

  [модель HEOS в основній формі, історії, серіях та проєктах](docs/WATER_HEOS_WORKSPACE_UK.md).
  IF97 та власний IAPWS-95 залишаються окремими моделями.
  [Історичне виправлення 1.40.1](docs/PWA_LEGACY_CHECK_UK.md).

  і fluids 1.3.1 виконуються в окремому Python Worker; SheetJS запускається
  при першому експорті XLSX/ODS/XLS.

## Запуск та офлайн

1. Відкрийте сайт із мережею й дочекайтеся готовності офлайн.
2. За бажанням установіть PWA через меню браузера. Надалі відкривайте ту саму
   адресу або іконку без інтернету.
3. Для ht / fluids окремо підготуйте пакет приблизно 32 МБ у розділі
   «Теплообмін і гідравліка → Бібліотеки ht / fluids».

Основний статус PWA та готовність Python-пакета показуються окремо.
Для оновлення натисніть «Перевірити оновлення» в панелі встановлення й офлайн.
Зберігайте резервні JSON-копії проєктів: браузер може очистити локальне сховище.

Для першого запуску без інтернету є повний ZIP: розпакуйте, виконайте
`python serve.py` (Windows: `py -3 serve.py`), відкрийте http://localhost:8080/.
Файли ht / fluids входять до ZIP; підготуйте їх у панелі до зупинки сервера.
Запуск застосунку через `file://` не підтримується. [Подробиці](docs/PWA_UK.md).

## Розробка й перевірка

Для приймання CI використовує Node.js 22 і Python 3.12.
Збірка та модульні тести не потребують npm-залежностей:

```sh
npm run build
npm test
npm run check:docs
npm run serve
```

Редагуйте `src/`. Build створює поточні ресурси в корені й `dist/`; обидві копії
відстежуються Git і потрібні чинній структурі проєкту. `vendor/` містить вихідні
сторонні залежності та ліцензії. Тимчасові журнали й профілі зберігайте в
ігнорованому `.release/`.

Повне приймання: `npm run verify:release`; повний офлайн-архів після build:
`npm run package`. Браузерні перевірки потребують Playwright, Chromium,
Firefox та незалежних Python-читачів таблиць.
[Підготовка середовища й структура](docs/DEVELOPMENT_UK.md) ·
[Архітектура PWA](docs/PWA_ARCHITECTURE_UK.md) ·
[Протокол модулів](docs/CALCULATION_MODULES_UK.md).
