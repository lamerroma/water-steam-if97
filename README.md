**Версія 1.40.1 — багатофайлова PWA з локальними розрахунками та роботою без інтернету.**

Підтверджена публікація — [1.40.1](docs/RELEASE_STATUS_UK.md), CI 110/110;
старі функції перевірено онлайн та офлайн в Chromium і Firefox.
[Перевірка старих функцій і виправлення проєктів/діаграм](docs/PWA_LEGACY_CHECK_UK.md).

[План розвитку до кінцевої мети](docs/DEVELOPMENT_MASTER_PLAN_UK.md) —
етапи, залежності, оцінки та критерії завершення.

Український та англійський інтерфейси для навчальних розрахунків термодинаміки
й теплофізики. Сервер лише віддає статичні файли; розрахунки виконує браузер.
Після підготовки кешу програма працює офлайн. Єдиний формат застосунку —
багатофайлова PWA; автономний HTML залишається форматом експорту звітів.

У 1.39.0 форма трубопроводу порівнює власний розрахунок із fluids 1.3.1:
Clamond/Colebrook, втрати тиску, потужність, CSV/JSON та повторний запуск офлайн.
Бібліотеки ht 1.2.0 і fluids 1.3.1 виконуються через окремий Python Worker.
SheetJS запускається при першому експортуванні XLSX/ODS/XLS.
[Підтверджений стан публікації та перевірок](docs/RELEASE_STATUS_UK.md).

У робочій гілці додано [20 пар води через CoolProp HEOS і числову перевірку циклів](docs/WATER_HEOS_M2_UK.md),
[явну модель HEOS в основній формі, історії, серіях та проєктах](docs/WATER_HEOS_WORKSPACE_UK.md)
і [план інтеграції відкритих модулів](docs/OPEN_LIBRARY_MODULES_PLAN_UK.md).
Ці зміни ще не опубліковано. IF97 та власний IAPWS-95 залишаються окремими моделями.

## Можливості та межі

| Розділ | Моделі й документація |
| --- | --- |
| Вода й пара | Власні JS-ядра IAPWS-IF97 та IAPWS-95, насичення, інверсії, транспортні властивості |
| Газові таблиці | NASA7 та восьмикомпонентна BSW2003; [P03](docs/STEAMTABLES_P03_UK.md) |
| Дисоціація | Дослідна калорична поправка VDI4670; [обмеження P04](docs/STEAMTABLES_P04_UK.md) |
| Інші речовини | Лід Ih, важка й морська вода; реальні чисті речовини та вологе повітря CoolProp |
| Процеси й навчання | Турбіна, flash, насос, компресор, теплообмінник, цикли, діаграми, дослідження та звіти |
| Трубопровід | Витрати, Reynolds, однофазна нестислива рідина; [порівняння з fluids](docs/FLUIDS_PIPE_UK.md) |
| ht / fluids | Каталог, виклики функцій і робота з об'єктами; [інструкція](docs/PYTHON_LIBRARIES_UK.md) |

Тиск у математичних ядрах абсолютний; кожна форма й експорт позначають свої
одиниці. У невизначених станах і поза областю моделі програма показує пояснення
замість вигаданих чисел. Імпортовані проєкти повторно обчислюються з входів.

Пріоритет розвитку — повне функціональне покриття Steam97Web, потім власні
розширення. [Стратегія](docs/PRODUCT_STRATEGY_UK.md) ·
[Матриця відповідності](docs/STEAMTABLES_PARITY_MATRIX.json).
Пряма числова відповідність P03/P04 оригіналу ще не підтверджена: під час збору
Steam97Web вимагав реєстрації. Імпорт ht / fluids також не означає перевірки
всіх їхніх функцій або наявності спеціальних форм для всього API.
[План покриття бібліотек](docs/HT_FLUIDS_INTEGRATION_UK.md).

Дослідна нейтронна модель не пройшла незалежну фізичну перевірку комірки.
[Протокол](docs/REACTOR_CELL_VALIDATION_UK.md). Програмні тести не змінюють
цього висновку.

## Запуск та офлайн

1. Відкрийте сайт із мережею й дочекайтеся готовності офлайн.
2. За бажанням установіть PWA через меню браузера. Надалі відкривайте ту саму
   адресу або іконку без інтернету.
3. Для ht / fluids окремо підготуйте пакет приблизно 32 МБ у розділі
   «Теплообмін і гідравліка → Бібліотеки ht / fluids».

Основний статус PWA та готовність Python-пакета показуються окремо.
Для оновлення натисніть «Перевірити оновлення» в панелі встановлення й офлайн.
Зберігайте резервні JSON-копії проєктів: браузер може очистити локальне сховище.

Для першого запуску без інтернету є повний ZIP: розпакуйте, виконайте
`python serve.py` (Windows: `py -3 serve.py`), відкрийте http://localhost:8080/.
Файли ht / fluids входять до ZIP; підготуйте їх у панелі до зупинки сервера.
Запуск застосунку через `file://` не підтримується. [Подробиці](docs/PWA_UK.md).

## Розробка й перевірка

Для приймання CI використовує Node.js 22 і Python 3.12.
Збірка та модульні тести не потребують npm-залежностей:

```sh
npm run build
npm test
npm run check:docs
npm run serve
```

Редагуйте `src/`. Build створює поточні ресурси в корені й `dist/`; обидві копії
відстежуються Git і потрібні чинній структурі проєкту. `vendor/` містить вихідні
сторонні залежності та ліцензії. Тимчасові журнали й профілі зберігайте в
ігнорованому `.release/`.

Повне приймання: `npm run verify:release`; повний офлайн-архів після build:
`npm run package`. Браузерні перевірки потребують Playwright, Chromium,
Firefox та незалежних Python-читачів таблиць.
[Підготовка середовища й структура](docs/DEVELOPMENT_UK.md) ·
[Архітектура PWA](docs/PWA_ARCHITECTURE_UK.md) ·
[Протокол модулів](docs/CALCULATION_MODULES_UK.md).
