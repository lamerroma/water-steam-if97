# Спринт 1.1.0 — перевірка 2026-10-10

## Числове ядро

235 тестів пройшли локально (Node 24.19.0). Збережено попередні офіційні тести IF97, IAPWS-95, промислового транспорту, похідних, меж, інверсій і процесів. Нові перевірки:

- R12-08 Table 5: усі 6 наукових μ з критичним доданком (T=647,35 K, ρ=122…422 кг/м³).
- R15-11 Table 5: усі 8 наукових λ з критичним доданком (ρ=1…750 кг/м³).
- R7-97 Tables 7/9/24/29: 24 backward T(p,h)/T(p,s) значення областей 1/2.
- SR3-03(2014) Tables 5/12: 12 backward значень області 3.
- CoolProp 8.0.0: 29 незалежних P–T точок двох водяних моделей.
- Cantera 3.2.0: по 3 точки на кожен із 11 газів та по 3 точки двох сумішей.
- Баланс суміші, перерахунок базису, ентропія змішування, PH/PS, відхилення екстраполяції.
- Ренкін IF97/95 та Брайтон: чотири стани, енергетичний баланс, ізоентропні ідеальні межі, невалідні входи.
- Вологе повітря: сухий/насичений край, порядок температур роси/мокрого термометра/сухого термометра, межі.

### Як трактувати CoolProp біля критичної точки

Для IAPWS-95 найбільші відносні відхилення в 14 контрольних P–T точках: Cp ≈2,8×10⁻⁹, μ ≈3,7×10⁻¹¹, λ ≈8,1×10⁻¹⁰. Це звірка обчислень, не фізична похибка формуляції.

IF97 при 22 МПа і 647 K: густина відрізняється приблизно на 0,085 %, Cp — на 0,84 %. CoolProp застосовує backward v(p,T), наше ядро уточнює густину до фундаментального рівняння тиску. Підстановка густини CoolProp у наше фундаментальне рівняння відтворює його h, s, Cp, Cv, w; тому ці алгоритми порівнюються окремо. Тест перевіряє фундаментальні властивості при однаковій густині, залишок тиску backward-стану та відхилення густини; загальна точність решти тестів не послаблена. Незалежний офіційний контроль основного рівняння області 3 зберігається.

| Режим | До, мс/стан | Після, мс/стан | Відношення |
|---|---:|---:|---:|
| P–h | 0,629 | 0,206 | 3,05 |

Це мікробенчмарк конкретного комп’ютера й набору, не гарантія швидкості будь-якої діаграми. Сирий WASM теж виміряний, але повертає одну величину, тоді як JS уточнює корінь, перевіряє фазу й обчислює всі властивості/транспорт. Числова політика JS збережена; WASM не підміняє кінцевий фундаментальний стан.

## Браузерна перевірка

Локальний HTTP, вбудований WASM, CSP connect-src none. Перевірені натискання кнопок:

- водяний P–T IAPWS-95, наукові μ/λ;
- газ P–T, P–h, P–s; молярний → масовий склад зі збереженням результату;
- вологе повітря: 30 °C, 50 %, 0,101325 МПа;
- Ренкін IAPWS-95 й IF97; Брайтон;
- помилка суми часток, явна нижня межа SO₂;
- CSV скачано й прочитано; JSON результатів скачано й перевірено.

Немає console errors. Нові модулі мають окремі локальні чернетки й явні SI-одиниці; не змішуються з водяним журналом. file:// та старі браузери залишаються ручною перевіркою. GitHub Pages workflow залишається лише manual, його не запускали.

## Межі результату спринту

NASA7 — ідеальні гази зі сталим складом; газові μ/λ, реакції та реальні гази відсутні. Вологе повітря — навчальна ідеальна модель, не віріальна EOS. Ренкін/Брайтон — прості цикли без регенерації, проміжного перегріву чи втрат у трубопроводах. Транспорт IAPWS-95 наведений лише до 100 МПа і 1173 K. Ці межі показані в UI та README.

**Знімок стану на момент спринту 1.1.0; це не поточний стан проєкту.** Після цього спринту додано цикли Ренкіна з перегрівом і з регенерацією, лід (IAPWS R10-06), важку воду (IAPWS R16-17) і морську воду (IAPWS R13-08) — 259 тестів станом на останній реліз; вологе повітря залишається навчальною ідеальною моделлю.
