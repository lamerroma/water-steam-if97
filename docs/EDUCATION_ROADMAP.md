# Навчальний калькулятор кафедри енергетики

Ціль: студенти та викладачі Одеської політехніки. Автор: Роман Гавриш. Назва університету описує цільову аудиторію; офіційне схвалення чи належність університету не заявляються.

## Реалізований етап

- Незалежні IF97 та IAPWS-95, 12 режимів введення, офіційні контрольні тести.
- Турбіна (потужність, витрата, ККД), флеш-випарник, насос, компресор, протитечійний теплообмінник.
- Модель зберігається в журналі, JSON, CSV та звіті; неоднозначні стани мають альтернативи.

## Спринт 2026-10-10 — реалізовано

- Наукові μ/λ IAPWS-95 з критичними доданками й офіційними транспортними контролями.
- Зворотні IF97 рівняння як наближення P–h/P–s; уточнення Newton із безпечним fallback.
- Другий водяний оракул CoolProp, контрольні NASA7 значення Cantera, JS/WASM benchmark.
- Узгоджені N₂, O₂, CO₂, CO, H₂, H₂O, CH₄, Ar, He, NO, SO₂; ідеальні гази, молярні/масові суміші й демонстраційні димові гази.
- Навчальна ідеальна модель вологого повітря з насиченням IAPWS-95.
- Прості цикли Ренкіна та Брайтона з балансом, чотирма станами, ККД і потужністю.
- Окремі CSV/JSON результати нових модулів, локальні чернетки форм.

## Фізична повнота — реалізовано

- Цикл Ренкіна з проміжним перегрівом (6 станів) і з регенерацією через один відкритий ПЖВ (7 станів); обидва звірені енергобалансом і дають вищий ККД за простий цикл.
- Лід Ih, IAPWS R10-06(2009), через енергію Гіббса; звірено з усіма 16 величинами офіційної Table 6.
- Важка вода (D2O), IAPWS R16-17(2018), через енергію Гельмгольца, режими (p,T) і насичення; звірено з 44 величинами офіційних Tables 6–8.
- Морська вода, IAPWS R13-08(2008), g=g<sup>W</sup>+g<sup>S</sup> на базі вже верифікованого ядра IAPWS-95; звірено з 39+27 величинами офіційної Table 8.
- Неон (Ne) — 12-й газовий компонент (NASA7, те саме джерело Cantera, що й решта 11); закрито три дрібні прогалини функціоналу проти оригінального сайту (питома витрата пари турбіни, відсоток пароутворення флеш-випарника, одиниці lb/(hp·h)).
- Власний набір inline SVG-іконок у тулбарі, меню та вкладках; виправлено одночасне відкриття кількох випадних меню (знайдено користувачем уживу).

## Реальні гази, наукова психрометрія, доступність — реалізовано

- Реальні чисті речовини (11: N₂, O₂, CO₂, CO, H₂, H₂O, CH₄, Ar, He, SO₂, Ne) через локальне MIT CoolProp 8 HEOS WASM, плюс дослідний режим сумішей (N₂/O₂/Ar/CO₂/H₂O, P–T, газова фаза). Звірено з Python CoolProp і незалежно з NIST Chemistry WebBook; знайдені розбіжності μ/λ метану й гелію розслідувано до першоджерела (різні версії опублікованих кореляцій), не замасковано.
- Віріальне вологе повітря ASHRAE-RP1485 через те саме локальне ядро CoolProp — закрито прогалину, яку раніше фіксував аудит проти Python `iapws`/CoolProp. Стара ідеальна NASA7-модель лишається як навчальне порівняння.
- **Публікація GitHub Pages**: https://lamerroma.github.io/water-steam-if97/ — рішення ухвалено, сайт живий і перевірений.
- Ліниве завантаження CoolProp WASM (~9 МБ) для багатофайлового сайту — підвантажується лише при першому відкритті вкладки "Гази"/"Вологе повітря", не при старті; `standalone.html` лишається повністю офлайн з усім вшитим.
- Завантажуваний офлайн-ZIP (`npm run package`) — `standalone.html` + інструкція українською + ліцензії, для роздачі студентам як один файл.
- Клікабельний глосарій (перший крок педагогічного режиму) на всіх вкладках, не лише головній таблиці: назва кожного показника (32 основних + усі показники газів/вологого повітря/льоду/D2O/морської води/циклів) — hover-tooltip і click-to-expand, пояснення простою мовою з побутовими аналогіями. Перемикач "Підказки" вимикає фічу повністю, стан зберігається в проєкті.

## Подальший розвиток

Приклади й викладацькі контрольні задачі за програмою кафедри; узгодження решти пар параметрів конкретного аналога; рівняння стану реальних газів поза HEOS-переліком і реакційні суміші з дисоціацією; лінії замерзання/кипіння та осмотичний коефіцієнт морської води; імпорт JSON нових модулів до форм; повноцінний покроковий режим розрахунку (глосарій — лише перший крок); банк завдань із самоперевіркою; друковані матеріали для викладачів; сторінка довіри/методології; новіша кореляція в'язкості метану (Sotiriadou et al. 2025) для закриття розбіжності з NIST. Набір 12 газових компонентів підтверджений автором, але його тотожність переліку комерційного аналога не заявляється.

Термінологія кафедри та решта пунктів цього розділу свідомо відкладені — рішення про перехід до них ухвалює автор окремо. Модель NASA7 (там, де CoolProp HEOS не підключено) та ідеальна психрометрика старого модуля явно позначені в UI; вони не видаються за повну реальногазову формуляцію.
