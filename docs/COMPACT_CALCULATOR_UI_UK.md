# Компактний інтерфейс калькулятора — 1.26.0

У звичайному калькуляторі налаштування більше не відкриваються поверх кнопок. На ширинах понад 900 px вони займають окрему праву колонку з власним прокручуванням; на вузьких екранах відкриваються між введенням і результатами. Escape і кнопка закриття зберігають попередню поведінку. Робоче місце діаграм зберігає своє компонування.

Картки головних значень прибрано: після введення й дій одразу показується таблиця властивостей із копіюванням у рядках. Введення ущільнено, основна кнопка розрахунку стоїть поруч із формою на ПК. Нижня панель називається «Історія розрахунків» українською та англійською; вона займає власне місце під роботою й згортається. Дублюючу верхню навігацію прибрано з відображення; меню, пошук інструментів, копіювання, експорт, звіти та діаграми доступні через наявні дії.

## Перевірено локально

- Chromium: відкриті налаштування, відсутність перекриттів і горизонтального переповнення, розрахунок на ширинах 1366, 1024, 768, 390 та 320 px; англійська назва історії.
- `BROWSER_NAME=firefox npm run test:task-ui`: клавіатура, одиниці, Escape, копіювання, дії результатів, перевірка відкритих панелей на 1366/390/320 px, 84 компонування каталогу та автономний `file://` без мережі.
- `npm run test:cross-browser`: Chromium і Firefox, UK/EN, HTML/JSON, імпорт і відновлення, 28 розділів на 320/390/768 px, діаграми, АЕС і лабораторний сценарій.
- `node --test tests/package.test.mjs`: цілісність готової збірки.
- `git diff --check`: без помилок.

Повне релізне приймання 1.26.0, Safari, справжні мобільні пристрої та публікацію цього оновлення ще не виконано. Числове ядро й протокол фонового виконавця не змінені.
