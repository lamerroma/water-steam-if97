# Курсова ЯЕР за методичкою — робочий модуль 1.16.1

Модуль призначений для введення варіанта, автоматичного перерахунку властивостей води та отримання таблиць і пояснювальної записки. Запитаний обсяг — теплогідравліка й нейтронна фізика всієї методички. Обчислювальні блоки охоплюють теплогідравліку, нейтронну модель, кампанію, стрижні та бор. **100% відповідність методичці та фізична точність ще не підтверджені:** частина кореляцій суперечлива, гранична поправка квадратної решітки задається вручну. Статус кожного розділу показано у результатах і записці.

Основне джерело: надані методичні вказівки Кравченка В.П., Одеська політехніка, 2025. [Огляд документів, Excel і виявлених помилок](REACTOR_TEACHER_MATERIALS_REVIEW.md) описує вихідний стан 1.14.0. Оригінальні документи, роботи студентів і повні тексти в репозиторій не перенесено.

## Як користуватися

1. «Навчання» → «Контрольні та курсові» → «Курсова ЯЕР за методичкою».
2. Оберіть варіант 1–45 і натисніть «Завантажити геометрію та потужність варіанта». Варіанти 1–25 мають шестигранну, 26–45 — квадратну решітку. Варіант 0 позначає власні дані.
3. Перевірте електричну потужність, ККД, тиск і температури. Таблиця варіантів задає лише сім початкових чисел; решта входів — редаговані припущення. Типовий варіант 5 і ККД 1/3 не означають, що вони призначені користувачу.
4. Розгорніть геометрію, матеріали, гідравліку, нейтронну частину й керування. Нульовий зазор потребує контакту: типова провідність 10000 Вт/(м²·К) є явно заданим припущенням; можна змінити її або обрати ідеальний контакт.
5. Натисніть «Розрахувати». Властивості води надходять з IF97 або IAPWS-95; функції й надбудови Excel не потрібні. Перегляньте попередження та припущення перед використанням чисел.
6. Виберіть координату для підстановок, відкрийте таблиці, перегляньте температури та графік кампанії. Повний профіль має 7–201 непарну кількість точок; сім контрольних перетинів формуються окремо.
7. «Пояснювальна записка HTML / друк PDF» завантажує автономний HTML. Відкрийте його у браузері та скористайтеся друком/збереженням PDF. Для автора й власних пояснень додайте розрахунок до спільного навчального звіту та відредагуйте його поля.
8. JSON зберігає входи й методи для повторного відкриття; CSV — результати. Числовий результат у звіті перераховується за збереженими входами.

Українська й англійська, мобільний екран і повна офлайн-версія підтримуються. Попередній тип «Активна зона/ТВЕЛ» зберігає свою методику й старі проєкти; новий тип має окремий ідентифікатор `reactor` і версію методу `reactor-course-2`.

Таблиця g-факторів використовується лише в 300…1300 K; холодний стан обмежено знизу 26,85 °C. F(a) чорного стрижня інтерполюється в межах наданої таблиці 0,025…10, без прихованої екстраполяції.

## Розширення 1.16.0

- **§3.3:** перерахунок тепловіддачі при поверхневому кипінні, таблиця порога й додатного надлишку потоку. Властивості об’ємного теплоносія залишаються однофазними; при насиченні розрахунок зупиняється.
- **§3.4:** опублікована кореляція CHF, профіль CHF/q та задана контрольна межа. Стару дослідну формулу можна обрати явно.
- **§4.4:** розрахунок резонансного інтеграла U-238, середніх хорд, затінення, поправок Данкова та Доплера. Показано проміжні величини. Ручний інтеграл залишається доступним.
- **§6–7:** розташування керуючих касет кільцями або координатами, окремі внески J₀², схема й пошук кількості касет у заданому наборі для заданої межі елементного бору.
- Записка містить таблицю покриття, температури, кампанію, CHF та схему стрижнів. Усі методи й картограма зберігаються у JSON/проєкті, працюють українською, англійською та офлайн.

### Як ввести розташування касет

Розгорніть «Стрижні та бор». Для кілець кожен рядок має формат `радіус [м]; кількість касет`, наприклад:

```text
0;1
0,4;6
0,8;12
```

Це лише приклад формату для 19 керуючих касет, а не рекомендована картограма реактора. Сума кількостей має дорівнювати заданому числу касет. Для координат формат `x [м]; y [м]`, одна касета на рядок. Радіуси перевіряються відносно фізичної активної зони, дублікати координат відхиляються. Перевірки посадкових місць, зіткнень касет і відповідності реальній решітці немає. У режимі кілець кола на схемі показують радіуси, а кутові позиції не задані.

Пошук перебирає задані касети від центра до периферії, до 1000 касет. Він повідомляє, якщо доступних касет недостатньо. Нові позиції не генеруються; глобальне оптимальне компонування не шукається. Інтерференція задається множником; 1 означає її відсутність, як у методичці. Для чорного стрижня таблиця F(a) не екстраполюється за межі джерела.

### Формули, суперечності й прийняті рішення

**CHF:** `qкр = 0,795 G^m (1−x)^n (1−0,0185p)` у МВт/м², `m = 0,311(1−x)−0,127`, `n = 0,105p−0,5`, p у МПа, G у кг/(м²·с). Лінійний вираз m звірено з рівнянням (15) [Lys та ін., 2021](https://vant.kipt.kharkov.ua/ARTICLE/VANT_2021_5/article_2021_5_88.pdf). У методичці показники переплутано; арифметика x та запасу також суперечлива. Використано базову форму без додаткового коефіцієнта форми потоку (fF = 1). Перевірка `0 < p < 22,064`, `G > 0`, `x < 1` захищає математичне обчислення, **не засвідчує область фізичної валідності**. Реальні межі та геометрію застосування потрібно звірити окремо.

**Кипіння:** `qрозр = Kα qпов`, `qпоч = αкон(tнас−tводи)`; лише при додатному надлишку `αкип = 0,027(10p)^1,33(qрозр−qпоч)^(2/3)`, `α = hypot(αкон, αкип)`, `tоб = tнас+(qрозр−qпоч)/α`. Тиск у степеневому множнику — бар, потік — Вт/м². Коефіцієнт і одиниці звірено з [Pronobis та Litka, 2012, Eq. (1)](https://journals.pan.pl/Content/84718?format_id=1); поправка застосовується тільки при 8…20 МПа. Ця публікація не підтверджує всю комбіновану модель недогрітого пучка. Методичка застосовує поправку нижче власного порога та містить розбіжність знака. Наш закон явно позначений як узгоджена інтерпретація; умову з додатковими 5 K і її застосування потрібно погодити з викладачем.

**Резонанс:** показано β = 17/3 для шестигранної та 17/8 для квадратної решітки, геометричні хорди, c, γ, F/M, базовий інтеграл і KT. Коефіцієнт Белла задається явно (типово 1,27). Розширення хорди й F/M на кільцеву таблетку геометрично узгоджене, але застосовність емпіричної апроксимації до отвору ще потребує підтвердження. Для ручного Iеф непотрібна апроксимація Данкова не обчислюється.

### Сумісність з попередніми розрахунками

Нові форми використовують розрахований інтеграл, кипіння та опубліковану CHF-кореляцію. Старі JSON без нових полів відкриваються з ручним інтегралом, без кипіння та з їхнім збереженим режимом CHF. Нова версія методу також використовує фізичний радіус розташування стрижнів і ефективний радіус у знаменнику аргументу J₀. Збережені входи перераховуються; старі числа можуть змінитися. Версія методу й обрані припущення вказані у записці.

## Що залишається для підтверджених 100%

1. Погодити суперечливі місця кипіння, область CHF і матеріальних поліномів; підтвердити резонансну апроксимацію, зокрема для кільцевого палива.
2. Звірити граничну поправку квадратної решітки: зараз це явне ручне значення, а не обчислена апроксимація.
3. Підтвердити контактну провідність для нульового зазору: типове значення є припущенням. Нечіткий запис емпіричної кривої джерела не відновлюється здогадкою.
4. Отримати незалежний перевірений приклад усієї курсової. Excel з `#NAME?` і зовнішніми функціями не є таким еталоном. Числова узгодженість тестів не дорівнює фізичній верифікації.

## Перевірки

- `npm run verify:reactor`: незалежна Python-реалізація, 51 набір даних. [Обсяг, результати й залишкові питання](REACTOR_VERIFICATION_UK.md). Спільні водні властивості й граничні температури не дозволяють назвати це фізичним еталоном.

- `npm test`: 667 тестів, з них 22 для реакторного модуля. Перераховуються всі 45 варіантів; перевіряються геометрія, баланс, циліндричні температури за незалежними формулами, нев’язки, нейтронна узгодженість, корінь кампанії, зворотна перевірка бору, границі таблиць, некоректні дані, JSON та екранування звіту.
- IF97 та IAPWS-95 зіставляються для водних входів нового розрахунку.
- `npm run test:reactor-course`: браузерна перевірка розрахунку/варіантів, нульового зазору, коми, помилок, англійської, екрана 390 px, відновлення/імпорту JSON, звіту й повного `standalone.html` без мережі.
- `npm run test:coursework`: регресія попередніх типів, діаграм, експорту, звіту й офлайн.

Ці перевірки підтверджують реалізацію й числову узгодженість. Вони **не підтверджують фізичну точність дослідних нейтронних наближень** і не замінюють контрольний розрахунок за узгодженою методикою.

## Код

`src/reactor-variants.js` — варіанти; `reactor-methods.js` — резонанс, кипіння, CHF і картограма; `reactor-coverage.js` — статуси розділів; `reactor-course.js` — теплові й гідравлічні обчислення; `reactor-nuclear-data.js` — числові таблиці; `reactor-neutronics.js` — дослідна нейтронна модель; `reactor-course-tables.js` — таблиці та записка; `reactor-course-ui.js` — форма й результати.
