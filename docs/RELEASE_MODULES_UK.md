# Реєстр можливостей для навчального релізу

Дата аудиту: 2026-10-12. Вихідна версія 1.16.1; виправлення стабілізації 1.16.2.

Каталог містить 28 розділів. Одна вкладка може містити кілька методик: зокрема «Курсова» має чотири типи, а «Гази» — різні моделі. Статус вкладки не є універсальною гарантією точності.

Позначення нижче описують **наявні докази**, а не сертифікацію. Автоматичний тест балансу, порівняння з тим самим ядром на іншій платформі та незалежний фізичний еталон мають різне значення.

| Розділ / режим | Методика і наявні перевірки | Межі / наступна робота |
|---|---|---|
| Вода та пара | IF97 / IAPWS-95; офіційні точки, незалежні локальні еталони, усі 20 режимів; `verify:water` | Неоднозначні інверсії; точний критичний стан та незбіжність мають явні обмеження |
| Насичення | Обидві формуляції, фазові кінці, сухість; `official`, `water-accuracy`, smart-input у браузері | P–T на насиченні не визначає сухість; невизначені властивості суміші не усереднюються |
| Таблиці насичення | Обчислені серії; `saturation-ph-copy`, `calculator-completion`, diagrams у браузері | Потрібні коректні межі й крок; імпорт відновлює входи |
| Пакетні розрахунки | Серії/CSV; `batch`, `calculator-completion`, sprint у браузері | Обмеження кількості рядків і розміру; помилки окремих станів |
| Транспорт води | IAPWS; `verify:transport`, `transport-domain`, `dielectric` | Консервативний діапазон реалізації; транспорт суміші не визначений |
| Гази: чисті реальні | CoolProp HEOS; `real-gases`, `nist-gases`, `gas-primary-controls` | Частина транспортних властивостей недоступна; відомі критичні розбіжності CH₄/He |
| Гази: ідеальні | NASA7; `nist-gases`, `sprint-tools` | Навчальне наближення, відлік h/s відрізняється від HEOS |
| Гази: реальні суміші | HEOS, дослідний P–T; `real-gases` | Немає незалежної фізичної перевірки довільних сумішей; обмежені склад, фаза й діапазон |
| Вологе повітря | CoolProp / ASHRAE; `humid-air-scientific` | Звірка переважно того самого ядра; не всі T/P/RH фізично допустимі |
| Лід Ih | IAPWS; `model-integration`, `phase-comparison` | Інші тверді фази не мають власної моделі властивостей |
| Важка вода | IAPWS; `model-integration`, `phase-comparison` | Межі реалізації, тверді/метастабільні стани та фазові неоднозначності |
| Морська вода | IAPWS; офіційні контрольні величини, `model-integration`, `phase-comparison` | Окремі області похідних, метастабільність; немає повної моделі всіх фаз |
| Фазові межі | IAPWS, допоміжні кореляції D₂O; `phase-comparison` | Допоміжну кореляцію не видавати за окремий стандарт |
| Порівняння моделей | IF97 ↔ IAPWS-95; `phase-comparison` | Різниця двох моделей не є похибкою відносно експерименту |
| Турбіна | Стаціонарний баланс і ККД; `processes`, `inverse-processes`, browser study/diagrams | Умовний зв'язок кінцевих точок не визначає реальний шлях розширення |
| Дроселювання / flash | Ізоентальпійний баланс; `processes`, `inverse-processes` | Припущення агрегату та фазова рівновага |
| Насос, компресор, теплообмінник | Баланси; `engineering`, `model-integration` | Навчальні моделі агрегатів; перевірка фаз і температурного перетину |
| Цикли | Ренкін, перегрів, регенерація, Брайтон; `full-sprint`, `sprint-tools` | Явні втрати та припущення; не довільна схема промислової установки |
| T–s, h–s, P–h | Chart.js, канонічні стани; diagram unit-тести і три браузерні сценарії | Полілінії агрегатів, адаптивна деталізація; перевіряти збереження виду й експорти |
| Витрати / гідравліка | Reynolds, тертя, місцеві втрати, насос; `hydraulics`, browser hydraulics | Перехідна область без вигаданого коефіцієнта; нестисливість/фаза за умовами моделі |
| Проєктування теплообмінника | LMTD, заданий U; `full-sprint`, browser sprint | U — вхід, а не результат повного розрахунку конструкції |
| Навчальні приклади | Контрольні задачі; `sprint`, `full-sprint`, browser sprint/smart-input | Довести відповідність інструкцій фактичним діям користувача |
| Лабораторні | Обробка вимірювань і невизначеностей; `laboratory`, browser laboratory | Вихідні вимірювання, припущення похибок і авторський висновок |
| Курсова: Ренкін і ступінь | Навчальні формули, баланси; `coursework`, browser coursework | Перевірка відповідності конкретній задачі, коефіцієнти як явні входи |
| Курсова: попередня активна зона | Теплова модель; `coursework` | Попередній модуль має непідтверджені кореляції; не ототожнювати з новим ЯЕР |
| Курсова: ЯЕР | 45 варіантів / власні параметри; `reactor-course`, Python 51 набір, browser reactor-course | Дослідний статус; комірки IAEA не пройдено (+11% у k); потрібні уточнення нейтронної моделі, застосовність CHF/кипіння й погодження неоднозначностей |
| Схема АЕС | Навчальний баланс двох контурів / MSR; `full-sprint`, browser study/navigation | Теплова схема не моделює безпеку чи нейтронну кінетику установки |
| Дослідження / варіанти | Серії, чутливість, порівняння; `full-sprint`, browser sprint | Успадковує межі вихідного модуля; пропуски не приховуються |
| Довідка / навігація | Каталог, пошук, статуси; `tool-catalog`, `tool-navigation`, browser usability/navigation | Пошук не підмінює чітких описів і меж методик |
| Проєкти | JSON, локальне сховище, входи для перерахунку; `project`, `calculator-completion`, browser sprint/study | Версія формату 1; імпорт не довіряє обчисленим полям; потрібна резервна копія при недоступності сховища |
| Навчальний звіт | HTML, preview, друк; `study-report`, browser study/laboratory/reactor-course | Автор, формули, припущення й актуальність даних; узгодженість версії всіх експортів перевірити окремо |

Таблиця розгортає підрежими, тому кількість рядків більша за кількість вкладок. Назви unit-тестів наведені без суфікса `.test.mjs`; браузерні сценарії знаходяться в `scripts/check-*-browser.cjs`.

## Наскрізні можливості

| Можливість | Наявні перевірки | Межі доказів |
|---|---|---|
| Українська / англійська | `i18n`, браузерні сценарії перемикання мови | Треба перевіряти також динамічні помилки й експорти, а не лише ключі JSON |
| Одиниці / тиск / десяткова кома | `english-units`, `smart-input`, `hydraulics`, `official` | У різних модулях різні явно зазначені основи тиску |
| Мобільний вигляд | Chromium viewport 390 px, сенсорні події діаграм | Не є перевіркою реального Android/iOS |
| PWA / офлайн | `pwa`, browser pwa: кеш, перезапуск, оновлення, збій/пошкодження завантаження, відновлення | Підтвердження в Chromium; Firefox/Safari ще не перевірені в цьому аудиті |
| Автономний HTML | `package`, браузерні file:// без мережі | ZIP і повторна збірка включені до релізного запуску |
| Захист від текстового HTML | `study-report`, `project`, browser study/laboratory | Перевірені сценарії не є повним аудитом кібербезпеки |

## Рішення щодо обсягу релізу

Зберігаємо всі поточні можливості. Дослідні моделі не підвищуються до підтверджених через успішні тести. Найближчий етап — дослідити невідповідність нейтронної моделі коміркам IAEA, потім перевірити CHF/кипіння.

[План](RELEASE_PLAN_UK.md) · [Журнал дефектів](RELEASE_DEFECTS_UK.md) · [Протокол аудиту](RELEASE_AUDIT_UK.md).


Оновлення 1.16.3: зовнішні комірки IAEA ZR-6 перевірено; нейтронна модель не пройшла порівняння (+10,97–11,47% у k). Кампанія, бор і стрижні залишаються дослідними. [Протокол](REACTOR_CELL_VALIDATION_UK.md).


Оновлення 1.16.4: методика reactor-course-3, виправлено дифузійну площу й облік поглинання; 4077 арифметичних порівнянь. Фізичне порівняння IAEA не пройдено (+10,59–11,41% у k). [Розбір](REACTOR_MODEL_REVIEW_UK.md).


Програмне приймання 1.16.7, 2026-10-13: 682 автоматичні тести й 15 браузерних сценаріїв пройдено. Перевірки метаданих і відмов збереження входять до повного прогону. Фізичний статус дослідних моделей не змінено. [Поточний протокол](RELEASE_ACCEPTANCE.json).
