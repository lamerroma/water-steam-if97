# Версія та походження експортів

Версія 1.16.5, 2026-10-12. Формули не змінено.

CSV результатів має додаткові колонки `export_app_version`, `export_build_id`, `export_method`, `export_model`. Вихідні значення й одиниці збережено. Роздільник і цитування багаторядкових назв збережено; шаблон CSV для введення не отримує додаткових колонок. Деякі CSV вже містили кілька секцій — ця зміна не перетворює їх на одну прямокутну таблицю.

HTML-експорт містить підпис версії/збірки та контекст методу. Для реакторної курсової зазначено `reactor-course-3`; змішані звіти посилаються на модель кожного результату. У JSON `version: 1` означає версію формату, а `exportedWith` — програму, що створила файл. Проєкт також має `savedWith`; після імпорту відоме походження переноситься в `importedFrom` і не замінюється поточною версією.

Ці дані **не встановлюють версію первісного розрахунку**. Старі файли не мають такої інформації. Імпорт перераховує результати за входами поточним ядром; історичні результати не приймаються за достовірні лише через метадані. Модель/метод у загальних експортах — контекст експорту, деталі окремих станів залишаються у таблицях. Метадані не засвідчують фізичну точність або справжність стороннього файлу.

Перевірка: `npm test`, `node scripts/check-provenance-browser.cjs`, браузерні сценарії навчального звіту та курсової; пакування й незалежна перевірка ZIP. Цільовий сценарій перевіряє CSV і HTML стану, JSON проєкту, імпорт файлу з попередньою версією, reload, повторний експорт, старий файл без метаданих та чистий CSV-шаблон. Повний числовий протокол 1.16.4 залишається історичним; цей спринт не виконує повторної фізичної перевірки.

Фактичний результат: **682/682** автоматичних тестів; три браузерні сценарії (метадані, навчальний звіт, курсова) пройдено в Chromium; ZIP пройшов незалежну перевірку CRC, складу, версії та відповідності HTML/документів. Збірка: `92355e28f505`.

Оновлення 1.16.7: CSV вимірювань лабораторної та її шаблон, як і CSV-шаблон пакетного введення, не отримують метадані результатів. Повторний імпорт вимірювань перевіряється після завершення читання файла (REL-014).
