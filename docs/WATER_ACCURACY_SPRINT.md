# Спринт точності води й пари · 2026-10-10

Додано спільне уточнення двох входів методом Ньютона з аналітичними термодинамічними похідними. Виправлено пропущені інтервали біля B23, критичної температури та тиску, уточнено критерії зворотних IAPWS-95 розрахунків і усунено дублікати чисельно близьких коренів. Для двофазного пошуку після вичерпання бісекції допускається найкращий стан з обмеженим залишком: це враховує числовий шум вкладеного розрахунку насичення.

## Незалежна перевірка

Набір `tests/fixtures/water-conformance.json`: 781 стан (випадкові точки з фіксованим seed 20261010, критична сітка, область 5, двофазні стани). Числові оракули: CoolProp 8.0.0 та Python iapws 1.5.5. Код цих пакетів не перенесено в застосунок.

Для IF97 контроль використовує фундаментальні рівняння з уточненою густиною; промисловий backward-результат CoolProp збережено окремо. Для IAPWS-95 контроль використовує CoolProp Dmass–T при густині, отриманій CoolProp P–T. Початкові P–T результати також збережено. Порівнюються ρ, h, s, u, Cp, Cv, w; транспортні властивості перевіряються окремими наявними офіційними тестами.

Виявлено різницю між двома шляхами CoolProp біля критичної точки. За 22,064 МПа / 647,1 K його P–T виклик дає Cp=3872,404953 кДж/(кг·K), а Dmass–T при тій самій густині — 3861,213956. Наш результат 3861,213953 погоджується з другим шляхом і Python iapws. Причину різниці всередині CoolProp не встановлено; повної тотожності його P–T API не заявляємо.

390 зворотних сценаріїв охоплюють PV, PU, TV, TU, US, VS, HV, UV, TH, TS. Допуск: 10⁻⁶ відносно тиску та 10⁻⁵ K для температури. Якщо стан неоднозначний, перевіряється наявність очікуваного кореня серед усіх повернених альтернатив; це не гарантія, що автоматично показаний перший корінь відповідає наміру користувача.

Результат: 781/781 прямих і 390/390 зворотних сценаріїв пройшли задані допуски. Максимальна відносна різниця прямої властивості — 7.81e-09; відновлення тиску — 5.33e-07, температури — 2.15e-07 K.

Повні результати: [water-conformance-results.json](water-conformance-results.json). Запуск без зовнішніх пакетів: `node scripts/water-conformance.mjs`. Перегенерація еталона потребує окремо встановлених CoolProp та iapws: `python scripts/reference-water-conformance.py`.

Усі 340 автоматичних тестів проходять.

## Браузер і межі висновку

Кнопкою «Розрахувати» перевірено IAPWS-95 u–s → 3 МПа / 300 K та IF97 T–v → 20 МПа / 640 K. Помилок консолі не виявлено.

Допуски перевіряють реалізацію, а не фізичну невизначеність формуляцій. Скінченна сітка не гарантує знаходження всіх близьких або дотичних коренів. Точна критична точка й інші заявлені в README обмеження залишаються. Цей спринт не перетворює ідеальні гази на модель реальних газів і не додає повну ASHRAE психрометрику; числової звірки з платними WSP/REFPROP не виконано.
