# Навчальні позначення на діаграмах — 1.4.0

## Можливості

- Перехрестя показує координати осей під курсором на T–s, h–s і P–h у поточних одиницях. Для P–h це абсолютний тиск на логарифмічній шкалі. На телефоні короткий дотик показує координати, коли режим переміщення вимкнений. Прокручування сторінки залишається доступним.
- Координати не передаються ядру як стан і не додаються в журнал. Наведення на обчислену точку, її вибір та повні властивості працюють окремо.
- Підписи «Рідина», «Волога пара», «Перегріта пара», «Надкритична область» прив’язані до опорних станів обраної моделі. Це орієнтири, а не алгоритм визначення фази довільної точки площини.
- Критична позначка IF97 використовує кінцеву точку купола. Для IAPWS-95 координати h/s беруться як середнє граничних фаз останнього зразка купола при Tс − 0,0001 K; Tс та Pс відомі. Позначка має символ ≈ і не означає підтримку розрахунку точного критичного стану.
- Ізотерми обчислюються за обраною моделлю при 81 значенні тиску за логарифмічною сіткою. Нижче критичної температури додаються обидва кінці насичення, включаючи двофазну ділянку. Пропуски поза моделлю не з’єднуються. Видимий діапазон тиску може приховувати частину лінії.
- Лінії сухості використовують рівноважні співвідношення h = h′ + x(h″ − h′), s = s′ + x(s″ − s′) для зразків купола. Точний критичний зразок IF97 виключений: окремі фази й сухість там не визначені.

## Керування

Відкрийте «Параметри вигляду» → «Навчальні позначення». Перехрестя й підписи спочатку ввімкнені; ізотерми й сухість — вимкнені.

Можна задати до 6 ізотерм (0…800 °C для IF97, 0,01…800 °C для IAPWS-95) у °C, K або °F та до 9 значень сухості з 0 < x < 1. Значення відокремлюйте крапкою з комою; десяткова кома дозволена, наприклад `0,2; 0,5; 0,8`. Межі x = 0 і x = 1 вже показані куполом.

«Застосувати лінії» перевіряє всі значення перед зміною налаштувань. Некоректний список не замінює останні застосовані параметри. Перемикання температурної одиниці переводить поточний список; нові значення застосовуються кнопкою. Перемикачі показують чи приховують лінії з останніми застосованими значеннями.

Налаштування спільні для трьох діаграм та зберігаються локально й у JSON. Старі проєкти отримують стандартні значення. Координати курсора є тимчасовими й не зберігаються.

## Експорт і швидкодія

Допоміжні лінії та підписи включено у SVG, PNG та HTML-звіт. Вимкніть підписи перед експортом, якщо потрібен чистий графік. Тимчасове перехрестя не включається в експорт. CSV станів зберігає попереднє призначення й не додає точки допоміжних ліній у журнал.

Ізотерми будуються лише після ввімкнення; між групами розрахунків програма віддає керування браузеру. Готові криві кешуються за моделлю та температурою. Вихід з діаграми скасовує її оновлення; експорт графіка недоступний під час побудови. Бібліотеки та обчислення локальні, автономний файл працює без мережі.

## Перевірки

```bash
npm run build
npm test
npm run serve
# З Playwright та Chromium у другому терміналі:
npm run test:diagrams
npm run test:diagram-guides
```

Для окремого runtime підтримуються `PLAYWRIGHT_MODULE_PATH`, `CHROMIUM_PATH` і `DIAGRAM_URL`. Перевірки охоплюють фізичні співвідношення сумішей, кінці насичення ізотерм, пропуски моделі, валідацію, старі/нові JSON, одиниці, мови, експорт, три діаграми, обидві моделі, мобільні екрани та автономну роботу.
