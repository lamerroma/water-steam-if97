і не є результатами поточного HEOS-кандидата. Архів підтверджує спостережений
стан доступу та введення; він не підтверджує числовий паритет.

визначення Dissociation залишаються невідомими. Нові докази додавати окремим
датованим збором, зберігаючи цей історичний набір.
