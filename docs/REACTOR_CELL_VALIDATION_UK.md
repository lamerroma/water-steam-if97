# Зовнішня перевірка нейтронної комірки — 1.16.4

**Фізичну перевірку не пройдено.** Навчальна модель завищує коефіцієнт розмноження приблизно на 11% у двох критичних решітках ZR-6. Це підтверджена розбіжність, а не повідомлення про чисельну незбіжність. Нейтронні результати, кампанія, бор і ефективність стрижнів залишаються дослідними. Перевірка не оцінює точність теплогідравлічного модуля чи ядра властивостей води.

## Відтворення

```sh
npm run audit:reactor:benchmark
npm run verify:reactor:benchmark
```

Перша команда записує `docs/REACTOR_CELL_BENCHMARK.json` і повертає код 0, якщо обчислення виконане; фізичний результат міститься у полі `status`. Друга команда є суворою фізичною перевіркою і зараз повертає код **1**. Звичайні програмні тести можуть проходити при невідповідності моделі експерименту. Фізична перевірка є окремою умовою підтвердження нейтронної моделі й не входить до зеленого статусу програмного приймання.

До першого порівняння задано ціль |k−1| ≤ 0,01. Додатково, окремо, перевіряються наведена у таблиці похибка k = 0,006 і інтервал відхилення B². Ціль 1% не є заявленою точністю програми. Наведене відхилення B² не трактується як стандартне статистичне відхилення. Навіть успішне порівняння двох випадків не підтвердило б усі режими.

## Як задано комірку

Гексагональна решітка: крок 1,27 см; радіус палива 0,380000 см; внутрішній радіус оболонки 0,387500 см; зовнішній 0,452500 см; еквівалентний радіус комірки 0,666798 см. Зазор порожній. Концентрації атомів взято з файлу вводу; одиниці атом/(барн·см) переведено множенням на 10²⁴ в атом/см³. B² переведено з см⁻² у м⁻² множенням на 10⁴.

Обчислення комірки відділено від розрахунку повного реактора: воно не потребує потужності, числа збірок або витрати. Густину води визначено з наведеної концентрації O-16 і молярної маси води; IF97 тут не використовується. Модель води задає H=2O; округлення офіційних концентрацій дає незначну відмінність від цього співвідношення. Концентрацію Zr усереднено за об'ємом металу та зазору відповідно до навчальних рівнянь. У кожному випадку температура всіх матеріалів однакова. Розчиненого бору немає.

У джерелах є дві неузгодженості:

- Короткі назви повторно використані для різних випадків: p2w2b0t2 має назву wwer_cra02 у докладній таблиці й wwer_cra05 у зведенні; p2w2b0t3 — відповідно wwer_cra03 і wwer_cra06. Ідентифікація спирається на код, повний набір крок/збагачення/бор/температура і номер CASE.
- Значення 3,079 під заголовком Vm/Vf відповідає відношенню **повного об'єму до об'єму палива** за наведеними радіусами. Відношення води до палива становить 1,66110. Адаптер використовує явні радіуси.

## Межі висновку та подальша робота

Навчальна модель не враховує U-234, Nb-93 і Hf-178 з еталонного складу. Її сталі перерізи, емпіричне сповільнення та витік не замінюють багатогрупові ядерні дані й закон розсіяння водню у воді. За двома порівняннями неможливо визначити, яка саме апроксимація спричиняє розбіжність. Жодного коефіцієнта не змінено для наближення до k=1.

Опубліковані результати WIMS наведено у JSON лише для контексту; WIMS у цій роботі не запускався. Поле `deltaKPcm` у JSON дорівнює Δk×10⁵; воно не є різницею реактивностей ρ=(k−1)/k. Контрольні суми стосуються локальних вихідних файлів перевірки, а не завантаженого оригіналу IAEA.

Наступний крок — перевірити фізичні припущення навчальних рівнянь, а потім зіставити їх з незалежним транспортним розрахунком з повним ізотопним складом і документованими ядерними даними. Окремо потрібні додаткові еталони для температури, збагачення, бору й геометрії. Підгонка одного множника для цих двох випадків не усуває проблему.


Версія 1.16.4 виправляє дифузійну площу води та інтегрування усереднених концентрацій. Зовнішню фізичну перевірку все ще не пройдено. [Розбір рівнянь, історичне порівняння та діагностика](REACTOR_MODEL_REVIEW_UK.md).
