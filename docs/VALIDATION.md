## Межі перевірки

- Пряме відкриття **file://** не виконано: політика доступного браузерного інструмента дозволяє лише HTTP/HTTPS і блокувала цей протокол. Обходів не застосовано. Сам HTML має inline CSS/JS і вбудований WASM, ініціалізований з байтів через initSync, без fetch; це перевірено package tests. У звичайному сучасному браузері файл призначений для прямого локального відкриття.
- Кнопку CSV натиснуто, але очікування browser download event завершилося тайм-аутом у in-app browser. Фактичне збереження файла через його UI не підтверджено. Формування CSV та правильність його даних перевірені автоматичним тестом; використовується стандартний Blob + anchor download.
- GitHub Actions і GitHub Pages у зовнішньому репозиторії не запускалися: публікацію користувач не погоджував. Workflow підготовлено для **ручного** запуску.
- Перевірка не є сертифікацією IAPWS і не охоплює всі можливі стани чи браузери. Дуже близько до критичної точки діє явна числова перевірка збіжності; при нестабільності калькулятор повідомляє про помилку.

## Виправлення CI, 2026-10-10

GitHub Actions "Verify IF97" падав на кроці `npm test` для двох останніх комітів v1.1.0-гілки. Причина: тест `IAPWS-95 Table 8 and Maxwell equilibrium T=275` порівнював тиск насичення з офіційним значенням R6-95(2018) Table 8 (0,000698451167 МПа) з допуском 1×10⁻⁸ відносно, а розрахований солвером результат відхилявся на ≈1,05×10⁻⁸ відносно (абсолютна різниця 7,35×10⁻¹² МПа — фізично незначуща величина). Спроби звузити поріг збіжності солвера Maxwell-рівноваги (`saturationT95`) показали нелінійну чутливість у різних точках T: будь-яке звуження порогу нижче початкового 2×10⁻¹⁰/2×10⁻¹¹ ламало збіжність в інших точках (до 24 нових провалів), тож солвер залишено без змін. Натомість допуск саме цієї перевірки для T=275 К послаблено до 1,5×10⁻⁸ з коментарем у тесті; точки 450 К і 625 К і так проходять із запасом при 1×10⁻⁸. Після фіксу: 235/235 тестів проходять стабільно (4 послідовні прогони), `npm run build` відтворює закомічені `index.html`/`dist/index.html` побітово.
