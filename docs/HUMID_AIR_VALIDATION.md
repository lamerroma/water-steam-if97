# Неідеальне вологе повітря · 2026-10-10

Вкладка використовує локальне ядро CoolProp 8.0.0, модель ASHRAE-RP1485 із другим/третім віріальними коефіцієнтами та поправкою насичення. Старий модуль NASA7 збережено тільки як навчальне порівняння; він не є fallback нового калькулятора.

## Обсяг

Заявлений діапазон застосунку: 193…473 K, 10 Па…5 МПа. RH=0…1; фізичність складу перевіряє ядро. Не кожна комбінація T/P/RH допустима: високі температури при низькому тиску можуть вимагати неможливої частки пари. При RH=0 точку роси не наведено. Невизначений мокрий термометр не наведено; неіснуючі зворотні стани відхиляються.

Режими: P–T–RH, P–T–W, P–T–точка роси, P–T–мокрий термометр. Показники: W, парціальний тиск пари, h, Cp, v, густина суміші, RH, температури роси й мокрого термометра. h/Cp/v — на 1 кг сухого повітря. Відлік h — CoolProp/ASHRAE; він відрізняється від попереднього NASA7 калькулятора.

Інверсія точки роси уточнюється через прямий CoolProp D(RH), бо штатний зворотний виклик має слабшу збіжність за дуже малого вмісту пари. Залишок заданої температури перевіряється перед поверненням результату (10⁻⁶ K для точки роси, 10⁻⁵ K для мокрого термометра). Незбіжність не маскується приблизною формулою.

## Контроль

83 фізично допустимі стани з Python CoolProp 8.0.0: атмосферний і підвищений тиск, морозне повітря, високі температури, RH=0 та 1. 13 неможливих комбінацій перевірено на відхилення й збережено в excluded з причинами зовнішнього ядра. Порівнюються W, h, Cp, v, D і B; перевіряється відновлення RH через W/D/B. Сухий граничний стан перевіряється прямо; зворотні D/B для нього не заявляються цим набором.

Допуск прямого порівняння: max(10⁻⁷ абсолютної величини SI, 10⁻⁹ відносної); відновлення RH — 10⁻⁷ абсолютного. Додатково перевірено три округлені опубліковані рядки насиченого повітря (−20, +20, +50 °C), відтворені у документації CoolProp за таблицями ASHRAE RP-1485. Це контроль інтеграції та відповідності платформ одного ядра, а не незалежна реалізація EOS чи оцінка експериментальної невизначеності.

Загальний результат: **436/436 тестів проходять**, із них 88 психрометричних і додаткова перевірка вбудованого WASM/static bindings. Формули водяних модулів у цьому етапі не змінено.

## Автономність і браузер

Офіційний JS/WASM закріплено SHA256, MIT-ліцензію й атрибуцію включено. Генерація Emscripten bindings відбувається під час build; browser не потребує eval. Немає backend, CDN чи runtime fetch у жодному форматі. Однофайлова версія (standalone.html, ~13 МБ) включає WASM без змін у вихідний JavaScript — без мережі, для file://. Багатофайловий сайт (index.html + assets/) натомість завантажує той самий бінарник лише один раз, лише коли відкрито вкладку "Гази" або "Вологе повітря" (assets/coolprop.wasm, ~9 МБ, звичайний fetch того самого походження, без base64) — початковий assets/app.js ~700 КБ, тож студенти, яким потрібна лише вода/пара, його взагалі не завантажують. Деталі лінивого завантаження: CHANGELOG.md.

Основний формат: 30 °C, 101,325 кПа, RH=50 % → h=64,355677 кДж/кг сухого повітря, D=18,450825 °C. Введення округленої D відновило RH=49,999999 %. Однофайловий формат: −20 °C, RH=70 % → W=0,00044596164, h=−19,012923 кДж/кг сухого повітря. Перевірено кнопку розрахунку; консоль без помилок. File:// залишається ручною перевіркою браузера.
