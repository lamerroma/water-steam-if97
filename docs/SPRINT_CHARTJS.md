# Діаграми Chart.js — версія 1.3.0

T–s, h–s та P–h відображаються локальною Chart.js 4.5.1. Математичне ядро й канонічні одиниці не змінені. P–h використовує справжню логарифмічну шкалу абсолютного тиску; формат збереження масштабу в JSON залишився сумісним із попереднім SVG.

## Як користуватися

- Спочатку видно купол насичення та стани поточної моделі. «Параметри вигляду» → «Показати ізобари» вмикає допоміжні лінії; кожну можна перемикати кольоровою кнопкою.
- Наведіть на стан для підказки. Натисніть для вибору; якщо поруч кілька станів, з’явиться список. Для клавіатури доступні список «Точка» й кнопки у «Стани й порядок з’єднання».
- +/− та Ctrl + колесо змінюють масштаб; перетягування переміщує графік. Після фокусування Canvas стрілки переміщують, +/− масштабують.
- На телефоні звичайний жест прокручує сторінку. Увімкніть «Переміщувати» для переміщення й масштабу двома пальцями.
- Історія підтримує виключення станів із лінії, зміну порядку, нумерацію та стрілки. Турбіна має окремий ізоентропний вихід; теплообмінник — гарячий і холодний потоки. Лінії процесів схематичні.
- PNG зберігає поточний Canvas із білим тлом і роздільністю екрана. SVG та HTML-звіт формуються з тих самих станів, видимих ізобар, одиниць і меж. SVG має власну сітку підписів, тому його оформлення може відрізнятися від Canvas. CSV містить числові властивості станів.
- Українська/англійська, SI/англійські одиниці, кількість цифр, JSON і автономний `standalone.html` підтримуються.

## Архітектура

`src/diagram-chart-data.js` формує набори в канонічних одиницях. Пропуски розривають лінії; сплайни не використовуються. Купол насичення має 181 обчислену точку на кожній гілці зі згущенням біля критичної точки.

`src/diagram-chart.js` створює Canvas і додає стрілки, номери та біле тло. Ідентичність наборів зберігається під час оновлень: вибір точки не запускає повторне малювання всіх кривих з нуля. Анімації вимкнено під час жестів і за системного налаштування зменшення руху.

`src/app.js` зберігає керування станами, масштабом, вибором і SVG-експорт. Екземпляр Chart.js знищується при переході з діаграми; ResizeObserver від’єднується.

`vendor/chart.umd.min.js` — зафіксована версія 4.5.1; MIT-ліцензія у `vendor/CHARTJS-LICENSE`, контрольні суми у `vendor/SHA256.json`. Збірка включає бібліотеку в локальний JS та автономний HTML; CDN під час роботи не потрібен.

## Перевірка

```bash
npm run build
npm test
npm run serve
# В окремому терміналі, якщо встановлено Playwright і Chromium:
npm run test:diagrams
```

Сценарій браузера підтримує `PLAYWRIGHT_MODULE_PATH`, `CHROMIUM_PATH` і `DIAGRAM_URL`, якщо середовище використовує окремий runtime. Він перевіряє всі три діаграми, історію, ізобари, близькі точки, підказки, клавіатуру, колесо, перетягування, збереження, одиниці, PNG/SVG/CSV/HTML, турбіну, дроселювання, моделі, таблиці насичення, JSON, мобільну ширину 390 px, сенсорне масштабування, режим зменшення руху й автономний файл без мережі. Знімки екрана зберігаються в системній тимчасовій папці.
