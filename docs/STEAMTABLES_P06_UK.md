## Реалізований результат

Турбіна повертає всі 15 документованих виходів: p/T/Tsat/h/s на вході; p/T/h/s/перегрів/сухість на виході; ККД, потужність, питому та фактичну витрату. Потужність потоку обчислюється без механічних і генераторних втрат. Для прямої задачі задаються ККД та витрата; зворотні задачі визначають витрату або ККД. Моделі IF97 та IAPWS-95 зберігають власні рівняння й області допустимості.

Вхідна потужність підтримує MW, kW, Btu/h. У канонічному API збережено kW; зміна одиниці перетворює число й очищає попередній результат. Питома витрата дорівнює `3600 / (h1 − h2)` у kg/(kW·h), англійська — lb/(kW·h). Попередню автоматичну одиницю lb/(hp·h) виправлено відповідно до документованого поля оригіналу. Перегрів переводиться як різниця температур: множник 1,8 для °F без додавання 32.

Насичений конденсат задає x1 = 0; недогрітий конденсат потребує однофазної стисненої рідини з T1 < Tc. Старе однофазне дроселювання P–T залишається окремим режимом. Старі проєкти з чотирма/п’ятьма аргументами flash і прапорцями 0/1 зберігають поведінку; новий строгий режим використовує прапорець 2. Обмеження `0 < p2 < p1`, невід’ємна витрата та скінченні числа перевіряються в API. За однофазного виходу поділ витрат не вигадується.

Додано дію «Додати стани до історії» для входу й виходу процесу. JSON зберігає режим, MW, точні значення та результати відтворення; CSV містить усі нові величини, фази, абсолютний базис тиску, окремий рядок `powerMW` і причини недоступності. Друкований звіт містить Tsat та перегрів. Оновлено UK/EN, мобільні й офлайн-сценарії.

## Явні локальні правила

- Для p ≥ Pc температура насичення й визначений через неї перегрів недоступні; для іншої числової відмови насичення також повертається null із поясненням.
- Перегрів вологої пари та насичених кінців дорівнює нулю. Для стисненої рідини на виході він недоступний. Сухість однофазного стану не підміняється довільним числом.
- Нульова пряма витрата допустима: потужність і фазові витрати дорівнюють нулю. Зворотні задачі потребують додатної потужності та відомого параметра. Переповнення потужності або питомої витрати явно відхиляється.

Ці правила фізично обґрунтовані та перевірені локально. Точне відображення таких станів в оригіналі, додаткові насичені/вологі входи турбіни, обмеження режимів/формуляцій і сценарій трьох колонок порівняння потребують прямого доступу до Steam97Web. Блокери B01/B03 залишаються відкритими.

## Незалежні контрольні числа

Генератор `scripts/generate-steam97-p06.py` не імпортує продукт. Використано Python iapws 1.5.5 для фундаментальних рівнянь IF97, CoolProp HEOS 8.0.0 для IAPWS-95 та незалежний Brent для P–h/P–s. Рівняння адіабатичного балансу і масового поділу застосовано окремо від коду калькулятора.

| IF97, вхід → вихід | Незалежний результат |
|---|---:|
| Турбіна: 6 МПа, 773,15 K → 0,1 МПа; η = 0,85; 10 kg/s | 7,867593956970 MW |
| Та сама турбіна, питома витрата | 4,575731817998 kg/(kW·h) |
| Температура насичення за 6 МПа | 548,736410756051 K |
| Насичений конденсат: 3 → 0,1 МПа; 2 kg/s | 0,523527300646 kg/s пари |
| Недогрітий конденсат: 3 МПа, 450 K → 0,1 МПа; 4 kg/s | 0,589907522497 kg/s пари |
| Недогрітий конденсат: 3 МПа, 300 K → 1 МПа | однофазна рідина; сепарація недоступна |

49 станів дають 97 запитів. Сітка охоплює обидві моделі, звичайні режими, насичення при 20/22 МПа, докритичний/надкритичний вхід і вихід, IF97 область 5, верхній тиск, холодну рідину IAPWS-95, η = 1, малий ККД, нульову витрату та насичені кінці flash. Окрім p/T/h/s/ρ/x звіряються Tsat, перегрів, питома витрата та баланси ентальпії, потужності, ентропії і фазових потоків.

Допуски зафіксовано у fixture: відносний 2·10⁻⁷; абсолютні T 2·10⁻⁵ K, енергія 2·10⁻⁶ kJ/kg, ентропія 2·10⁻⁹ kJ/(kg·K), сухість 2·10⁻⁷. Для рівно η = 1 незалежна перевірка пряма; зворотне замикання на межі використовує потужність тієї самої моделі, щоб її округлення не створило η > 1.

Під час побудови еталона виявлено наближені густини насичення Python IF97 в області 3 та неоднозначність вибору фази біля насичення в бібліотеках. Еталон уточнено прямим рівнянням тиску IF97 та HEOS із явною фазою для однофазних коренів. Допуски не збільшувалися. Це числова перевірка реалізацій рівнянь, а не експериментальна невизначеність.
