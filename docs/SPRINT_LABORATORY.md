# Лабораторні роботи та обробка вимірювань — 1.12.0

Група «Навчання» → «26. Лабораторні роботи». Два адаптовані сценарії: крива насичення водяної пари та парова турбіна. IF97 / IAPWS-95, українська / англійська, вебверсія, PWA та автономний файл.

## Робочий процес

1. Виберіть сценарій, одиниці та вид тиску. Вакуум вводиться як додатна величина pатм − pабс; pатм завжди задається у kPa. Ці налаштування застосовуються до всіх рядків. Зміна одиниці змінює трактування чисел, тому обирайте одиниці перед введенням/імпортом.
2. Додайте вимірювання в таблиці, вставте CSV в текстове поле або імпортуйте файл. Вкажіть умову, прилади/джерело. «Синтетичний приклад» створює модельні дані з навмисними відхиленнями, а не реальні результати досліду.
3. Натисніть «Обробити вимірювання». Помилкові фізичні точки залишаються з причиною, не входять до статистики й розривають лінію графіка. Помилка структури CSV відхиляє імпорт цілком, зберігаючи попередні дані.
4. Перегляньте вимірювання та модель або відхилення. Для турбіни доступний h–s окремого досліду: відрізки схематично з’єднують стани, не розраховують внутрішній профіль агрегату.
5. Запишіть власні висновки. Редагування умови, джерела й висновку не скидає розрахунок; зміна вимірювань чи фізичних налаштувань скидає результати.
6. Експортуйте CSV вимірювань (для повторного імпорту) або CSV результатів (із модельними значеннями й статусами). Додайте лабораторну роботу та за потреби графік до навчального звіту. Збережіть JSON-проєкт для резервної копії.

Входи та стан розрахунку зберігаються локально. HTML-звіт містить канонічні вимірювання, джерело, умову, висновок, модель, формули, таблицю й статистику. Він відкривається офлайн, придатний до друку/PDF. Під час імпорту/експорту результати перераховуються з входів; імпортовані «готові результати» не приймаються як достовірні. Відкриття лабораторного блоку зі звіту повертає канонічні входи в редактор.

## CSV

Максимум 100 вимірювань і 100 кБ. Заголовки обов’язкові, порядок незмінний. Підтримуються `;`, табуляція та кома. Десяткова кома дозволена лише із `;`/табуляцією. Це числовий CSV без довільних текстових або цитованих полів. Порожні невизначеності означають «невідомо»; порожня виміряна потужність залишає модельний розрахунок без порівняння.

Насичення (приклад структури, kPa і °C):

```csv
p;T;uP;uT
101.3;100.0;0.05;0.1
```

Турбіна (MPa, °C, kg/s, η у %, kW):

```csv
p1;T1;p2;flow;eta;power;uPower
3;400;0.1;1;85;610;2
```

Експорт результатів має інший формат із текстовими статусами й метаданими; для повторного завантаження використовуйте «CSV вимірювань».

## Методика

Для насичення модель оцінює pₛ(Tвим) та Tₛ(pвим):

- Δp = pвим − pₛ(Tвим), ΔT = Tвим − Tₛ(pвим).
- Відносне відхилення тиску = 100 Δp / pₛ(Tвим).
- u(Δp) = √[u(p)² + (dpₛ/dT · u(T))²]. Похідна визначається малим кінцевим приростом у вибраній моделі.

`u` — задана користувачем **стандартна невизначеність**, k = 1; входи незалежні, лінеаризація, атмосферний тиск фіксований. Не плутайте її з максимально допустимою похибкою приладу або розширеною невизначеністю. Для перерахунку вакууму користувач має попередньо врахувати невизначеність барометра у невизначеності абсолютного тиску, якщо вона істотна. Невизначеність моделі не врахована. Коли одного u немає, сумарне u не визначається; при u = 0 відношення Δ/u не визначається.

Для турбіни:

- h₂s = h(p₂,s₁); w = ηᵢ(h₁ − h₂s); h₂ = h₁ − w.
- Nвнутр = ṁw; Nел = Nвнутр ηм ηг.
- ΔN = Nвим − Nмодель; відносне відхилення = 100 ΔN / Nмодель.

Тип виміряної потужності має відповідати вибраному типу модельної. Внутрішній ізоентропний ККД задається незалежно від виміряної потужності; добір ККД за тією ж потужністю не є незалежною перевіркою. Для турбіни u(N) характеризує лише виміряну потужність: невизначеність входів і моделі не поширюється. Механічний/генераторний ККД — задані користувачем, не розраховані з геометрії.

Статистика: середнє знакове відхилення, MAE = середнє |Δ|, RMSE = √середнього Δ². Це відхилення від моделі, а не автоматична оцінка студентської роботи чи доказ правильності фізичної моделі. Якщо виміряна потужність відсутня, дослід входить до кількості розрахованих, але не до кількості порівняних.

## Перевірка

Модульні перевірки: строгий CSV, одиниці та вакуум/манометричний тиск, зворотні перетворення, статистика, нульові/відсутні невизначеності, некоректні фізичні точки, внутрішня/електрична потужність і баланс турбіни, обидві моделі води, звіти та JSON. Незалежно зафіксований попередній контроль турбіни 3 MPa / 400 °C → 0,1 MPa, ηᵢ = 0,85, ṁ = 1 kg/s: приблизно 611,1288 kW внутрішньої потужності; це контроль моделі, не вимірювання.

Браузерний сценарій `npm run test:laboratory`: редагування, CSV, графіки, звіт/відкриття джерела, перезапуск, JSON, українська/англійська, мобільний екран та автономний файл без мережі.
