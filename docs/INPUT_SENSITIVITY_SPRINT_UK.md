# Спринт 1.35.4: чутливість входів та фізичні гілки

Версія **1.35.4**, збірка **e0d6a646caab**. Приймальні перевірки пройдено локально. Базове ядро перевірено у збірці d209c4a35bae; після цього змінено лише підпис фаз у UI та його переклад. Фінальний worker побайтово збігається з перевіреним; фінальні UI, збірку та пакування перевірено окремо. Публікацію та віддалений CI цей звіт не підтверджує.

## Зміни

- Числові дублікати об’єднуються за машинною чутливістю, фазою, областю й знаком визначника якобіана. Група перевіряється попарно, щоб ланцюжок близьких точок не об’єднав віддалені стани. Користувацький сценарій округлення не впливає на об’єднання.
- Основний стан обирається за стійкістю та нормованою нев’язкою обох початкових входів. Кожен запропонований корінь мусить задовольняти ці входи, зокрема v після внутрішнього перетворення в ρ.
- Заголовок фазової таблиці явно показує її власні P і температуру. Після вибору іншого кореня це не видає насичення при іншому тиску за поточний стан.
- Збережено реальні альтернативи T–h біля повороту та перекриття областей IF97. Ручний вибір зберігає початкову пару, сценарій і гілку після перезавантаження. Старі журнали з іншим представником числової групи відновлюються з перерахунком, без довіри до збережених властивостей.
- Компактний розділ показує локальну зміну p, T, h, s, u, v, ρ за припущенням ± половини останнього записаного десяткового розряду. Враховано нулі, кому, запис e, перетворення одиниць та незалежність приросту від манометричного зсуву.
- Окремо показано евристичну числову роздільність: 128 EPS × термодинамічний масштаб, поширений через якобіан. Рекомендація щодо цифр враховує суму цих двох оцінок; її застосування до основних властивостей і копіювання вмикається окремо. JSON/CSV зберігають повні числа та канонічні одиниці діагностики.

Еталони зворотних розрахунків: Python iapws 1.5.5, CoolProp 8.0.0 та попередні незалежні критичні обчислення на 70/90 цифрах. Нові похідні перевірено п’ятиточковими скінченними різницями незалежних Python-формуляцій, на двох кроках; до допуску входить різниця між кроками. Є звичайна рідина, пара, надкритичні стани та точки поблизу Tc. Точну сингулярну критичну точку IAPWS‑95 не вважаємо звичайним розрахунковим станом.

Об’єднано **39** дублікатів у 2 запитах u–s, відкинуто **2** помилкових альтернатив біля 1073,15 K. Зокрема IAPWS-95-2066 повертає один стан замість 25. Малий залишок u/s не гарантує кращого тиску: представник цієї числової групи може відрізнятися від еталонного p, що відображає погану обумовленість.

Firefox перевірив автономний HTML через file://. Політика Chromium блокує цей протокол; той самий автономний файл перевірено через loopback із подальшим offline. Окремо перевірено вже завантажену сторінку з прогрітим worker. Це не перевірка встановлення PWA з нуля без мережі.

## Межі оцінки

Це локальна лінійна оцінка, а не похибка вимірювання, гарантований інтервал або додаткові точні цифри самої формуляції. Переходи через фази й області не перевіряються цією оцінкою. Для сумішей, насичених кінців, виродженого якобіана та критичної невизначеності немає вигаданих рекомендацій цифр. Великі прирости позначено як обмежену оцінку. Інші властивості, фазові таблиці та історія використовують звичайний формат.

## Відтворення та CI

Основні команди: npm run build, npm run verify:release:core, npm run audit:inverse:quick, npm run audit:inverse:full. Браузерні сценарії: node scripts/check-input-sensitivity-browser.cjs та node scripts/check-inverse-precision-browser.cjs, для Firefox BROWSER_NAME=firefox. Локальний HTTP-сервер має обслуговувати dist на 127.0.0.1:8080; доступні CALCULATOR_URL і каталоги доказів через змінні оточення.

Нові браузерні сценарії включено до повної release-перевірки для обох браузерів. CI запускає швидкий аудит на змінах і повний аудит окремим завданням для main або ручного запуску; Pages чекає успішного CI саме для SHA, що публікується. Заморожені еталони не потребують Python-залежностей чи мережі під час аудиту. Генератор нових похідних: scripts/generate-input-sensitivity.py (PYTHONPATH з iapws 1.5.5 та CoolProp 8.0.0).
