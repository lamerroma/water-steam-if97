# Від розрахунку до готової роботи — 1.23.0

Спринт об’єднує наявні сценарії основного калькулятора, процесів, циклів, гідравліки, LMTD, АЕС, курсових і лабораторних задач. Реакторна курсова залишається «У розробці».

## Дії та статус

Панель біля результатів використовує однакові назви дій: історія, навчальний звіт, діаграма та CSV там, де відповідний модуль їх підтримує. Наявні спеціалізовані кнопки й формати збережені; спільна панель викликає їхні обробники. Графіки всередині модуля отримують фокус, зовнішні діаграми відкриваються на відповідній вкладці. На телефоні нові кнопки та основні поля звіту мають висоту від 44 px.

Панель розрізняє початковий ввід, актуальний результат і змінені входи. Після редагування перенесення/експорт результату вимикаються до перерахунку. Загальне додавання до звіту також перевіряє актуальність. Раніше збережені блоки звіту залишаються самостійними.

Додавання водних станів до історії спершу перевіряє весь набір за канонічними входами та моделлю, потім додає відсутні стани. Повторні p/h тієї самої моделі не дублюються. Стани газового циклу Брайтона мають власні графік/CSV/звіт; перенесення до водного журналу недоступне. Після очищення журналу поточний стан основного калькулятора можна знову додати або перенести на діаграму.

Якщо модуль має власний CSV, викликається його експорт. Для АЕС без окремого CSV результату доступний набір p [MPa abs], T [K], h [kJ/kg], s [kJ/(kg K)], x [fraction] з назвою та моделлю кожного стану. LMTD експортує розрахункові величини й одиниці. Числа CSV не залежать від відображуваної десяткової коми.

## Редактор звіту

Зміст відображає назви в поточному порядку, включно зі збереженими користувацькими назвами. Перехід установлює фокус на заголовок блоку; підказка для пояснення — на відповідне поле висновку. Метадані, назви й перестановки оновлюють підсумок без втрати фокуса в полі вводу.

Перед експортом показуються лише редакційні нагадування: порожній набір блоків, відсутні назва роботи/автор/умова, назви та пояснення блоків. Це не фізична перевірка й не оцінка виконання роботи. Експорт HTML, перегляд та друк доступні навіть для незаповненого або порожнього шаблону, без додаткових підтверджень.

## Перевірка

- `tests/study-workflow.test.mjs`: перелік редакційних підказок, цілі переходів, перестановки та відсутність мутації даних.
- `npm run test:study-workflow`: стани → порівняння → процес → діаграма → звіт/PDF; захист від додавання застарілого результату, ідемпотентна історія, зміст, підказки, мови, reload, мобільна ширина, газові стани, CSV LMTD та повний автономний сценарій.
- `BROWSER_NAME=firefox npm run test:study-workflow`: той самий сценарій у Firefox; автоматичне створення PDF перевіряється лише в Chromium, HTML і звіт — в обох браузерах.
- Повне приймання: `npm run verify:release`; фактичний результат наведено в `RELEASE_AUDIT_UK.md` та `RELEASE_ACCEPTANCE.json`.
