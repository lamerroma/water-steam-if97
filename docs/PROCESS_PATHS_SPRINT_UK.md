# Розраховані лінії процесів і перевірка сіток — 1.18.0

## Діаграми циклів та АЕС

Графіки T–s і h–s будуються зі станів обраного термодинамічного ядра. Для циклів Ренкіна доступні IF97 та IAPWS-95; для Брайтона використовується та сама модель повітря NASA7, що й у розрахунку циклу. Баланси, витрати та визначення кінцевих станів не змінюються через вибір режиму графіка.

- Суцільні лінії: ізобарне нагрівання/охолодження, кипіння, конденсація та перегрів; ізоентальпійне дроселювання дренажів АЕС; ідеальні процеси агрегатів при η = 1.
- Крапкові лінії: контрольні ідеальні ізоентропи для агрегатів із η < 1. Їхні виходи позначені як контрольні, наприклад S4s, і не підміняють фактичний стан S4.
- Штрихові лінії: з’єднання входу й виходу реальної турбіни/насоса за замовчуванням, а також сепарація та змішування. Такі ділянки не класифікуються як нагрівання лише через однаковий тиск кінцевих станів.
- Штрихпунктирні лінії: необов’язкова навчальна модель сталого ізоентропного ККД від входу.

Для навчальної моделі при кожному проміжному абсолютному тиску p обчислюється h_s(p, s_in), а потім:

- турбіна: h(p) = h_in + η_t [h_s(p, s_in) − h_in];
- насос/компресор: h(p) = h_in + [h_s(p, s_in) − h_in] / η_c.

Це явно вибране продовження заданого ККД на проміжні тиски. Воно не є відновленням виміряного шляху, політропною моделлю чи розрахунком окремих ступенів. Змішування та сепарація залишаються схемами в обох режимах.

На ізобарних ділянках використовується ентальпія як параметр, щоб пройти через двофазну область. Обидві межі насичення додаються як окремі опорні стани. Для зміни тиску застосовується логарифмічне розбиття. Початкова сітка з 17 проб адаптивно уточнюється за геометричним відхиленням на поточному масштабі. Незбіжні стани створюють розрив, а не з’єднання через невідому область. Бюджет обмежує роботу; статус показує розриви та досягнення межі уточнення.

У списку «Моделі ліній» показано тип і кількість проб кожної ділянки. CSV містить усі розраховані точки, одиниці, модель лінії, контрольну/основну роль і розриви. «Діаграма до звіту» додає поточне зображення та пояснення вибраної моделі. Звичайний «Розрахунок до звіту» зберігає числовий розрахунок; для включення графіка натисніть окрему кнопку діаграми.

Поки триває побудова, експорт точок і зображення недоступний. Зміна осей, режиму або розміру графіка скасовує застарілу побудову. Вибір станів зберігається. Нові налаштування ліній не зберігаються у файлі проєкту; після повторного відкриття застосовується початковий режим «Лише кінцеві стани» з контрольними ізоентропами.

## Згущення реакторної сітки

У теплогідравлічних задачах курсової відкрийте «Перевірка згущення сітки». Початковий допуск порівняння температур — 0,5 K; його можна змінити. Порівнюються вкладені сітки за правилом N_new = 2(N_old − 1) + 1, до 201 точки. Якщо результат уже має 201 точку, порівнюються 101 і 201.

У точках густішої сітки визначається найбільша різниця відносно лінійної інтерполяції грубішої. У таблиці показуються найбільші різниці температур та зміна мінімального CHF/q. Це перевірка локального згущення сітки, а не доказ збіжності до точного розв’язку чи фізичної застосовності кореляцій. Зупинка при 201 точці явно позначається, якщо заданий допуск не досягнуто.

Перевірка не змінює поточний розрахунок. Для застосування натисніть «Перерахувати результат: … точок»: тоді разом перераховуються результати, таблиці й графік. Для збереження порівняння доступний CSV.

## Виправлення IAPWS-95

Під час побудови ізоентропи насоса виявлено помилкове відхилення стисненої рідини при низьких тисках. В оберненні використовувалася межа Tsat ± 10⁻⁷ K, яка могла залишатися всередині смуги неоднозначності P–T. Тепер межами служать вже розраховані фазові стани. Якщо проміжний P–T стан неоднозначний, цільова h/s/u дозволяє вибрати потрібну фазу. У межах чинного допуску обернення повертається відповідний край насичення. Неоднозначність звичайного введення P–T на насиченні збережено.
