# Доробка поточного калькулятора

Цей етап завершує робочі сценарії наявних модулів. Новий редактор довільних циклів, проточний розрахунок турбін і конструктор АЕС залишаються наступними етапами [навчального плану](EDUCATION_MASTER_PLAN.md).

## Виправлено

- Усі 12 розрахункових вкладок включено до спільного проєкту: турбіна, флеш-випарник, інженерні процеси, серії/CSV, гази, вологе повітря, цикли, лід, D₂O, морська вода, фазові межі та порівняння моделей.
- Перехід між вкладками зберігає введення. Успішні результати перераховуються при поверненні; після редагування попередній результат не відновлюється як актуальний.
- Відновлюються поточний водяний результат і активна вкладка. JSON переносить робочий простір до чистого браузера; CoolProp завантажується перед відновленням відповідних результатів.
- Старі проєкти версії 1 підтримуються. Попередні локальні навчальні чернетки переносяться під час відновлення старого локального проєкту. Імпорт нового проєкту не підмішує чернетки попереднього.
- Окремі JSON-розрахунки навчальних/наукових вкладок можна відкрити через меню імпорту. Імпортовані обчислені значення і HTML не використовуються; перевіряються входи, а результат обчислюється заново.
- Нові стани журналу містять початкову пару параметрів: відновлення не змушує критичні стани чи неоднозначні гілки проходити через P–h. Старі стани без цієї інформації читаються попереднім способом.
- Альтернативна таблиця копіює власні значення; кнопка «Вибрати цей стан» задає однозначні входи обраного стану.
- Пояснення всіх 20 водяних режимів описують потрібні величини й навчальне застосування. Головний глосарій збережено лише при наведенні.
- Режими вологості перераховують фізичний стан при зміні способу введення. HEOS-суміші пропонують лише реалізований режим P–T.
- Неактивні поля циклу/серії не блокують обчислення. Старі результати CSV прибираються після редагування або помилки структури.
- Перерахунок одиниць процесів виконується цілісно: помилка одного поля не залишає частину значень у старих одиницях.
- HTML-звіт включає поточний розрахунок із входами, водяний результат/насичення, пояснення й порівняння станів журналу. Додано u, вибрані транспортні величини та довкілля ексергії. PDF зберігається засобами друку браузера.

| Альтернативи | Копіювання температури іншої гілки при P=100 МПа / T≈623,16 K та явний вибір цієї гілки |
| Вологість | Перемикання RH → W зі збереженням вологовмісту |
| Інтерфейс | 21 поєднання ширини 320…1440 px і масштабу 100/115/130%; вкладки, результати, налаштування, помилки, підказки, роздільник і друк |
| Звіт | Автономний HTML відкрито й надруковано в PDF у Chromium |
| Офлайн | standalone.html відкрито через file://; вода і CoolProp-газ обчислюються |
| Збірка | npm run build; багатофайлова та однофайлова версії оновлені |

Числові регресії доступні у `tests/calculator-completion.test.mjs`. Вони перевіряють контрольні стани, обмеження імпорту, гілки відновлення й формування звіту. Браузерні сценарії цього аудиту виконані через Playwright/Chromium; це не перевірка кожного браузера чи всіх можливих значень входів.

## Межі цієї версії

- Межі фізичних моделей та чисельних інверсій залишаються явно зазначеними. Скінченний пошук не гарантує всіх близьких або дотичних коренів; складні інверсії IAPWS-95 поки можуть блокувати інтерфейс на кілька секунд.
- Діаграми залишаються T–s та h–s; довільні цикли і їхні криві тут ще не додаються. Масштаб графіка й геометрія панелей не переносяться в JSON.
- Глобальні одиниці водяних таблиць не змінюють явні SI-входи й результати інших речовин. Їхні одиниці підписані у формах.
- Звіт включає поточну відкриту розрахункову вкладку та водяні стани. Для звіту іншої вкладки відкрийте її й експортуйте звіт. Він не зводить автоматично всі розділи у повну курсову роботу.
- Журнал порівняння містить стани води й пари. Розрахунки інших модулів зберігаються у проєкті, а не підміняють модель журналу.
- Базовий калькулятор дає стани для задач практикуму. Автоматичний розрахунок теплоти/роботи довільного процесу й редактор навчального циклу заплановані окремо.
