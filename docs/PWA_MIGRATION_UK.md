# Перехід на PWA: кандидат 1.36.0

Дата: 19.10.2026. База: main, 6bae91383df7085f73dd1cc2f3eb462571143867.
Рішення користувача: зняти вимогу запуску програми одним HTML-файлом,
залишити встановлювану PWA з можливістю запуску без інтернету.

## Виконані зміни

- Вилучено генерацію та готові standalone.html у корені й dist/.
- Прибрано вбудовування копій CoolProp WASM і розрахункового Worker в однофайловий
  застосунок, Blob-Worker та його обробник звільнення. PWA використовує окремі
  версійовані ресурси й наявний кеш із SHA-256.
- Єдиний набір ресурсів використовується вебверсією, встановленою PWA та ZIP.
  Ідентифікатор збірки враховує також окремі Worker і WASM.
- Перепаковано ZIP: index.html, assets/, Service Worker, manifest, інструкції,
  ліцензії, метадані та serve.py зі стандартної бібліотеки Python. Це повний
  статичний комплект для першого локального запуску без інтернету.
- Колишні перевірки одного HTML переведено на підготовку кешу та нову навігацію
  без мережі. Тестові профілі ізольовані від користувацького браузера.
- Додано test:pwa-package: перевірку реального ZIP і вкладеного сервера,
  зупинки сервера та повторного запуску профілю браузера офлайн.
- Оновлено довідку, переклади, швидкий старт, README, стратегію та правила CI.
  Браузерні тести використовують Playwright browser discovery, якщо CHROMIUM_PATH
  не задано. Для перевірок у Windows Python запускався з PYTHONUTF8=1.
- Описано [архітектуру PWA](PWA_ARCHITECTURE_UK.md) і [повний обсяг ht/fluids](HT_FLUIDS_INTEGRATION_UK.md).

Початкові незакомічені документи збережено й доповнено. Формули, коефіцієнти,
моделі та допуски термодинамічного ядра не змінено. Автономні HTML-звіти результатів
залишаються доступними; вилучено саме однофайловий застосунок.

## Спостережена відмова початкової бази

Тест tests/rankine-library.test.mjs, «Independent Python iapws IAPWS-95:
dry-saturated-inlet», у Windows / Node.js 24.18.1 повертає помилку:

> 1 → 2: IAPWS-95: не знайдено стабільний корінь густини.

Її відтворено окремим запуском тесту з незмінених src/, vendor/, tests/ і package.json,
отриманих через git archive HEAD у тимчасову директорію. Це спостереження
підтверджує, що помилка присутня до PWA-міграції в цьому середовищі. Причину
залежності від середовища та фізичну правильність цього випадку тут не встановлено.
Не змінювали формули чи допуски для отримання зеленого тесту.

## Виправлення після незалежної перевірки

Незалежна перевірка показала, що оновлення кнопкою з відкритої вкладки ніколи не
видаляло кеш попереднього релізу: у Chrome після двох оновлень лежали три повні
копії (39,9 МБ замість 13,3). Старі кеші видалялися лише при активації без жодної
відкритої вкладки. Тепер сторінка повідомляє Service Worker свою збірку; кеші інших
релізів видаляються, коли єдина відкрита вкладка працює на поточному повному релізі
і немає нового релізу, що встановлюється або чекає. Відкриті старі вкладки й надалі
отримують свої ресурси.

- Модульний тест виконує справжній service-worker.js у чотирьох сценаріях
  (одна вкладка поточного релізу, дві вкладки, сторінка іншого релізу, реліз, що чекає).
- Браузерний test:pwa перевіряє видалення після закриття старої вкладки; імітований
  реліз тепер змінює номер збірки скрізь, як справжня збірка.
- Окремо в Chrome: три оновлення кнопкою в одній вкладці лишають один кеш 13,3 МБ,
  офлайн-розрахунок після перезапуску працює.

Збірка після виправлення: **1.36.0 / 41fe877d84e0**. Chrome: test:pwa 8/8, test:pwa-package
пройдено; модульні тести 1693 з 1694 (та сама описана відмова IAPWS-95 у Windows).
ZIP: 5718202 байти, SHA-256 `b147f77ec2cb3fd258369e70c6f1d77cb90f0f96b43d0fe02f21cc744f654c9a`.
Firefox після виправлення локально не перевірявся.

## Що є наступним етапом

Окремий менеджер великих завантажуваних модулів, Pyodide, ht/fluids та міграція
великих користувацьких даних до IndexedDB ще не реалізовані. Наявна PWA кешує
повний комплект поточної програми. Сумісність усього API Python-бібліотек і їхні
розмір, пам'ять та швидкість потребують прототипу та окремого приймання.

Історичні числові звіти, JSON та скриншоти попередніх спринтів збережені.
