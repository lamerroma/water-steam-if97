# Збереження роботи та відновлення

Версія 1.16.6. Якщо локальний проєкт не відкривається, меню **Файл → Завантажити оригінал для відновлення** зберігає початковий текст, навіть коли це пошкоджений JSON. Завантаження не виправляє файл автоматично.

Перед наступним автозбереженням початковий запис копіюється до ключа `water-steam-if97-project-v1-recovery`. Якщо запис копії неможливий, поточний ключ не перезаписується. Після відновлення доступності сховища нова робота зберігається, а копія залишається доступною після перезапуску. Це один запис для відновлення, а не історія всіх версій.

При переповненому або недоступному сховищі поточна робота залишається у пам'яті сторінки. Використовуйте **Файл → Експорт проєкту JSON** і переконайтеся, що файл завантажено, перш ніж закривати сторінку. Браузер може очистити своє сховище; локальна копія не замінює окремий JSON-файл.

Помилкові, завеликі або непідтримувані JSON-файли перевіряються до застосування. Сам вибір файла не запускає автозбереження. Якщо проєкт змінився під час читання файла, імпорт відхиляється; його можна повторити. Пізніша відповідь попереднього імпорту не має замінювати новішу.

Перевірка: `node scripts/check-project-safety-browser.cjs` моделює пошкоджений JSON, невідому версію, недопустимий стан і звіт, файл понад 2 МБ, зміну проєкту під час читання, QuotaExceededError, експорт без сховища та відновлення запису. Додатково виконуються перевірка метаданих експорту й автоматичні тести. Формули й фізична перевірка в цьому спринті не змінюються.

Результат перевірки 2026-10-12: **682/682** автоматичних тестів; браузерні сценарії збереження/відновлення й метаданих пройдено в Chromium. ZIP пройшов незалежну перевірку CRC, складу та відповідності HTML/документів. Версія `1.16.6`, збірка `934f839d811f`.
