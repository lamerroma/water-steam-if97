# Питання для погодження повного розрахунку ЯЕР

Мета: підтвердити застосування методики для всіх 45 варіантів і власних параметрів. Теплогідравліка, нейтронні коефіцієнти, кампанія, стрижні та бор реалізовані; арифметику додатково звірено окремою програмою на Python.

1. **Гранична поправка квадратної решітки, §4.4.** Який вираз γ слід застосовувати? У документі наведено лише гексагональний. Чи є для квадратної окрема таблиця/апроксимація? Якщо її потрібно задавати, звідки брати значення для кожного варіанта?
2. **Поверхневе кипіння, §3.3.** Який критерій є визначальним: `tоб > tнас + 5 K` чи `q > αкон(tнас−tводи)`? Потік у порівнянні має включати Kα? У прикладі 987608 < 1047441 Вт/м², але поправка застосована. Чи підтверджується додатна різниця `q−qпоч` у формулах α та температури?
3. **CHF, §3.4.** Чи слід використовувати `m = 0,311(1−x)−0,127`, `n = 0,105p−0,5`, p у МПа, G у кг/(м²·с), qкр у МВт/м²? Які межі p, G, x та геометрії? Чи потрібна поправка форми осьового потоку, і як її обчислювати для наших варіантів?
4. **Матеріали й нульовий зазор.** У яких температурних межах допустимі поліноми λ цирконію, газу та UO₂? Яку контактну провідність брати при нульовому зазорі? Якщо її треба розраховувати, потрібен чіткий вираз із одиницями та всіма коефіцієнтами.
5. **Кільцева таблетка.** Чи допустима апроксимація ефективного резонансного інтеграла з геометричною хордою кільцевого палива? Якщо ні, яка поправка потрібна для варіантів з отвором?
6. **Нейтронна комірка.** Чи підтверджується облік газового зазору й центрального отвору у другій зоні? Які константи та таблиці слід використовувати як остаточні для U-235/U-238/Pu, цирконію й води?
7. **Контрольний приклад.** Потрібен один погоджений повний варіант: усі входи, властивості води, проміжні нейтронні величини, k∞/kеф, кампанія, картограма стрижнів і концентрація бору. Кешовані числа Excel з `#NAME?` та зовнішніми функціями для цього непридатні. Бажано окремі приклади для шестигранної й квадратної решіток.
