# Спринт 1.35.0 — Вплив тиску відбору

Дослідження в бібліотеці циклів для одного відкритого підігрівача. Змінюється лише тиск відбору, решта канонічних параметрів незмінні. Окреме поле тиску відбору одиничного шаблону не впливає на дослідження; усі тиски для нього визначає сітка. Рівномірна сітка включає обидві межі; 2…41 точка, початково 11. Повний розрахунок кожної точки у Worker, ліміт 120 с, скасування та захист від запізнілих відповідей при редагуванні й навігації. Частковий розрахунок не видається за завершений.

Чотири графіки: ентальпійний ККД, питома корисна робота на kg пари котла, частка відбору та вологість виходу ЦНТ. Максимум — лише серед допустимих точок сітки. Недопустимі режими містять причину та розрив лінії. Сухість/вологість поза насиченням не визначені. Гранична вологість турбіни, неперервна оптимізація, втрати тиску й проміжний перегрів не входять до спринту.

Клік або клавіатура вибирає точку; окрема дія повторно розраховує допустиму точку та відкриває цикл у редакторі. Вибір і налаштування зберігаються у JSON-проєкті лише як входи. CSV, SVG і UK/EN-звіт містять одиниці, сталі параметри, правила сітки та межі трактування. Звіти з дослідженням формуються у Worker зі скасуванням. Імпортованим результатам не довіряємо.

Приймання: зовнішні еталони, узгодженість із одиничним розрахунком, сітка/максимум/недопустимі точки/null, Worker, Chromium/Firefox, 320/390/768 px, збереження/імпорт/звіт/джерело, автономний HTML без мережі. Публікація — окрема дія після приймання.

## Незалежні еталони

`tests/fixtures/rankine-sweep-reference.json` містить 10 розрахунків зовнішнього Python iapws 1.5.5: п’ять тисків 0,1 / 0,825 / 1,55 / 2,275 / 3 MPa для IF97 та IAPWS-95. Власний генератор: `PYTHONPATH=/path/to/isolated-iapws python3 scripts/generate-regeneration-reference.py --sweep`. Інверсії виконуються за зовнішнім рівнянням стану, правилом важеля на насиченні або scipy brentq. Результати застосунку не використовуються; Python-залежностей у runtime немає.

Контроль: pLow = 0,01 MPa, pHigh = 10 MPa, Tsteam = 773,15 K, ККД насосів 0,85/0,82 та ступенів турбіни 0,88/0,90. На зовнішній сітці з п’яти точок найбільший ηₕ IF97 ≈ 0,39012238 при 1,55 MPa. На дрібнішій сітці з 41 точки знайдено кращий розрахований режим при 1,26 MPa. Це ілюструє залежність знайденого максимуму від сітки; неперервний оптимум не встановлюється.

Числові допуски звірки: ηₕ та y — 2×10⁻⁷, робота — 0,003 kJ/kg пари котла, x/1−x — 2×10⁻⁶. Кожна допустима точка також проходить попередні критерії повного розрахунку циклу; їхні допуски не послаблено.
