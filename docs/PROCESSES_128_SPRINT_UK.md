# Прості процеси води, пари й газів — 1.28.0

Спринт розширює [модуль 1.27.0](WATER_PROCESSES_SPRINT_UK.md), зберігаючи його маршрут «Процеси й цикли → Прості процеси», фоновий Worker, діаграми T–s/h–s та навчальні звіти. Додано оборотний ізоентальпійний шлях, політропу та шість процесів ідеального газу. Це завершення погодженої частини простих процесів; довільний цикл і процеси реальних газів залишаються окремими задачами навчального плану.

## Доступні задачі

| Речовина | Модель |
| --- | --- |
| Вода й пара, включно з рівноважною двофазною ділянкою | IF97 або IAPWS-95 |
| Сухе повітря, N₂, O₂, CO₂, He, Ar | Ідеальний газ зі сталими cp, cv при 300 K або NASA7 cp(T) |

Початкова пара: p–T, p–h, p–s; для води також p–x. Тиски абсолютні, MPa; температури K; питомі енергії kJ/kg. Для газу сухість відсутня, а водяні формуляції недоступні. Ідеальність газу обґрунтовується умовою задачі: межі температурного полінома не підтверджують ідеальність при високому тиску.

| Процес | Кінцева умова |
| --- | --- |
| p = const | T, h, v; для води також x |
| v = const | T або p |
| T = const | v або p; для води також x |
| s = const | p або T |
| h = const | p |
| pvⁿ = const | p або v; при n = 0 тільки v |

### Політропа

Задається саме закон p·vⁿ = const, а не геометрична лінія між кінцевими станами. Інтерфейс приймає −20 ≤ n ≤ 20; скінченність усіх станів та енергій контролюється додатково. Вихід за межі формуляції, неоднозначна інверсія або несумісна умова дають помилку.

За кінцевим тиском v₂/v₁ = (p₁/p₂)^(1/n); за кінцевим об’ємом p₂ = p₁(v₁/v₂)ⁿ. При n = 0 тиск не визначає кінцевий об’єм, тому така умова відхиляється. n = 0 з кінцевим об’ємом є ізобарою.

Аналітична робота: w = 1000p₁v₁ · expm1[(1−n)ln(v₂/v₁)]/(1−n). При n = 1 використовується скінченна границя w = 1000p₁v₁ln(v₂/v₁). Формула через expm1 зберігає стійкість поблизу одиниці. Для цього закону wₜ = n·w. Ці співвідношення перевіряються незалежно від числового ∫p dv.

Для реальної води n = 1 означає pv = const і загалом не є ізотермою. Для ідеального газу зі сталими cp/cv n = cp/cv дає ізоентропу. Для NASA7 cp/cv змінюється з температурою, тому сталий n не можна автоматично прирівнювати до поточного cp/cv на всьому шляху.

### Ізоентальпійний шлях і дросель

Новий h = const — оборотний рівноважний навчальний шлях. Для нього Δh = 0 та q = wₜ = −1000∫v dp. Він може мати ненульове тепло й роботу.

Адіабатне дроселювання — інша, необоротна модель агрегату: q = 0, wₜ = 0, h₂ = h₁, за нехтування кінетичною/потенціальною енергією. Інтеграл ∫T ds уздовж довільної рівноважної ізоентальпи не є теплом дроселя. Це пояснення включено до результату та навчального звіту. Наявні дросельні/флеш-розрахунки не змінюються.

### Ідеальний газ

Склад повітря береться з наявного AIR у газовому ядрі; для чистих газів використовується одна речовина. Склад уздовж процесу незмінний. Реакції, дисоціація та конденсація не моделюються.

Обидва режими обмежено температурними межами використаних NASA7-даних: для обраних шести речовин 200…6000 K, без екстраполяції. Стала теплоємність — окрема навчальна апроксимація в цих межах, а не твердження про її фізичну точність у всьому діапазоні.

- IDEAL-CP: cp = cp(300 K), cv = cp − R; h = h₀ + cp(T−300); s = s₀ + cp ln(T/300) − R ln(p/p₀).
- IDEAL-NASA7: існуючі інтеграли NASA7 для h(T), s(T,p), cp(T); інверсії p–h/p–s використовують перевірене газове ядро.
- p₀ = 0,101325 MPa; h₀/s₀ беруться з NASA7 при 300 K для того самого складу. Від’ємна абсолютна ентальпія через цей базис не є помилкою.
- Для обох моделей pv = RT/1000 та u = h − RT.

Ідеальний газ має h = h(T), тому його ізоентальпа водночас є ізотермою. Межа поліномів NASA7 при 1000 K додається до сітки як окрема опорна точка, якщо процес її перетинає.

## Баланси та числова перевірка

Конвенція знаків і метод інтегрування з 1.27.0 збережені: q = ∫T ds, w = 1000∫p dv, wₜ = −1000∫v dp; додатні тепло до речовини й робота від речовини. Контролюються q−Δu−w, q−Δh−wₜ і зміна інтегралів при подвоєнні сітки. Допуск 0,005 + 10⁻⁵·max(|q|,|w|,|wₜ|,|Δu|,|Δh|) kJ/kg; максимум 1024 базові інтервали плюс опорні точки.

Для політропи незалежно перевіряються аналітична робота та q = Δu + wаналітичне. Для водяної ізоентальпи закрита формула тепла не заявляється: відповідне поле показує «—», а точність підтверджується двома балансами та згущенням. Для ідеального газу на ізоентальпі додатково q = TΔs. Недосягнення хоча б одного критерію залишається явним попередженням. Числовий допуск не є фізичною невизначеністю.

## Збереження й інтерфейс

- Проєкти 1.27.0 без поля fluid читаються як вода; старі результати відновлюються з входів.
- Нові проєкти зберігають речовину, модель теплоємності, n, граничну умову та масу. Газові моделі дозволено лише для цього модуля й відповідного блоку звіту.
- Вибір газу не знімає позначку IF97/IAPWS-95 у головному калькуляторі. Газові стани не потрапляють до водяної історії; для них доступні власний збережений розрахунок та навчальний звіт.
- Зміна n, речовини, моделі чи інших входів вилучає старі результати й скасовує Worker. Зберігаються захист від запізнілого результату та обмеження виконавця 60 с.
- Зі звіту відкривається вихідна задача з правильними речовиною, n та моделлю. Під час імпорту не приймаються готові результати чи довільний HTML.
- CSV містить модель, речовину, тип процесу, n для політропи, масу, точки шляху та баланси. SVG і звіт відображають обчислену траєкторію.
