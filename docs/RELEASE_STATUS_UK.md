Перший CI виявив залежність офлайн-тесту напрямних від спільного сховища
браузерних вкладок. Відтворено повернення двох попередніх напрямних через
pagehide-автозбереження. Сценарій отримав незалежний контекст, перевірку
чотирьох стандартних напрямних збережено. Повторний повний CI успішний.

Steam97Web для P03/P04 залишається непідтвердженою; відомий результат фізичної
перевірки нейтронної моделі описано в її окремому протоколі.
