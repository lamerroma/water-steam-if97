# Підтверджена публікація 1.41.0

Перевірено 23.10.2026 на [публічному сайті](https://lamerroma.github.io/water-steam-if97/).
Build **a8e94fb1e643**, прийнятий коміт **5dc609c92fe80a7ffe050b4cc0696d6876628ac2**.
CI, окремі inverse-full/library-registry та GitHub Pages успішні.

Після публікації перевірено Chromium і Firefox: по 39 числових зіставлень
зі старою версією (3986 величин без розбіжностей), 13 офлайн-сценаріїв,
старі JSON-проєкти, 15 циклів діаграм і два скасування активного уточнення.
Штатне оновлення з установленої 1.40.1 зберігає проєкт, історію, одиниці,
мову й підготовлений Python-пакет. HEOS та ht.LMTD працюють після повного
перезапуску без мережі. Незалежні читачі перевірили на браузер 8 експортів
XLSX/ODS/XLS/CSV та 24 числові комірки. Нові сценарії ht/fluids пройшли
по 15 груп, включно з реконструкцією об'єктів офлайн.
Усі 27 публічних ресурсів побайтово збігаються з прийнятим комітом.

[Повний протокол, перші відмови та межі](release-1.41.0/REPORT_UK.md) ·
[точні результати](release-1.41.0/publish-summary.json) ·

[Pages](https://github.com/lamerroma/water-steam-if97/actions/runs/39909605539).

У перевірених сценаріях регресій не виявлено. Це не підтверджує всі можливі
входи, числовий паритет P03/P04 зі Steam97Web або точність усього ht/fluids.
Нейтронна комірка має physical-screening-failed. Фізичні мобільні пристрої
та Safari не перевірялися; попереднє спостереження Firefox при масовому
P08-експорті не оголошено виправленим. Перші відмови підготовки та виправлення
очікувань драйвера збережено окремо від успішних повторів. Після відкриття
збереженого проєкту перед навігацією дочекайтеся повідомлення про його
відновлення; раннє втручання в одному прогоні Firefox зупинило відновлення.

[Локально перевірений кандидат 1.41.1](release-1.41.1/REPORT_UK.md) усуває відтворений конфлікт ранньої навігації та введення під час відновлення. Це ще не протокол публікації нової версії.
