# Упорядкування інтерфейсу — 1.14.0

Мета: зберегти наявні інструменти, зробити їх легшими для пошуку та показати різницю між числовими перевірками й обґрунтованістю навчальної методики.

## Вибір інструмента

- П’ять напрямків збережені. Назви вкладок короткі, без наскрізної нумерації. Внутрішні маршрути не змінені: попередні проєкти, JSON та історія продовжують відкриватися.
- «Обрати інструмент» відкриває каталог поточного напрямку з описами та позначками методик.
- Пошук працює для всіх напрямків: «насос», «втрати тиску», «ккд циклу», «лопаткова потужність», англійські назви, ключі маршрутів. Слова запиту мають бути присутні у назві, описі чи словнику синонімів. Це прозорий текстовий пошук, не автоматичне розуміння довільної умови задачі.
- Старі номери на кшталт `21.` та `27.` залишені пошуковими синонімами.
- На телефоні напрямок вибирається компактним списком замість кількох рядів кнопок. Каталог і всі інструменти доступні також офлайн.

## Позначки методик

Пояснення знаходиться перед формою. «Про цей розрахунок» показує припущення та значення позначки.

| Позначка | Що вона означає |
|---|---|
| Залежить від режиму | Інструмент поєднує кілька методик; конкретний статус з’являється після вибору режиму |
| Контрольні перевірки | Реалізація має числові контрольні перевірки; це не сертифікація й не оцінка фізичної невизначеності |
| Навчальна модель | Баланси та приклади перевіряються; висновки залежать від спрощень і заданих коефіцієнтів |
| Методику уточнюємо | Частина первинних джерел або діапазонів кореляцій ще не підтверджена |
| Дослідний режим | Режим має додаткові обмеження й потребує незалежної звірки |
| Візуалізація | Графік допомагає аналізувати дані; зчитування з нього не замінює прямого розрахунку |
| Робота з даними | Збереження та представлення; методика належить вихідному розрахунку |

Статус залежить від режиму: курсова Ренкіна/ступеня турбіни — навчальна; активна зона — «Методику уточнюємо». Реальні чисті гази — контрольні перевірки, NASA7 — навчальна ідеальна модель, газові суміші — дослідний режим. Для двох останніх особливі обмеження показуються відповідно до вибраного режиму; непідтверджені реакторні кореляції показані окремо до розрахунку.

Нові першоджерела для реакторних кореляцій у цьому спринті не отримані. Статус не змінює й не приховує це обмеження.

## Форми й результати

У модулях з формами є спільна підказка послідовності: введіть дані, розрахуйте, перевірте результат і припущення. Після успішного розрахунку вона показує модель. Відображення використовує фактичний статус форми; чисельні алгоритми не змінені.

Для курсових:

- Первинні параметри ступеня турбіни показані одразу, коефіцієнти — у розгортаному блоці.
- Підсумки, попередження, графік та дії з результатом залишаються видимими.
- Стани, підстановки, повний осьовий профіль і розрахунок вибраної точки відкриваються окремо.
- Зміна входів прибирає попередній результат, як і раніше.
- HTML-звіт містить усі таблиці незалежно від згортання. Прямий друк тимчасово розгортає подробиці й відновлює стан після друку. Загальний експорт HTML також розгортає клони блоків.

## Підтримка

Опис, пошукові синоніми та статуси винесено в `src/tool-catalog.js`; тексти — в український та англійський каталоги мов. При додаванні маршруту потрібні назва, опис, обмеження та статус. Тест перевіряє повноту для всіх 28 маршрутів.

## Перевірка

- `npm test`: усі наявні перевірки й покриття каталогу, пошуку та статусів.
- `npm run test:usability`: вибір за задачею, зміна статусу, форми, згортання/друк, телефон, мови, відновлення власних даних та standalone офлайн.
- Регресії `test:navigation`, `test:coursework`, `test:laboratory`, `test:sprint`, `test:diagrams` і `test:pwa` перевіряють попередні можливості.
