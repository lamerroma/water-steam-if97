# P08 — табличні формати для підтверджених водяних результатів

Кандидат **1.35.9** додає справжні XLSX, OpenDocument ODS, Excel 97–2003 XLS (OLE/BIFF8) та спільний CSV UTF-8. Це завершена локальна поставка відомих водяних сценаріїв. Повне приймання відповідності Steam97Web залишається відкритим через B01/B03/B08: зразків завантажених файлів оригіналу немає, а невідомі газові результати P03/P04 не вигадуються.

## Доступні результати

- Поточний стан, насичені кінці й альтернативні корені; повні властивості, фазові ознаки та причини відсутніх значень.
- Історія зі збереженням назв, моделі кожного стану та всіх його властивостей.
- Таблиця насичення: базис і одиниця вхідного діапазону, обидві фази, теплота пароутворення, помилки окремих рядків.
- Турбіна й flash: стани, показники процесу та повні властивості кінцевих і контрольних точок.
- Діаграма: точки, їхні підписи, вибір, спільний стиль та іменовані серії. Графічна інтерполяція явно відокремлена від термодинамічного процесу.
- Пакетний розрахунок: успішні стани й рядки з помилками.

Біля чинної дії експорту розташовані компактний вибір формату та «Зберегти таблицю». Зміна входів прибирає застарілий результат та його експорт; назва нового діапазону не підписує старі числа. Нові елементи перекладаються українською/англійською та переносяться на вузькому екрані. Експорт історії розміщено перед рештою її дій, щоб плаваюча кнопка повернення не перекривала його.

## Контракт файлу

`src/tabular-data.js` формує типізовані рядки без проміжного CSV й без округлення до екранних цифр. `src/spreadsheet.js` записує всі формати з тієї самої схеми. Старі CSV-кнопки збережено; їхні початкові серіалізатори використовують ті самі винесені масиви рядків.

Аркуш Metadata містить версію/збірку експорту, метод, модель, систему одиниць та абсолютний базис тиску. Для стану збережено p0/T0 і визначення фізичної ексергії. Це походження експорту, а не твердження про версію первісного розрахунку. Одиниці вказані біля значень або в заголовках; метадані не замінюють одиниць конкретної клітинки. Процес зберігає визначені ним одиниці kJ/kg та kJ/(kg·K); детальні властивості мають власні одиниці.

Числа — числові клітинки; нуль не підмінює невизначену величину. Порожні властивості й причини недоступності зберігаються окремо. Назви, Unicode, лапки, роздільники й переноси рядків залишаються текстом. Формул немає. У CSV текст, який табличні програми можуть трактувати як формулу, отримує початковий апостроф; справжні від’ємні числа залишаються числами. Новий CSV містить усі іменовані розділи з маркерами `worksheet` та BOM UTF-8.

Спільний контракт обмежує аркуш 65536 рядками і 256 колонками. Перевищення відхиляється до запису, без обрізання. XLS додатково відхиляє текст понад **4000 UTF-16 одиниць у клітинці** й пропонує XLSX/ODS: довгий Unicode не можна безпечно передавати цьому BIFF8 writer через CONTINUE. XLSX/ODS зберігають до 32767 UTF-16 одиниць; тест містить 16384 символи Unicode. Підтверджені поточні назви й наукові примітки вкладаються в межі XLS. Це відоме локальне обмеження, а не заявлена поведінка Steam97Web.

## Бібліотека та автономність

Локально включено SheetJS CE **0.20.3**, Apache-2.0, 951904 байти. SHA-256 і джерела: [vendor/SHEETJS.json](../vendor/SHEETJS.json), [атрибуція](../THIRD_PARTY_NOTICES.md). Отримано неофіційну npm-перепублікацію з перевіреним tarball integrity; бандл побайтово збігається у двох незалежних перепублікаціях. Офіційний CDN недоступний за політикою середовища; підпис автора не заявляється.

Бібліотека включена у звичайний app.js та standalone, без зовнішніх CDN-запитів і без імпорту користувацьких електронних таблиць. Worker розрахунків не завантажує цю бібліотеку. PWA перевіряє хеш цілого app.js під час встановлення. Повна Apache-2.0 ліцензія включена в обидва HTML та автономний ZIP.

Зафіксовані адаптації: BIFF8 використовує SST, інакше writer обрізає довгий текст; ODS перепаковує власний щойно створений ZIP із першим нестисненим `mimetype` без extra field. CRC й структуру перевіряє незалежний Python ZIP reader.

Порівняно з 1.35.8 app.js збільшився приблизно на 0,97 MB, standalone — на 0,98 MB (близько 6,4%). Обрано один повний writer для трьох справжніх форматів; заміна на CSV з іншою назвою або видалення підтримки старого XLS не використовувалися. Точні байти й хеші остаточної збірки наведені в acceptance JSON.

## Перевірки та відтворення

Машинний підсумок: [STEAMTABLES_P08_ACCEPTANCE.json](STEAMTABLES_P08_ACCEPTANCE.json). Схема і межі: [tasks.json](steam97-p08/tasks.json). Докази незалежного читання й браузерів збережено в `docs/steam97-p08/`.

`scripts/audit-steam97-p08.mjs` створює **91 файл**. Незалежні openpyxl 3.1.5, odfpy 1.4.1, xlrd 2.0.2 та Python CSV звіряють **33138 клітинок**, їхні типи, числа, Unicode, порожні значення та відсутність формул. Звичайні, критичні, навколокритичні й двофазні стани представлені для IF97/IAPWS-95; додатково область 5, англійські одиниці/J, процеси, помилкові рядки, довгі та формулоподібні підписи. Довгий текст XLS явно відхиляється і записаний окремим контролем. Допуск серіалізації — відносний 2e-14, абсолютний 1e-13; це точність збереження чисел, не невизначеність EOS.

Обидва браузери завершили по **5 груп, 48 файлів і 112 незалежних числових зіставлень**. Повний набір має **1673 модульні тести**, 14 перевірок ядра/збірки/пакування, 6 регресій графіків і проєктів та по 7 перевірок життєвого циклу PWA. 30 старих CSV-сценаріїв побайтово збігаються із серіалізаторами 1.35.8 на однакових канонічних результатах (`node scripts/check-steam97-p08-legacy.mjs`).

Браузерні перевірки завантажують файли через справжні кнопки і передають їх незалежним Python-читачам. Числа властивостей додатково зіставляються з незалежними контрольними станами P07 у їхніх встановлених допусках. Перевіряються обидві моделі, усі формати, діапазони, процеси, пакет, діаграма, англійська мова, 320/390 px, standalone та встановлена PWA після офлайн-перезапуску. Firefox відкриває справжній `file://`; керований Chromium блокує такі навігації, тому явно завантажує ідентичний standalone з loopback перед відключенням мережі. Це обмеження позначене в його звіті. Кліки Chromium в тесті обмежені за частотою через захист браузера від пакетних завантажень.

Для повторення: `python -m pip install -r scripts/reference/requirements-p08.txt`, `npm run audit:steam97:p08`, `node --test tests/spreadsheet.test.mjs`, `npm run test:steam97:p08` для Chromium/Firefox з локальним `CALCULATOR_URL`, `npm run verify:release:core`. Регресії графіків/проєктів — `node scripts/check-steam97-p08-regression.mjs`; обмеження `file://` у керованому середовищі можна явно врахувати наявним локальним harness P07. У CI fallback не вмикається. CI встановлює незалежні читачі й повторює як аудит файлів, так і обидва нові браузерні набори.

Основні рівняння властивостей і зворотні розрахунки не змінено. Реакторні патчі з окремої Windows-теки не включалися. Наступний етап — P09: підсумковий аудит локально реалізованих сценаріїв і точний перелік відкритих вимог. Він не може оголосити повний аналог до закриття B01/B03/B04/B05/B08/B09 та інших чинних питань оригіналу.
