# Редактор довільного циклу — 1.29.0

Інструмент «Процеси й цикли → Редактор циклу» створює впорядкований набір іменованих станів. Для кожного рядка задається закон процесу до наступного; у замкненому режимі останній процес веде до першого стану. Є відкритий режим для перевірки незавершеного шляху.

## Робочий сценарій

1. Оберіть воду (IF97/IAPWS-95) або ідеальний газ (повітря, N₂, O₂, CO₂, He, Ar; сталі cp/cv при 300 K або NASA7 cp(T)).
2. Додайте 2…12 станів; замкнений цикл потребує щонайменше трьох. Назви до 40 символів, унікальні. Початкові пари p–T, p–h, p–s; для води також p–x. Тиски абсолютні в MPa, температури K.
3. Для кожного стану оберіть ізобарний, ізохорний, ізотермічний, ізоентропний, ізоентальпійний або політропний вихідний процес. Політропа має явний показник n у межах −20…20 і закон pvⁿ = const.
4. Стани можна перейменовувати, редагувати, переставляти та видаляти. Порядок рядків визначає топологію. Окрема дія обчислює новий стан за законом вибраного рядка й кінцевою умовою та вставляє його після цього рядка. Вихідний закон нового стану потрібно обрати відповідно до наступної ділянки.
5. «Розрахувати й перевірити цикл» обчислює всі траєкторії й перевіряє їхні кінці. Несумісний стан дає помилку з назвою переходу, величиною розбіжності й допуском. Програма не змінює задані стани, щоб штучно замкнути цикл.
6. Ті самі траєкторії відображаються на T–s, h–s і p–v зі стрілками напряму й назвами станів. Вибір маркера або рядка синхронізує виділення на трьох графіках і вибір вихідного стану для побудови.
7. Збережіть JSON-проєкт, CSV, SVG потрібної діаграми або додайте блок навчального звіту. Зі звіту відкривається вихідний редактор.

## Модель та баланс

Використовується числове ядро простих процесів 1.28.0, з його межами формуляцій, перевіркою неоднозначності, опорними точками та уточненням інтегралів. Модель описує оборотні рівноважні шляхи. Ізоентальпа не є необоротним адіабатним дроселем. Для ідеального газу склад сталий, без реакцій чи фазових переходів; NASA7 і навчальний режим сталих теплоємностей обмежені 200…6000 K.

- Питоме тепло q = ∫T ds; робота w = 1000∫p dv; технічна робота wₜ = −1000∫v dp. Підведене тепло та робота від речовини додатні.
- qᵢₙ і qₒᵤₜ підсумовуються за знаком тепла кожного інтервалу, включно зі зміною знака всередині одного процесу. Сума лише додатних/від’ємних підсумків цілих процесів дала б помилку для такого шляху.
- Замкнений цикл: qᵢₙ − qₒᵤₜ − w = 0 та qᵢₙ − qₒᵤₜ − wₜ = 0 в межах числового допуску. На відкритому шляху враховуються Δu та Δh між першим і останнім станами.
- Термічний ККД η = w/qᵢₙ наведено лише для перевіреного замкненого теплового двигуна з додатною корисною роботою, підведеним та відведеним теплом. Для відкритого шляху, циклу зі споживанням роботи, нульовою роботою чи недосягнутим допуском ККД двигуна відсутній. Холодильний коефіцієнт у цьому спринті не заявляється.
- Маса масштабує питомі енергії до Q/W у kJ; вона не є масовою витратою, потужність не обчислюється.

Узгодженість кінцевого стану з наступною незалежно заданою точкою перевіряється за p, T, h, s та v: |Δz| ≤ a + 5·10⁻⁶ max(|z₁|,|z₂|). Абсолютні a: 10⁻⁸ MPa, 0,002 K, 0,005 kJ/kg, 0,00002 kJ/(kg K), 10⁻⁹ m³/kg відповідно. Баланс усього циклу використовує суму допусків процесів плюс оцінку похибки стикування через u/h. Допуски є числовими, а не фізичною невизначеністю.

p–v-крива використовує всі ті самі обчислені точки, що й інтеграл роботи. Перевірка площі p–v тестується незалежним сумуванням. Додаткова умовна лінія замикання до графіка не додається. Для замкненого циклу таблиця замикання порівнює кінець останнього обчисленого процесу з першим станом; для відкритого шляху показується залишковий розрив.

### Незалежні контролі

- П’ятиточковий цикл газу зі сталою та змінною теплоємністю: дві ізохори й три ізобарні ділянки. Робота дорівнює площі прямокутника на p–v.
- Аналогічний п’ятиточковий водяний цикл для двох формуляцій.
- Цикл Карно 600/300 K: обидві газові моделі дають η ≈ 0,5; робота перевіряється як R(600−300)ln2.
- Зворотний цикл споживає роботу без ККД двигуна; відкритий шлях має ненульову зміну енергії.
- NASA7-політропа зі зміною знака тепла на одній ділянці перевіряє незалежне підсумовування qᵢₙ/qₒᵤₜ.

## Відтворення та фонове виконання

Проєкт зберігає лише обмежену чернетку входів: речовину, модель, масу, режим замикання, рядки станів і закони процесів. Незавершене чи некоректне текстове введення зберігається без автоматичного розрахунку. Імпортовані властивості, HTML і готові результати не приймаються. Навчальний звіт також зберігає канонічні входи; таблиці, діаграми, формули й баланс формуються заново.

Обчислення циклу й вставлення наступного стану працюють у Worker. Зміна входів, навігація або скасування переривають виконавця; запізнілі відповіді ігноруються. Для редактора встановлено ліміт 120 с і 12 станів; для імпорту проєкту діє загальний ліміт читача. Великі діапазони, які не встигають у ліміт, не повертають частковий результат як готовий.

- `npm run test:custom-cycle` — браузерний сценарій редагування, генерації й скасування, три графіки, мова/мобільний вигляд, відновлення чернетки/проєкту/звіту та приклад КПІ.
