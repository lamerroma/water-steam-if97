## Межі перевірки

Браузерний інструмент відхилив file:// через політику безпеки; обхід не застосовано. Потрібно вручну відкрити index.html подвійним кліком у своєму браузері. Через HTTP сторінка ініціалізована і кнопка «Розрахувати» працює з connect-src none без console errors.

Зміна viewport інструментом не вплинула на вкладки: CSS перевірено в окремому iframe 390×844 (mobile-preview.html), без горизонтального переповнення форми; широкі таблиці прокручуються. Desktop перевірено на 921px і 1280px. Це не перевірка всіх мобільних пристроїв або всіх браузерів.

HTML-звіт візуально перевірено (print-check.png), stylesheet містить A4 landscape і повторення заголовків таблиці. Системний діалог друку, PDF із нього і фізичний принтер не перевірено. Попередження beforeunload при відмові localStorage залежить від браузера; звичайне autosave/reload перевірено.

Сайт не опубліковано; реліз підготовлено у файлах. IAPWS-95 і гази — окремий майбутній етап.
