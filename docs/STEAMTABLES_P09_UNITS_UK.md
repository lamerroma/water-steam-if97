# P09-01 — одиниці транспортних властивостей

Версія **1.35.10** завершує підтверджену підзадачу одиниць із довідки [Steam97Web](https://www.steamtablesonline.com/help.aspx). Це обмежена поставка перед повним прийманням P09. Модель води, корені й кореляції не змінено; WASM відкладено.

У налаштуваннях одиниць додано три незалежні списки:

| Величина | Доступний вибір |
|---|---|
| Динамічна в’язкість μ | Pa·s, μPa·s, lb/(ft·s), lb/(ft·h) |
| Кінематична в’язкість ν і температуропровідність | m²/s, mm²/s, ft²/s, ft²/h |
| Поверхневий натяг | N/m, mN/m, lbf/ft |

«За системою» — початковий вибір для нових і старих проєктів; він зберігає попередню поведінку SI/English. Явний вибір перевизначає систему для відповідної величини. Зміна системи скидає індивідуальні налаштування за чинною поведінкою програми. Різниця між секундами й годинами — множник 3600; mm²/s містить квадрат перетворення довжини.

Одиниці застосовуються до таблиці поточного стану й насичених фаз, копіювання, історії, поточного CSV, повних властивостей у XLSX/ODS/XLS/CSV для станів, історії, процесів, діаграм і пакетів та властивостей поточного стану в HTML-звіті. Налаштування записуються у JSON і локальне збереження. Числові значення експорту не округлюються як екран. Старі CSV без індивідуальних налаштувань залишаються побайтово сумісними. JSON стану містить канонічні числа й одиниці за попереднім контрактом.

## Перевірки

- `scripts/audit-steam97-p09-units.mjs`: типова рідина/пара, надкритичний стан, IF97 у критичній точці, стан на 0,001 K вище неї, гаряча пара, суміш і насичені кінці обох моделей. Точна критична точка IAPWS-95 та 1500 K для IAPWS-95 явно відхиляються за наявними межами; ці відхилення перевіряються окремо.
- `scripts/reference/transport_unit_reference.py`: незалежний Decimal із 60 цифрами, 1 lb = 0,45359237 kg, 1 ft = 0,3048 m та стандартне g = 9,80665 m/s². Для ненульових чисел лише відносний допуск 2·10⁻¹⁴, без абсолютної поблажки для малих значень.
- `tests/transport-units.test.mjs`: сумісність старих налаштувань, фізичні розмірності, недоступні величини, усі повні табличні набори й друк.
- `scripts/check-steam97-p09-units-browser.cjs`: обидві моделі, всі нові одиниці, SI/English, копіювання й CSV, чотири формати з незалежними читачами, JSON/перезавантаження, мови й 320/390 px, автономний HTML та PWA без мережі.
- Повне програмне ядро приймання та регресія попереднього P08. Точні результати, збірка й хеші наведені у [машинному звіті](STEAMTABLES_P09_UNITS_ACCEPTANCE.json).

Приймання виконане на Node 22 з CI та закріпленій у CI Playwright 1.64.1. На початковому Node 24.19.0 відтворено стару відмову IAPWS-95 у тесті dry-saturated-inlet циклу Ренкіна, зокрема на незміненому попередньому коміті; це окрема невирішена залежність числового алгоритму від runtime. Початковий Firefox 153/Playwright 1.62.1 аварійно завершив вкладку під час офлайн-PWA; цей прогін не враховується як прийнятий. Точні прийняті версії браузерів містить машинний звіт.

Цей аудит перевіряє перетворення вже розрахованих канонічних станів. Він не є новою незалежною перевіркою рівнянь стану або прямим числовим порівнянням з оригіналом.

## Що залишається до повного аналога

Нових числових відповідей чи файлів Steam97Web не отримано. Публічна довідка доступна; інструмент підключеного інтерактивного браузера відсутній, а домен не дозволений мережевою політикою виконавця. Тому **повний P09 не прийнято**. Дев’ять блокерів [реєстру P01](steam97-p01/blockers.json) залишаються відкритими:

- B01–B03: живі приклади, повний селектор насичення та приховані/реєстраційні поля.
- B04–B05: формули, коефіцієнти, базиси й нулі газової моделі BSW2003 та дисоціації. Наявна NASA-модель не оголошується її еквівалентом.
- B06–B07: фактичні розширені межі й кореляції оригіналу, базис ексергії.
- B08–B09: реальні файли експорту та точна геометрія/керування паровою h–s.

Для закриття потрібен доступ до реального інтерфейсу або збережені його входи, модель, одиниці, результати й файли. Локальні тести не замінюють цих доказів. Публікація цієї підзадачі — окремий крок; її завершення не змінює статус невідомих контрактів.
