## Перший запуск

Відкрийте https://lamerroma.github.io/water-steam-if97/ з інтернетом. Панель «Встановлення та офлайн» над калькулятором показує підготовку й кількість завантажених ресурсів. Після перевірки всіх файлів з'явиться повідомлення про готовність поточної версії офлайн. Основний кеш містить базовий набір: математичні ядра, CoolProp WASM, діаграми, всі розділи й обидві мови. Вбудовані в JavaScript IF97 та IAPWS-95 також зберігаються.

Тепер можна вимкнути мережу, закрити браузер і відкрити ту саму адресу або встановлену програму. Розрахунки, діаграми, імпорт проєкту та локальні експорти працюють офлайн. Зовнішні посилання на джерела потребують інтернету. Однофайлового застосунку більше немає; автономні HTML-звіти залишаються форматом експорту результатів.

Після обриву чи помилки з'являється «Повторити завантаження». Підключіться до мережі та повторіть. Статус готовності не з'являється для часткового або пошкодженого комплекту.

SheetJS для XLSX/ODS/XLS входить до основного кешу, але виконується тільки
під час першого експорту в ці формати. CSV не запускає цю бібліотеку.
Додаткової підготовки понад основний статус PWA для таблиць не потрібно.

## Додаткові бібліотеки ht / fluids

Відкрийте «Теплообмін і гідравліка» → «Бібліотеки ht / fluids» і підготуйте окремий
пакет (~32 МБ). Тільки після його власного статусу готовності бібліотеки працюють
офлайн, включно з новим запуском браузера. Базовий статус PWA не включає цей пакет.
Повний ZIP уже містить його файли: підготуйте пакет до зупинки локального сервера.
Видалення пакета через панель звільняє його кеш, зберігаючи проєкти.
[Інструкція й обмеження](PYTHON_LIBRARIES_UK.md).

## Перший локальний запуск без інтернету

Повний ZIP із `npm run package` містить усі ресурси та `serve.py`. Розпакуйте його, виконайте `python serve.py` (у Windows також `py -3 serve.py`) і відкрийте **http://localhost:8080/**. Потрібен Python 3; додаткові пакети не потрібні. Сервер лише віддає файли, розрахунки виконує браузер. Після статусу готовності офлайн сервер можна зупинити й повторно відкривати ту саму адресу або встановлену програму. Зберігайте ту саму адресу й порт. У разі очищення кешу знову запустіть сервер. Відкриття через `file://` не підтримується.

## Встановлення

- Chrome / Edge на ПК та Android: кнопка «Встановити програму», якщо браузер її пропонує, або встановлення через меню браузера.
- Safari на iPhone / iPad: «Поділитися» → «На початковий екран».
- Якщо встановлення недоступне, користуйтеся PWA у вкладці браузера. Готовність офлайн перевіряється окремо від установки.

Наявність кнопки й назви пунктів меню залежить від платформи та браузера. Автоматичні перевірки виконано у Chromium на ПК та з мобільним розміром екрана; встановлення на фізичних Android/iOS-пристроях у цьому спринті не перевірено.

## Оновлення

Коли новий комплект завантажено й перевірено, панель показує «Доступне оновлення» та кнопку «Оновити програму». Натискання зберігає поточний проєкт і перезавантажує сторінку з новою версією. Якщо локальне збереження не працює, оновлення блокується з поясненням: спочатку експортуйте JSON. Після закриття всіх вкладок браузер також може автоматично активувати вже підготовлену версію.

Кнопка «Перевірити оновлення» одразу запитує сервер, не чекаючи, поки браузер перевірить оновлення сам. Якщо нова версія є, програма завантажує й перевіряє весь комплект, зберігає проєкт і перезавантажується з новою версією. Якщо нової версії немає, панель показує «Встановлено останню версію». Без інтернету кнопка повідомляє, що перевірити неможливо, а програма працює далі офлайн.

Кожна збірка має свій кеш; файли перевіряються за SHA-256. WASM має URL з ідентифікатором збірки. Старі кеші зберігаються для відкритих вкладок; при активації без відкритих клієнтів непотрібні кеші очищуються. Очищення кешів не видаляє localStorage чи JSON-проєкти.

Браузер може очистити кеш і локальні дані. Зберігайте резервні JSON-копії. Якщо кеш відсутній, при відкритті з'явиться сторінка відновлення: підключіться до мережі й натисніть «Відновити». Якщо локальні дані залишилися, проєкт відновиться. Видалені самим браузером дані можна повернути з JSON-копії.

Відновлення завантажує та перевіряє повний комплект файлів, після чого повертає до калькулятора. Поки триває завантаження, кнопка недоступна. Якщо мережі немає або завантаження не вдалося, з'явиться повідомлення й можливість повторити спробу. Проєкт і вибрана мова зберігаються; після успішного відновлення калькулятор знову працює офлайн.

## Перевірки розробника

```
npm run build
npm test
npm run test:pwa
```

Для Playwright можна задати `PLAYWRIGHT_MODULE_PATH`, `PLAYWRIGHT_BROWSERS_PATH` і `CHROMIUM_PATH`. Перевірка Firefox: `BROWSER_NAME=firefox npm run test:pwa`. Сценарій запускає власний сервер зі шляхом `/water-steam-if97/` й тимчасовий профіль браузера. Перевіряються повний кеш, мови, екран 390 px, повторний запуск без мережі, IAPWS-95, реальний газ CoolProp, діаграма, контрольоване оновлення, збереження проєкту, обрив та пошкодження ресурсу й відновлення кешу.

Service worker працює через HTTPS або localhost. Для локальної розробки після зміни файлів потрібно виконати `npm run build` і застосувати запропоноване оновлення; активна PWA показує свою перевірену збірку.

Механізм встановлення й життєвий цикл описано в [MDN: installable PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) та [MDN: Service Workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).

## Архітектура й розширення

[Архітектура PWA](PWA_ARCHITECTURE_UK.md) описує основний кеш та додатковий пакет Pyodide/ht/fluids. Історичні звіти зі згадкою одного HTML описують попередні збірки.

Порівняння трубопроводу з fluids: підготуйте Python-пакет, потім у формі
гідравліки виберіть Clamond або Colebrook. Входи й обидва результати експортуються
в CSV/JSON; перезапуск офлайн підтримано. [Контракт](FLUIDS_PIPE_UK.md).
