# Інтерфейс і офлайн-робота — 1.16.8

Перевірка на Linux у Chromium 151.0.7922.34 та Firefox 153.0 через Playwright 1.62.1. Firefox використовується для перевірки вебінтерфейсу й Service Worker; це не підтвердження можливості встановлення PWA через меню Firefox.

## Що перевіряється

- Розрахунок p–T, десяткова кома, помилки введення, перемикання UK/EN і збереження власної назви проєкту.
- Англійські HTML-звіти, JSON експорт → імпорт → перезавантаження; історія й введені дані зберігаються.
- Усі 28 розділів на ширинах 320, 390 і 768 px; масштаб інтерфейсу 130%. Сторінка не має горизонтального зсуву. Широкі таблиці мають локальне прокручування.
- Схема АЕС, вибір стану, розгортання й Escape, відображення чисел таблиці без розбиття на рядки; T–s графік і HTML-звіт; обробка лабораторного прикладу.
- Повний офлайн-кеш, запуск після закриття браузера, IAPWS-95, WASM-модуль газів, графіки та їхній експорт без мережі.
- Оновлення на змодельовану наступну версію. Якщо збереження проєкту блокується переповненим сховищем, версія не змінюється. Після усунення помилки оновлення зберігає проєкт і мову.
- Стара відкрита вкладка зберігає свої ресурси; перерване завантаження й пошкоджений ресурс не залишають частковий кеш; повторне завантаження та відновлення видаленого кешу зберігають проєкт.

Основні поля й кнопки на телефоні збільшено до 44 px. Виправлено англійський текст припущень про перший контур. Знімки екрана калькулятора, АЕС і діаграм зберігаються разом із журналом перевірки.

## Відтворення

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install --with-deps chromium firefox
npm run verify:release -- --browser-only
```

Для окремого сценарію інтерфейсу запустіть локальний сервер (`npm run serve`), потім `npm run test:cross-browser`. Офлайн-сценарій має власний сервер на порту 8091: `npm run test:pwa`, далі `BROWSER_NAME=firefox npm run test:pwa`. Ці два офлайн-запуски виконуються послідовно.

## Межі

Це браузерне приймання. Фізичний статус моделей ним не змінюється; повне числове приймання 1.16.7 збережене в `RELEASE_ACCEPTANCE.json`. Актуальний протокол інтерфейсного спринту має режим `browser` і зберігається окремо в `UI_OFFLINE_ACCEPTANCE.json`.

Реальний Android/iPhone, Safari, жести на фізичному сенсорному екрані та встановлення через системне меню телефона не перевірено. Мобільні розміри в браузері не підмінюють таку перевірку. GitHub Actions для нових змін виконає весь набір після пушу.
