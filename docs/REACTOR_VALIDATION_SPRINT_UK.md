# Перевірка реакторної методики — 1.20.0

## Результат

Метод обчислень залишається `reactor-course-4`, нейтронні рівняння — `reactor-course-3`. Додано `reactor-evidence-1`: відтворювані числові перевірки та їх відображення у програмі й записці. Підтверджено арифметичну узгодженість усіх 45 варіантів із типовою моделлю IF97. **Фізичну нейтронну перевірку не пройдено.** Зелений статус балансу рівнянь не означає підтвердження фізичної точності.

## Розбір розбіжності

| Випадок | Крок, см | Температура, °C | Наш k | Експериментальний k | Δk | Походження входів |
|---|---:|---:|---:|---:|---:|---|
| p2w2b0t2 | 1,27 | 80 | 1,11406123 | 1 | +0,11406123 | Раніше переписаний офіційний файл |
| p2w2b0t3 | 1,27 | 130 | 1,10588972 | 1 | +0,10588972 | Раніше переписаний офіційний файл |
| p1w2b0t2 | 1,10 | 80 | 1,07236303 | 1 | +0,07236303 | Реконструйована комірка |
| p1w2b0t3 | 1,10 | 130 | 1,05677798 | 1 | +0,05677798 | Реконструйована комірка |

Експериментальні k та наведені похибки взято з [IAEA WIMS-D Library Update, табл. 14.9, друкована с. 82](https://www-pub.iaea.org/MTCD/Publications/PDF/Pub1264_web.pdf); крок, геометрію та B² — також із [опису ZR-6](https://www-nds.iaea.org/wimsd/wwer.htm) і додатка IV.3. Числа нашої моделі отримано локальним запуском, а не взято з публікації.

Первинні два входи звіряються з попереднім JSON та незалежним адаптером: площі, концентрації, температури, см⁻² → м⁻². Їхній результат залишився незмінним. У додаткових випадках площу еквівалентної комірки отримано як √3 S²/2; склад води без бору при тій самій температурі повторно використано з початкових випадків. Виміряні B² 64,02 та 59,76 м⁻² задані прямо, без вигаданого поділу на радіальну й осьову складові.

Офіційний `wwercrb.win` під час цього спринту повертав HTTP 403. Тому додаткові випадки **не названі точним відтворенням файла**; їхні припущення записані у JSON. Вони не замінюють початкові еталони й не розширюють підтверджений фізичний діапазон.

Залежність розбіжності від кроку та температури відтворюється, але цих порівнянь недостатньо для однозначного визначення причини. Сталі перерізи, резонансна апроксимація, сповільнення, витік та пропущені ізотопи залишаються можливими складовими помилки. Попередній [розбір рівнянь](REACTOR_MODEL_REVIEW_UK.md) зберігає чинність. Для розділення причин потрібен незалежний транспортний розрахунок із повним складом і відповідними ядерними даними; єдиного поправкового множника не введено.

Наведена у IAEA похибка k використовується як окремий числовий інтервал порівняння, без трактування її як стандартного σ. Попередня ціль 1% збережена окремо у протоколі двох початкових випадків; усі чотири порівняння не проходять і своїх інтервалів. Випадки 21 °C не додані через нижню межу таблиць g-факторів 300 K; екстраполяції немає. Боровані решітки не перевірені.

## Теплогідравліка та CHF

- 16 контрольних температур: чотири лінійні навантаження, чотири поверхні/центр. Входи — [INL TMAP8 ver-1m, Table 1 та аналітичний розв’язок](https://tmap8.inl.gov/docs/PRs/451/site/verification_and_validation/ver-1m.html). Еталонні числа обчислено незалежно з 60 десятковими цифрами. Це сталі властивості U-ZrH, не експериментальна перевірка UO₂. Тепловіддача 18000 W/(m² K) у джерелі є оцінкою; контакт 7381 використовується як площинна провідність W/(m² K).
- 3 перевірки CHF: локальні p, G, x із [AbdulHameed et al., Table 10, формула (53)](https://arxiv.org/html/2203.15048). Очікувані числа — високоточне обчислення кореляції, **не виміряні CHF**. Перехід 795 kW/m² → 0,795 MW/m² явний.
- Для поточного результату перевіряються рівняння балансів і шарів у гарячому та середньому профілях, збереження нормування профілю та сума перепадів тиску. CHF звіряється з еквівалентним записом показника 0,184−0,311x. Кандидат 1.15.0 не оголошується підтвердженою кореляцією.
- Задані множники профілю потужності та підігріву гарячого каналу залишаються незалежними навчальними входами. Перевірка кожного рівняння не встановлює узгоджений баланс одного фізичного гарячого каналу.

Числові допуски перевірок задані явно у формі `atol + rtol·|expected|`; це допуски програмної верифікації. Невизначеність матеріальних поліномів, застосовність кипіння та CHF до довільної геометрії з них не випливає. [Попередня теплова перевірка](REACTOR_THERMAL_REVIEW_UK.md) та її відкриті питання залишаються чинними. Поправки нагрітої довжини, форми потужності й решіток не додані без окремого обґрунтування.

## Як користуватися

Курсова ЯЕР → «Розрахувати» → «Контрольні перевірки: рівняння, приклади та експеримент». Перегляньте отримане число, еталон, допуск і відхилення; у наступній таблиці — формулу, підстановку та джерело. «JSON протоколу перевірок» зберігає входи, модель, версію збірки та результати. HTML-записка включає ці самі таблиці; вона працює без мережі. Помилкове введення прибирає попередній результат разом із протоколом.

```sh
npm run audit:reactor:validation -- --write-report
npm run audit:reactor:validation -- --physical  # очікується код 1: фізична перевірка не пройдена
npm run test:reactor-validation
```

[Машинний протокол усіх варіантів і контрольних прикладів](REACTOR_VALIDATION_1_20.json). Погодження викладача не є залежністю цієї перевірки. Приватні матеріали у репозиторій не копіюються.
