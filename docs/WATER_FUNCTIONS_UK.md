# Функції води й пари

Розділ **Властивості → Функції** обчислює властивості води й пари як функції з
іменованими аргументами. Це власний функціональний аналог бібліотек властивостей
для електронних таблиць і математичних пакетів (на кшталт WaterSteamPro): ті самі
ядра IAPWS-IF97 та IAPWS-95, що й в основній формі, без зовнішніх DLL.

## Синтаксис

Кожен рядок — одна формула. Рядки з `#` або `//` — коментарі.

```
h(p=10 бар; t=250 °C)            # ентальпія в точці
s(h=3000; p=1)                   # будь-яка підтримувана пара аргументів
h(t=100; x=1)                    # насичена пара
h0 = h(p=10; t=550)              # змінна
h2 = h(p=10; t=550; p2=0.005; eta=0.85)   # стан після розширення з ККД
N = h0 - h2                      # арифметика з попередніми змінними
cp(p=1; t=100..300 step 50)      # діапазон → таблиця значень
h(p=1; t=150; region=2)          # примусова область IF97 (екстраполяція)
pKw(p=25; t=300; model=IAPWS-95) # інша формуляція для одного виклику
```

- Аргументи розділяються `;`, десятковий розділювач — кома або крапка.
- Без одиниці використовується базова: МПа, °C для `t`, K для `T`, кДж/кг,
  кДж/(кг·K), кг/м³, м³/кг, частка для `x` та `eta`, мкм для `wl`.
- Підтримувані пари стану: p–t, p–h, p–s, p–x, t–x, h–s, t–h, t–s, p–ρ, t–ρ,
  p–v, t–v, p–u, t–u, u–s, v–s, h–v, u–v.
- Функції лінії насичення (`psat`, `tsat`, `Tsat`, `r`, `dpsdt`, а також `sigma`)
  приймають один аргумент `p` або `t`.
- Арифметика (`+ - * / ^`, `sqrt`, `exp`, `ln`, `log10`, `abs`) не перевіряє
  розмірності: числа беруться в базових одиницях результатів.
- У рядку дозволено один діапазон `від..до step крок` (або `крок`); без кроку
  діапазон ділиться на 10 інтервалів, максимум 1000 точок.

Повний перелік функцій, аргументів і одиниць є в довідці внизу розділу.

## Нові властивості

| Функція | Величина | Джерело та межі |
| --- | --- | --- |
| `pKw` | −lg Kw, іонний добуток води | IAPWS R11-07(2019): 273,15…1273,15 K, p ≤ 1000 МПа |
| `nD` | показник заломлення (за замовчуванням λ = 589,29 нм, аргумент `wl`) | IAPWS R9-97: 261,15…773,15 K, ρ ≤ 1060 кг/м³, 0,2…1,1 мкм |
| `drhodh` | (∂ρ/∂h)p = −ρα/cp; для суміші −ρ²·Δv/Δh | похідні обраної формуляції |
| `drhodph` | (∂ρ/∂p)h = ρ(κT − α·μJT) | однофазний стан |
| `dpsdt` | dpₛ/dT за Клапейроном–Клаузіусом | насичені стани й двофазна суміш |

Ці величини також показуються в основній таблиці «Вода та пара», експорті та
англійських одиницях. Для IF97 нахил dpₛ/dT обчислюється з властивостей фаз і
відрізняється від похідної рівняння області 4 не більше ніж на ~3·10⁻⁴ біля
критичної точки (до 10⁻⁵ при помірних температурах).

## Обмеження

- Примусова область працює лише з `p` і `t` у IF97 (області 1, 2, 5) і дає
  основні термодинамічні величини; поза межами області це екстраполяція.
- Розширення `p2`/`eta` використовує ізентропний ККД 0 < eta ≤ 1 і не
  поєднується з примусовою областю.
- Надбудови для Excel, Mathcad чи інших пакетів не входять до цього етапу.
