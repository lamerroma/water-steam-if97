# P05 — наукові діапазони та транспортні властивості

Кандидат **1.35.6**. Незалежну частину спринту виконано: виправлено локальні N03/N04, побудовано [карту допустимості](steam97-p05/validity-map.json). Повне приймання відповідності Steam97Web залишається відкритим через B01/B03/B06. Нових числових відповідей оригіналу немає; показник повноти не обчислюється.

База — локальний коміт P02 `8f85659`, версія 1.35.5. Його звіти збережено без змін. P01 раніше відправлено в main як `175a98c`; нові P02/P05 не опубліковані. Історичні перевірки цілісності P01/P02 прив’язані до своїх версій; поточний кандидат перевіряється `node scripts/verify-steam97-p05.mjs`.

## Що виправлено

**N03.** IAPWS-95 раніше відхиляв будь-яку температуру нижче 273,16 K. Тепер стійка стиснена рідина допускається за кривими плавлення Ih/III/V/VI. Для температур нижче потрійної точки перевіряються нижній і верхній тиски рідкої області. Найнижча температура кривої — 251,165 K; це не прямокутний діапазон для будь-якого тиску. Межа плавлення виключена, лід не обчислюється. Газ нижче потрійної точки та метастабільна рідина не додаються як неявна екстраполяція.

Нижня температура P–h/P–s/P–u і сіток P–v/P–ρ залежить від тиску. Для фіксованої температури додано точки з обох боків кривих плавлення. Для u–s/v–s/h–v/u–v пошук знаходить край допустимого інтервалу та уточнює обидва входи зі стартів на рідкому боці межі. Це закриває вузькі інтервали, які пропускала груба сітка. h–s використовує той самий новий нижній діапазон і перевіряє фазу прямим рівнянням.

**N04.** Спільне обмеження μ/λ при 100 МПа замінено незалежними межами двох формуляцій. Кожний інтервал тиску відкритий зліва та замкнений справа; p > 0. Знизу потрібен стійкий флюїд вище плавлення, а для пари при p нижче потрійної точки — T ≥ 273,16 K.

| Величина | Верхній тиск інтервалу, МПа | Верхня T, K |
|---|---:|---:|
| μ | 300 / 350 / 500 / 1000 | 1173,15 / 873,15 / 433,15 / 373,15 |
| λ | 100 / 250 / 687 / 785 / 1000 | 1173,15 / 874 / 573 / 403 / 348 |

Теплопровідність іноді допустима там, де μ вже поза власним діапазоном. R15-11 потребує кореляції в’язкості як допоміжної величини; це не робить її доступною як валідовану μ. ν потребує доступної μ; температуропровідність — λ; Pr — обох. Для двофазної суміші транспортні величини не усереднюються.

Сумісність старих проєктів: збережений представник числової групи u–s може відрізнятися від нового результату пошуку. Якщо звичайне зіставлення не підходить, стан заново обчислюється за збереженим тиском та незалежним входом; потрібні узгодженість обох початкових входів і той самий числовий кластер за якобіаном. Повертається новий обчислений представник. Правило застосовується до історії та ручного вибору кореня; підроблені тиски відхиляються, глобальні допуски не збільшено.

Форма приймає холодну стійку рідину та зберігає вищу нижню межу для насичення рідина–пара. Оновлено довідку UK/EN. Недоступне значення залишається порожнім у CSV, поруч додається рядок `<property>_unavailable_reason`; інтерфейс показує пояснення з верхньою температурою саме за поточного тиску.

Еталони створює `scripts/generate-steam97-p05.py`, який не імпортує продукт: Python iapws **1.5.5**, CoolProp HEOS **8.0.0**. 259 станів охоплюють звичайні режими, рідину біля плавлення, усі сходинки μ/λ з обох боків і на межах, верхню T IAPWS-95 та кілька критичних околиць. Максимальна відносна різниця двох бібліотек у цій сітці — **6,84·10⁻⁹**. Це числова узгодженість реалізацій, а не невизначеність вимірювань.

Python iapws видає загальне попередження `Using extrapolated values` для T < 273,16 K; його збережено в еталоні. Допустимість конкретного стану підтверджується R6-95/R14-08. Біля переходу льоду V/VI автоматична перевірка плавлення CoolProp відрізняється від R14-08; після незалежної перевірки рідкої області для холодних точок явно задано рідку фазу HEOS. Ця обставина записана в кожному відповідному еталоні.

Допуски зафіксовано у fixture до перевірки продукту: відносний 2·10⁻⁷ із заданими абсолютними межами; для незалежних зворотних станів — 2·10⁻⁶ МПа і 2·10⁻⁶ K. Кожний повернутий корінь додатково перевіряється за обома входами й термодинамічною стійкістю незмінною політикою попереднього аудиту.

## Межі приймання

Первинні джерела: [R6-95, §5](https://iapws.org/technical-guidance/release/IAPWS-95.download), [R14-08, рівняння 1–4](https://iapws.org/technical-guidance/release/MeltSub.download), [R12-08, §2.4](https://iapws.org/technical-guidance/release/viscosity.download), [R15-11, §2.4](https://iapws.org/public/documents/w-mwl/ThCond.pdf), [R8-97](https://iapws.org/technical-guidance/release/Dielec.download), [R1-76](https://iapws.org/technical-guidance/release/Surf-H2O), [IF97](https://iapws.org/technical-guidance/release/IF97-Rev). Карта охоплює всі десять вимог власника P05; межі IF97, діелектрична проникність та поверхневий натяг не розширювалися.

Сингулярна точна критична точка IAPWS-95 залишається відмовою. Обмеження самої формуляції для вищих похідних в її найближчій околиці зберігаються. Скінченна сітка та браузерні сценарії не є доказом усіх станів континууму. Не повторювали всі сторонні браузерні розділи програми.

Ширші заяви допомоги Steam97Web про 5000 K / 100000 МПа потребують окремого контракту екстраполяції та прямих результатів сайту. B06 не закритий науковою картою. P03/P04 також очікують газові коефіцієнти та визначення дисоціації B04/B05; наступна незалежна робота — підтверджена частина P06, турбіна/flash.
