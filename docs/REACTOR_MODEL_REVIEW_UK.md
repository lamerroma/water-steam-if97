# Розбір нейтронної моделі — 1.16.4

**Виправлено три неузгодженості рівнянь. Фізичну перевірку IAEA ще не пройдено.** Формули змінювалися за оригіналом методички та умовами збереження числа атомів і швидкостей реакцій; коефіцієнти не підбиралися під критичність. Методика нових розрахунків — `reactor-course-3`.

## Підтверджені виправлення

### 1. Дифузійна площа води

У §4.3 методички перед транспортним перерізом води наведено формулу:

```
Lвод² = (2,72/ρвод)² · (Tвод/293,15) · 1,0614 / [1 + 0,0614√(Tвод/293,15)]
```

Tвод у K, ρвод у г/см³, результат у см². Раніше реалізація використовувала сталу `27.62`, взяту з числового прикладу. Тепер застосовується формула з температурою теплоносія; температура нейтронного газу не підставляється замість неї.

Оригінал перевірено за вбудованим зображенням формули `image73.wmf`; підстановку — за `image74.wmf`. Повні приватні документи викладача в репозиторій не копіюються. Підстановка 575 K і 0,722 г/см³ за формулою дає приблизно 27,21 см², а не надруковані 27,62. Числовий приклад не використовується для зміни коефіцієнтів.

### 2. Поглинання усередненої зони

Для зони води, металу та зазору визначено:

```
Σa1 = (Vвод·Σaвод + V₂·ΣaZr)/(Vвод + V₂)
```

Раніше далі ця усереднена величина множилася лише на Vвод. Це втрачало частину інтегрального поглинання. Тепер у відношенні поглинань використовується повний об'єм зони Vвод+V₂. Визначення θ як частки поглинання в паливі та облік Σa·Φ·V для всіх матеріалів зіставлено з [DOE-HDBK-1019/2-93, Module 3, друкована с. 5 / PDF с. 26](https://www.osti.gov/servlets/purl/10144945). Це обґрунтовує облік об'ємів, а не підтверджує всі емпіричні поправки нашої моделі.

Кінетичну поправку δ з методички залишено окремим доданком. Просторова форма потоку та граничні наближення залишаються предметом подальшої фізичної перевірки.

### 3. Резонансне поглинання цирконію

Концентрація NZr уже усереднена за об'ємом металу та газу:

```
NZr = NZrметал · Vметал / V₂
```

Її повторне множення на Vметал давало подвійне зменшення кількості атомів. Тепер у показнику експоненти використовується NZr·V₂ = NZrметал·Vметал. У тепловому поглинанні й сповільненні вже застосовувався об'єм V₂, тому це також усуває неузгодженість між складовими однієї моделі.

## Перевірені припущення, які не змінено

- Позначення c у методичці для поправки Данкова відповідає ймовірності зіткнення у сповільнювачі, тобто доповненню звичайного фактора C. У коді збережено історичне поле `dancoff`; додано явне `dancoffFactor=1−c`. Заміна c на 1−c у формулі затінення не виконувалася: це змінило б прийняту конвенцію, а не виправило її.
- Фактор Белла, інтеграл U-238 за Гуревичем–Померанчуком, сталі перерізи, коефіцієнт резонансного відтворення 1,6 та емпіричний вік нейтронів не підганялися.
- Дані IAEA, виміряний B², геометрія та критерії приймання залишилися такими самими. Незадані U-234/Nb/Hf і багатогрупові дані не замінювалися вигаданими числами.

## Діагностика чутливості

Актуальний JSON окремо показує теплову й резонансну складові k∞, Lвод², ймовірності поглинання та ілюстративні відхилення I₈, τ і L² на ±10%. Центральна точка кожного відхилення відтворює основний результат. Ці відхилення **не є похибками джерела чи інтервалами фізичної невизначеності**; пошуку значень, що дають k=1, немає.

Наприклад, збільшення I₈ на 10% зменшує k першого випадку приблизно на 0,0246, а другого — на 0,0254. Це показує чутливість до резонансної апроксимації, але не доводить, що саме вона спричинила всю розбіжність. З наявних двох експериментів неможливо однозначно визначити правильну заміну емпіричних коефіцієнтів.

## Що потрібно для наступного фізичного підтвердження

Потрібен незалежний транспортний розрахунок з повним складом еталонів, оціненими ядерними даними, температурною обробкою резонансів та розсіянням водню у воді. Варто порівнювати не лише k, а й реакційні швидкості та спектральні показники, щоб розділити джерела розбіжності. Далі — інші кроки решітки, збагачення й концентрації бору за незмінними критеріями.

До цього моменту нейтронний модуль, кампанія й керування залишаються навчальними дослідними оцінками. Повторне обчислення старих входів може змінювати результати; новий номер методики та пояснення містяться у записці.
