# Порівняння станів та повторні розрахунки — 1.22.0

Спринт розширює журнал основного калькулятора. Нова вкладка не додається: вибір і копіювання доступні біля записів; порівняння відкривається в діалозі.

## Розрахунок і дані

Порівнюються 2–5 станів, включно з різними моделями IF97/IAPWS-95. База — один із вибраних записів. Для 13 властивостей показано значення, Δ = стан − база та Δ % = 100(стан − база)/|база|. Відсотки використовують канонічні властивості: K та абсолютний тиск. Зміна показу °C/°F або манометричного тиску не змінює відсоток. Температурна різниця перетворюється без зсуву шкали. За нульової/відсутньої бази відсоток не визначається; відсутні властивості не замінюються нулями.

Налаштування температури, тиску й енергії беруться з панелі одиниць на момент відкриття; інші властивості мають явні SI-одиниці. Манометричний показ враховує збережений атмосферний тиск, який фіксується разом із видом тиску. CSV і блок навчального звіту використовують цей самий набір даних.

Блок звіту незалежний від подальших змін історії: зберігає назви, моделі, канонічні входи кожного стану, p/h для вибору гілки оберненого розрахунку, базу та одиниці. Імпорт перевіряє дані і повторно обчислює стан. Довільні готові результати з JSON не приймаються. Початкові дані з одиницями, назви й формули включено до HTML-звіту. Для A4 кожен стан має окрему таблицю з п’ятьма стовпцями замість однієї надширокої таблиці. CSV екранує лапки, а текстові заголовки, що починаються з формульних символів таблиць, мають захисний апостроф.

## Робочий сценарій

Назви задаються в журналі; доступні підказки типових точок. Наявні діаграми продовжують використовувати назви журналу. Новий блок порівняння переносить їх у звіт.

Дія ✎ відновлює незалежні входи, залишає початковий запис і пропонує змінити параметри. Після успішного розрахунку з’являється новий запис із назвою-копією; помилковий розрахунок не додає запису. Звичайне ↗ та видалення з можливістю скасування залишаються доступними.

Вибір станів тимчасовий: зберігається при додаванні нового запису, зміні мови та одиниць; видалені записи виключаються, reload/імпорт скидає вибір. Сам блок звіту зберігається в JSON-проєкті. На телефоні таблиця прокручується всередині діалогу, назви властивостей закріплені; Esc повертає фокус.

## Перевірка

- `tests/state-comparison.test.mjs`: температурні зсуви й різниці, абсолютний/манометричний тиск, інша база, нульова сухість, недоступні властивості, перевірка входів, різні моделі, CSV та екранування HTML.
- `npm run test:state-comparison`: повний шлях від початкового стану й копії до порівняння, CSV, блоку звіту, перегляду, JSON і повторного відкриття; обмеження 5 станів, скасування очищення, мобільний діалог та автономний файл без мережі.
- Загальне приймання запускається через `npm run verify:release`; його фактичний результат записується в `RELEASE_AUDIT_UK.md` та `RELEASE_ACCEPTANCE.json`.

Реакторна курсова залишається «У розробці». Ядра фізичних моделей та методи побудови графіків цим спринтом не змінюються.
