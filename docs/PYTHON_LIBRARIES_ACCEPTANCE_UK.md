У першому додатковому запуску чотири P03/P04 сценарії не знайшли `python3`
(Windows exit 9009). Їх повторено з `P03_PYTHON` / `P04_PYTHON`, які вказують
на наявний `.release/pwa-test-venv/Scripts/python.exe`: усі чотири пройшли.
Це виправлення середовища запуску перевірки; числовий код через нього не змінювали.
Оригінальні статуси першої спроби збережено окремо, а не переписано.

Обидва браузери перевірили окремий кеш і completion marker, холодне скасування
Worker з повторним стартом, каталог зі збереженням чутливості UI, функції й
класи, NumPy-масиви та експорт JSON. Профіль закривали; сервер відключали;
новий браузерний сеанс ініціалізував Python і обидві бібліотеки з кешу.
Екран 390 px не мав горизонтального переповнення. Видалення кешу виявлялося,
проєкт залишався; повторне завантаження відновлювало роботу. Пошкоджений wheel
відхилявся, частковий кеш видалявся, повторна підготовка проходила.

Перші два числа — контрольні виходи підключених зафіксованих бібліотек.
Це перевірка інтеграції та узгодженості між браузерами, не незалежний фізичний
еталон для всіх кореляцій. Для TANK додатково використано аналітичний об'єм циліндра.

Недоступні в обох каталогах: `numba`, `numba_vectorized` (немає Numba),
`units` (немає Pint). Решта записів не вважається чисельно прийнятою лише
через успішний імпорт. Потрібні окремі матриці функцій, одиниць і областей
застосування. Відповідність Steam97Web залишається непідтвердженою.
Чинна невдала фізична перевірка дослідної нейтронної моделі, позначена в core
report, не перетворюється на успішну валідацію через проходження software-тестів.
