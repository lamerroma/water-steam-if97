# Точність зворотних розрахунків — спринт 1.35.3

## Протокол перевірки

База порівняння — опублікована 1.35.2, коміт `ff7c663`. Еталони генеруються
без імпорту JavaScript продукту: IF97 — Python iapws 1.5.5, IAPWS-95 —
CoolProp 8.0.0 HEOS для звичайних станів із вибірковою перехресною перевіркою
Python IAPWS95. Усі 20 критичних станів IAPWS-95 і 4 IF97 при Pc обчислено
незалежними рівняннями на 70/90 цифрах, зі збігом краще за 1e-25 відносно.
Високотемпературні насичені кінці IF97 також уточнено на 70/90 цифрах.
Для насичення перехресна перевірка виконується при тій самій температурі:
це усуває вплив грубішої зворотної процедури P→T сторонньої бібліотеки.

Сітка містить 2200 різних станів (1700 IF97, 500 IAPWS-95), звичайні точки,
межі області, насичені суміші та критичний окіл. 4657 запитів охоплюють
усі 15 зворотних режимів. Випадкова частина відтворюється seed=13503.
Для B23 і 1073,15 K перевіряються обидві сторони, зокрема вузькі інтервали.
Точна сингулярна критична точка й відомі неузгодженості областей IF97
не підмінюються розв'язками іншої фізичної моделі.

У критичному наборі є розбіжності CoolProp/Python за h/s/u. Вибір еталона
перевірено multiprecision-кодом, який не імпортує продукт: Python IAPWS95
при тих самих T/ρ збігається з ним краще за 5e-14 відносно. Початкові
розбіжності з CoolProp збережено у `criticalChecks` fixture; це не зараховано
як помилки продукту й не «виправлялося» під відповідь іншої бібліотеки.

Для порівняння з 1.35.2 використовується **4441 однаковий запит** по всіх
2200 станах і всіх 15 режимах. Додаткові 216 складених запитів us/vs/hv/uv
для сумішей перевіряються за незалежними еталонами в новій версії; повільний
повний старий запуск для них не є частиною порівняння до/після.

Перевірка вимагає одночасного виконання обох вхідних рівнянь, відновлення
p/T та правильної фазової ознаки. Якщо є кілька коренів, еталонний стан має
бути серед явно повернутих альтернатив. Один збіг вхідних властивостей без
правильного стану недостатній.

Допуски зафіксовані до виправлень у `scripts/audit-inverse-precision.mjs`:
залишки входів — 2e-9 відносно з абсолютними порогами залежно від одиниць;
відновлення T — 2e-5 K, p — max(1e-9 MPa, 2e-7 p). Для погано обумовлених
однофазних пар додатково обчислюється поширення оголошеної похибки еталонного
входу через аналітичний термодинамічний якобіан. Це не експериментальна
точність водяної моделі й не універсальна гарантія поза перевіреною сіткою.

## Реалізація

- На розрізах B23 і 1073,15 K додано послідовні близькі точки з обох боків.
  Це враховує округлення коефіцієнтів прямого/зворотного B23 та знаходить
  також альтернативний корінь області 5 у малому перекритті рівнянь.
- Критерій завершення IF97 та IAPWS-95 враховує зміну властивості на машинний
  крок T через її аналітичну похідну. Стійкий критичний розв'язок більше не
  відхиляється через недосяжний абсолютний залишок.
- P–h/P–s/P–u IAPWS-95 використовують захищений крок Ньютона всередині
  фазового інтервалу; при виході за інтервал зберігається бісекція.
- Уточнено залишок тиску при пошуку густини IAPWS-95, завершення h–s та
  повторну перевірку стабільного стану. Однофазний h–s шукається перед
  дорожчою двофазною рівновагою, зі збереженням перевірки стабільності.
- При низькому тиску насичення IAPWS-95 тиск обчислюється зі стійкішого
  парового кінця, без додавання похибки віднімання в рідкій фазі. Уточнено
  P→T і збережено заданий p у всіх повернутих фазах.

## Фінальна сітка нової версії

Збірка **1.35.3 / 62a81462d23c**: **4657/4657** запитів у допуску,
з них IF97 — 3439/3439, IAPWS-95 — 1218/1218. Відмов і невідповідностей
фазової ознаки на цій сітці немає. Оцінка стосується найближчого до еталона
кореня серед явно повернутих станів, а не універсального вибору першого
кореня для неоднозначної пари.

| Найбільша розбіжність відновленого стану | Значення |
|---|---:|
| p, абсолютно | 6.6685e-7 MPa ≈ 0.667 Pa |
| T, абсолютно | 8.9595e-7 K |
| ρ, відносно | 7.7441e-8 |

Ці максимуми належать різним точкам. Найбільша **відносна** розбіжність p —
8.9952e-5, для u–s рідкої води при p≈0.005173 MPa і T≈282.343 K. Ця пара
погано обумовлена: дуже малі зміни u/s змінюють відновлений p. Вона проходить
лише з явно обчисленим допуском якобіана; це не твердження про однакову
відносну точність тиску в усіх режимах. Близькі повернуті корені в межах
такої невизначеності не слід трактувати як окремі фізичні фази.

## Браузери й регресії

Повний стандартний unit-набір — **1052/1052**, з них **126 нових регресій**.
Core — **14/14**, включно з еталонами, відтворюваною збіркою, цілісністю
й відтворюваністю автономного ZIP. Усі результати отримано на збірці
62a81462d23c. Chromium і Firefox — по **32/32** сценарії,
без помилок JavaScript, однакова збірка 62a81462d23c. Перевірено всі 15
режимів у формі/Worker, B23, критичні P–h/P–s з обох боків Tc, суміш u–s,
повторення без мережі та автономний HTML.

Firefox відкриває автономний HTML як `file://`. У Chromium цей протокол
блокується політикою середовища; той самий артефакт перевірено через
локальний HTTP із подальшим вимкненням мережі. Обмеження зафіксовано в
браузерному JSON, політика браузера не змінювалася.

Стандартний core запускається на Node 22 з дозволеними дочірніми процесами.
Sandbox цього середовища повертав EPERM і втрачав обмін stdin/stdout із
Node/Python; це підтверджено мінімальними контрольними командами. Такі
запуски не є успішним прийманням. Release-скрипт тепер пише stdout/stderr
безпосередньо в журнали, які доступні під час перевірки.

Для строгого енергетичного балансу навчальних розрахунків абсолютний
критерій h/u IF97 зменшено з 2e-8 до 2e-10 kJ/kg, збережено обмеження
машинного кроку біля критичної точки. Після цієї єдиної остаточної зміни
повторно перевірено всі 3439 IF97-запитів. IAPWS-95 не використовує цей
критерій; незмінність його залежностей перевіряє фіналізатор за байтами.
