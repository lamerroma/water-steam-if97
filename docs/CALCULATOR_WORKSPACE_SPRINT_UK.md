# Основний калькулятор: результати, помилки та звіт — 1.21.0

Реакторний модуль залишається «У розробці»; цей спринт покращує щоденну роботу з основним калькулятором. Математичне ядро та бібліотека графіків не змінені.

## Поведінка

- Шість основних параметрів стану над повною таблицею. Картка копіює значення; одиницю можна включити або вимкнути. Число має поточну кількість значущих цифр, десятковий роздільник мови та не містить роздільників тисяч. Копіювання таблиці та JSON залишаються окремими діями; JSON містить канонічні числа.
- Таблиця насичення має копіювання окремо для рідини й пари. Відсутні властивості не копіюються. Недоступний/заборонений clipboard відкриває модальний діалог із виділеним текстом, Esc/закриття повертає фокус.
- Список помилок над розрахунком переходить до відповідного поля. Помилка зникає після виправлення; інші помилки залишаються. Порядок відповідає порядку полів, включно з переставленими параметрами.
- Кнопки додавання та відкриття навчального звіту є біля результатів. У журналі є окрема дія додавання обраного запису, яка бере його входи, назву та модель, не змінюючи поточний розрахунок.
- Відкриття запису використовує збережені незалежні параметри замість примусового P–h. Для старих записів без джерела використано P–x для вологої пари, P–T для критичного стану, інакше P–h. Значення виводяться в одиницях полів.
- Очищення результату та очищення історії розділені. Скасування історії залишається видимим після видалення всіх записів; стек скасування не переноситься через перезавантаження.
- Після розрахунку основні результати прокручуються у видиму область. На телефоні дві колонки карток, кнопки копіювання від 44 px та перехід до початку результату після розрахунку. Константи винесено з широкого стовпця в наявний розгортаний блок.

## Перевірка

`npm run test:calculator-workspace` перевіряє справжню сторінку: помилки та фокус, українське/англійське копіювання, відмову clipboard, відновлення історії, додавання окремого стану до звіту й попередній перегляд, очищення/скасування, reload, фази насичення, ширину 390 px та автономний файл без мережі.

`tests/calculator-result-tools.test.mjs` перевіряє числове форматування копії й відновлення збережених входів. Повний прогін приймання та його фактичні результати наведені в `RELEASE_AUDIT_UK.md` і `RELEASE_ACCEPTANCE.json`.
