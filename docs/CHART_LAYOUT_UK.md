# Компонування графіків — 1.17.1

Основні діаграми мають окрему колонку додаткових налаштувань і експорту. Графік, масштабування та вибір точки залишаються разом. На екранах до 1100 px колонки переходять у вертикальне компонування; на телефоні налаштування розташовано після графіка. Розгортання приховує додаткову колонку й збільшує область побудови.

Для основних діаграм і графіків курсових, циклів, АЕС, лабораторних, теплообмінника та досліджень ширину обмежено, а висота залежить від ширини. Пропорції на великому екрані — 16:10; на телефоні — близько 4:3 з мінімальною висотою. В основному режимі діаграми на короткому екрані обмежується також ширина, щоб зберегти ці пропорції й залишити місце для навігації. Фізичний масштаб осей та розрахунки не змінено.

Галерея показує по одному графіку в рядку, без деформації зображень. Щоб побачити нові пропорції в старих скріншотах, їх потрібно перегенерувати; поточні 47 прикладів перегенеровано під новий формат.

Перевірено:

- 47 браузерних графіків: дані моделі та координати залишаються узгодженими.
- Пропорції на ширинах 1920/1440/1024/390 px, зміна розміру, розгортання та Esc, відсутність горизонтального прокручування і помилок JavaScript.
- Браузерні перевірки `test:diagrams` і `test:diagram-quality`: вибір точок, переміщення/масштаб, SVG/PNG/CSV/HTML, мобільні жести, автономна версія.

Перевірка компонування: `npm run test:chart-layout` (потрібні локальний сервер і Playwright/Chromium). Зображення галереї: `npm run test:graph-generation`, потім `node scripts/render-graph-audit.mjs`.

Це цільова перевірка компонування, а не новий повний протокол приймання релізу. Наявні протоколи 1.17.0 зберігають свої ідентифікатори збірок. Зміни 1.17.1 поки локальні.
