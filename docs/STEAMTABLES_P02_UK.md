# P02 — водяні інверсії та підтверджені сценарії

18.10.2026. Локальна версія **1.35.5**. База: P01, коміт `175a98c8ea037b8311f26745a5ce8719142882d6`, код розрахунків 1.35.4. Підготовка P01 запушена в `origin/main`; реалізація P02 готується окремо.

Обсяг цієї поставки — **P02-01 і відома частина P02-02**: однофазні P–h/P–s/P–u поруч із Pc та завершені сценарії вже встановлених водяних режимів. Повний P02 не приймається, доки невідомі селектори насичення та відлік ексергії не підтверджені оригіналом. Прямої числової відповідності Steam97 ця поставка не оголошує.

## Зміни

Початкові дев’ять відмов P01 спричиняв обов’язковий розрахунок насичення перед пошуком однофазної інверсії. При P трохи нижче Pc фазові кінці можуть бути чисельно нерозрізненними або неузгодженими між рівняннями IF97; це не робить гарячий чи холодний однофазний стан нерозв’язним.

Новий [пошук фазового інтервалу](../src/inverse-phase-bracket.js) працює після такої відмови лише поблизу Pc. Прямий розрахунок підтверджує стійкі однофазні межі. Пошук ведеться на потрібному боці цих меж, зі старими критеріями залишку, фізичної стійкості та контролю коренів. Усередині нерозрізненого фазового інтервалу помилка зберігається; сухість, критичний стан або двофазні похідні не вигадуються.

Для гарячого стану не потрібен надточний холодний фазовий кінець: холодний пошук починається нижче Tc та уточнюється лише за потреби вхідної величини. Початковий крок 1 K є стартом пошуку, а не виключеним діапазоном. Перевірені фазові значення кешуються окремо для моделі й тиску; кеш обмежений 64 тисками. Це прибирає зайві дорогі спроби визначити насичення практично в Tc.

Пошук інтегровано в [IF97](../src/engine.js) та [IAPWS-95](../src/iapws95.js), Worker і автономну збірку. Окремо h–s IF97 зберігає вже перевірений однофазний корінь, коли повторна класифікація насиченого кінця за його тиском недоступна. Саме таку побічну залежність виявив повторний пілот після першого виправлення.

Збережено всі 16 пар IF97 і 11 пар IAPWS-95 з підтвердженого контракту P01. Не додавалися невідомі режими лише на підставі згадки довідки про «15 функцій».

## Незалежні числа та допуски

[Генератор P02](../scripts/generate-steam97-p02.py) використовує незалежні фундаментальні рівняння з попереднього [генератора високої точності](../scripts/generate-accuracy-followup.py), коефіцієнти Python iapws та mpmath. Продуктовий JavaScript не імпортується. Для IAPWS-95 густина знаходиться бісекцією у широкому фазовому інтервалі; вузька смуга автоматичного визначення фаз CoolProp не використовується як еталон чи обмеження.

Сітка: 11 тисків з обох боків 22,064 МПа, включно з сусідніми представними числами, та шість температур Tc ± 0,1 / 0,001 / 0,00001 K для обох моделей. **132 стани** перевірено на **70 і 90 десяткових знаках**; різниця еталонів менша за 1e-25 відносно. Заморожені значення: [steam97-p02-reference.json](../tests/fixtures/steam97-p02-reference.json).

У кожному стані перевіряються P–T/P–h/P–s/P–u: **528 запитів**. Разом із незміненим водяним пілотом P01 — **745**. Допуски залишилися з [політики P01](steam97-p01/pilot-policy.json) та [спільних критеріїв інверсій](../scripts/inverse-precision-common.mjs). Відтворюється саме заданий тиск; повторно обчислений зовнішньою EOS тиск не підміняє вхід біля Pc.

На базовому коді 1.35.4 той самий набір має **610/745**, тобто **135 відмов**: 9 у P01 та 126 у щільній сітці. Це кількість запитів, а не 135 різних дефектів. Порівняння виконується одним аудитором [audit-steam97-p02.mjs](../scripts/audit-steam97-p02.mjs) для старого й поточного модулів.

Конкретний приклад IF97: P=22,063999999999997 МПа, h=2211,8660819937427 кДж/кг. Раніше P–h завершувався помилкою насичення; тепер повертає T≈647,196 K, як незалежний прямий еталон. Для IAPWS-95 за того самого P і T відповідна h інша — 2221,6437149143076 кДж/кг; формуляції перевіряються кожна зі своїми числами.

Збіг незалежних реалізацій тієї самої EOS перевіряє програму. Він не змінює експериментальної невизначеності формуляції. Це скінченна сітка, не доказ для будь-якої точки чи всіх 32 похідних/транспортних властивостей.

Числовий контроль включає кожний повернутий корінь: обидва початкові входи, стабільність і відповідну фазу. Окремі регресійні тести зберігають помилки для нерозрізненого насичення, критичної сухості й сингулярної точки IAPWS-95. Звичайні x=0/0,5/1 і старі фазові кінці продовжують перевірятися.

Браузерний сценарій [check-steam97-p02-browser.cjs](../scripts/check-steam97-p02-browser.cjs) охоплює 27 комбінацій модель–пара в SI/English, фазові таблиці, всі початкові відмови, холодні стани, JSON/CSV, імпорт/перезавантаження з точним тиском, вибір альтернативи та офлайн-Worker. Для автономного файла фіксується фактичний спосіб запуску; за блокування `file://` перевіряється той самий файл через loopback з подальшим відключенням мережі.

Перевірки браузерів читають незмінну копію зібраних файлів, щоб не перетинатися з повторною детермінованою збіркою основного приймання. Хеші копії мають збігатися з остаточними файлами 1.35.5.

Окремий [PWA-набір](steam97-p02/pwa-results.json) перевірив повний кеш нового Worker, повторний запуск браузера без мережі, кероване тестове оновлення зі збереженням роботи, відмови пошкоджених ресурсів та відновлення після втрати кешу. Наступну версію сервер імітував локально; це не перевірка розгортання на живому сайті. Chromium заблокував `file://` у цій сесії, тому автономний HTML у ньому перевірено через loopback з відключенням мережі; Firefox пройшов безпосередній файловий запуск.

Повний попередній набір 4657 інверсій зберігається окремо. CI додатково виконує P02-аудит перед публікацією main; основний браузерний набір включає сценарії P02 в Chromium та Firefox. Історичні файли P01 не перезаписані: їхні хеші описують коміт P01, а повторення на новому коді має окремий результат.

## Відкритий обсяг

- **P02-03, B01/B02/B03:** фактичний повний селектор насичення й режими після реєстрації. Прямий доступ до оригіналу в цьому середовищі був заблокований CONNECT 403; нових відповідей оригіналу немає.
- **P02-04, B01/B03/B07:** відлік ексергії та контрольні приклади оригіналу. Незалежні власні P0/T0 не доводять тотожність його конвенції.
- **P05, N03/N04:** низькотемпературна рідина IAPWS-95 і межі транспортних властивостей. Дві проби P01 залишаються окремими відомими прогалинами, до успішних числових зіставлень не зараховуються.

Вимоги N01/N02 закриваються як локальні числові дефекти на перевіреному наборі. Їхній статус прямої відповідності повертається до `requires_reference_cases`; жодної нової вимоги `verified` не встановлюється. Поточні задачі: [steam97-p02/tasks.json](steam97-p02/tasks.json).

## Відтворення

```sh
# iapws 1.5.5, CoolProp 8.0.0, mpmath 1.3.0 у PYTHONPATH
python3 scripts/generate-steam97-p02.py
npm run audit:steam97:p02
npm run audit:inverse:full
npm run verify:release:core
# CALCULATOR_URL локального сервера, PLAYWRIGHT_MODULE_PATH та шляхи браузерів
npm run test:steam97:p02
BROWSER_NAME=firefox npm run test:steam97:p02
node scripts/verify-steam97-p02.mjs
```

Для порівняння старого коду експортувати `src` і `vendor` коміту P01 в окремий каталог, встановити `P02_ENGINE=/absolute/path/to/old/src/engine.js` та `P02_NAME=baseline`. Аудитор змінює лише власні файли результатів, не старий код чи еталони. Повторне генерування еталонів потребує зазначених залежностей; для звичайних перевірок вони вже заморожені в репозиторії.
