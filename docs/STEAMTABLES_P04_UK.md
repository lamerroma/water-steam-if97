# P04 — дослідна калорична поправка дисоціації

У **1.35.12** реалізовано обмежений дослідний сценарій P04: окреме ядро VDI4670 поверх газових таблиць BSW2003, Worker зі скасуванням, форма, проєкти, чотири табличні формати й автономна робота. **Повне приймання P04 та відповідність Steam97Web залишаються відкритими.** Первинну статтю BSW2003 повністю не отримано, нових числових off/on відповідей оригіналу немає. Контракт і блокери: [contract.json](steam97-p04/contract.json).

## Що реалізовано

У вкладці газів виберіть BSW2003, потім «Калорична поправка VDI4670 · дослідна», явно задайте умови повного згоряння у звичайному повітрі та коефіцієнт надлишку повітря λ. За замовчуванням поправку вимкнено; попередня модель P03 та NASA7 зберігають свою поведінку.

Підтримано P–T, P–h, P–s, молярний/масовий базис, частки/відсотки, SI/English, збереження й повторний розрахунок проєкту, JSON та CSV/XLS/XLSX/ODS. Метадані зберігають модель, припущення, λ, початковий склад, поправки й недоступні виходи. Збережений результат JSON не приймається за новий розрахунок.

Локальні межі: **1200…2000 K**, **0,01…5 МПа**, O₂ ≥ 1 мол. %, початковий CO = 0, N₂ > 0, λ > 1,05. Обидві межі T/P включено. Це межі нашого дослідного режиму, а не встановлені межі сайту. Декларація умов згоряння є входом користувача; сама наявність N₂ не доводить звичайне повітря. Кисневе та неповне згоряння не підтримуються.

## Рівняння й походження

[Реєстр джерел](steam97-p04/sources.json) та [аудит Modelica](steam97-p04/modelica-source-audit.json) фіксують URL, ревізію й SHA-256. ReferenceMoistAir дає шість рядків A–E, гілки U₂…U₆ та калоричні поправки; PTB-CP-3 пов’язує спрощену модель VDI4670 зі статтею Bücker/Span/Wagner 2003. Це не доводить тотожності конкретній реалізації Steam97Web. BSD-3-Clause атрибуцію включено в автономну збірку; стороннього виконуваного Modelica-коду не додано.

Для початкових молярних часток y, температури T у K і тиску P у МПа:

- Kᵢ = Aᵢ exp(Bᵢ/T), r = √(0,101325/P), o = √yO₂.
- U₁ = K₁ yCO₂ r/o; U₂ = K₂ yH₂O r/o.
- U₃ = K₃ √yH₂O √o √r; U₄ = K₄ √U₂ r.
- U₅ = K₅ o r; U₆ = K₆ √(yN₂ yO₂).
- Vᵢ = Cᵢ + Dᵢ/T + Eᵢ/T²; W = 1 + ΣUᵢ.
- Δcp,m = Σ(UᵢVᵢ)/W; Δh,m = −T² Σ(UᵢVᵢ/Bᵢ)/W; Δs,m = Δh,m/T.

Гілку CO₂ → CO + ½O₂ **виведено із закону діючих мас** за окремо табульованим K₁; її немає у вологоповітряному наборі функцій Modelica. Додатний D₂ = +303000 обрано як у Modelica: незалежні NASA-ентальпії реакції H₂O → H₂ + ½O₂ підтримують цей знак (відмінність енергетичного індексу приблизно 0,15 % або менша на 1200/1600/2000 K). Від’ємний знак вторинної текстової таблиці не використано. Знак у первинній статті безпосередньо не перевірено. Допоміжні похідні Modelica з виявленими суперечностями не переносилися.

Молярні поправки діляться на молярну масу **початкової суміші**: результат Δh у кДж/кг, Δcp/Δs у кДж/(кг·K). До h/u додається однакова Δh, до cp/cv — однакова Δcp за описом PTB. Значення cp — окрема емпірична апроксимація, **не точна похідна апроксимованої h**; cv — не рівноважна похідна при сталому об’ємі. Обернені задачі розв’язуються бісекцією без використання cp як похідної Ньютона.

Склад, M, R, Z, ρ та v залишаються властивостями початкової ідеальної суміші. Uᵢ — внутрішні реакційні індекси; це не рівноважні відсотки й не частка дисоціації. Швидкість звуку та ізентропний показник у цьому режимі недоступні. cp/cv підписано як калоричне відношення.

## Незалежні перевірки

`node scripts/audit-steam97-p04.mjs` запускає **280 станів і 140 зворотних задач**: п’ять складів, два базиси, сім температур (з кінцями та сусідніми точками) й чотири тиски. Окремий Python Decimal із 60 цифрами не імпортує код програми та виконує **2520 перевірок** поправок і реакційних індексів за замороженим зовнішнім набором коефіцієнтів. Допуск для поправок: 2e−12 + 5e−12·|еталон|; для Uᵢ: 1e−18 + 5e−12·|еталон|. Це підтверджує реалізацію обраних рівнянь, а не фізичну точність.

[Порівняння з Cantera 3.2.0](steam97-p04/cantera-comparison.json): 60 станів продуктів CH₄/звичайного повітря, λ = 1,06/1,2/2, T = 1200…2000 K, P = 0,01…5 МПа. Окремо мінімізується Gibbs при заданих T/P; порівнюються приращення від того самого початкового складу з урахуванням ентальпій утворення. Рівноважна cp отримується повторним урівноваженням при T ± 0,05/0,025 K, а не читанням cp замороженого складу. Найбільші відмінності **самих поправок**: Δh — 2,20 %, Δcp — 6,89 %, Δs — 14,04 % (округлено вгору). Це різні моделі; значення не є похибкою повних h/s/cp, встановленим допуском Steam97Web чи доказом фізичного приймання. Коефіцієнти не підганялися. Сірковмісні та неонові суміші цим порівнянням фізично не валідовано.

Відтворення фізичної діагностики в окремому Python-середовищі з Cantera 3.2.0:

```sh
python3 scripts/reference/gas_dissociation_reference.py --cantera /tmp/p04-cantera.json
```

Браузерний сценарій `scripts/check-steam97-p04-browser.cjs` перевіряє реальний Worker, граничні відмови, P–h/P–s, масовий/молярний базис, скасування/повторення, проєкт/JSON, SI/English, 320/390 px, автономний HTML і PWA офлайн. Кожен браузер створює 16 табличних файлів та виконує 128 перевірок окремими читачами CSV, openpyxl, odfpy й xlrd.

Підсумок перевірок конкретної збірки та посилання на докази: [STEAMTABLES_P04_ACCEPTANCE.json](STEAMTABLES_P04_ACCEPTANCE.json). Повна регресія включає P03, P02/P05…P09, водяні моделі, транспорт, діаграми, реакторні й навчальні модулі та детерміноване пакування. Її проходження не змінює науковий статус окремих моделей.

## Чому λ задається явно

[Раціональний атомний аудит](steam97-p04/input-identifiability.json) показує два процеси повного згоряння з однаковими вісьмома продуктами, але різними λ. На 1 моль CH₄ подано 2,08 моль O₂ (λ = 1,04); на 1 моль CH₃OH — 1,58 моль O₂ та 79/42 моль додаткового N₂ (λ = 79/75 > 1,05). Обидва дають CO₂ = 1, H₂O = 2, O₂ = 0,08, N₂ = 4108/525 моль. За наявності азотного розбавлення формула трасера N₂ не визначає λ однозначно. Це доказ неоднозначності загального входу, не дефект Steam97Web. Відтворення: `python3 scripts/reference/dissociation_input_audit.py`.

## Що ще потрібно для повного P04

Первинне підтвердження всіх рівнянь/коефіцієнтів, точні правила λ/палива/окисника й базисів оригіналу, нулі h/s, його межі тиску/температури, визначення «Dissociation» й компонентних виходів, cp/cv та акустичних похідних. Потім — прямі off/on приклади Steam97Web з точними входами й фіксованими допусками. Блокери B01/B03/B04/B05 не закрито припущеннями; `full_sprint_accepted=false` і `full_reference_parity_verified=false` збережено.
