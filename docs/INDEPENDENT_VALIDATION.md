# Незалежна числова звірка

96 станів порівняно з Python iapws 1.5.5 ([джерело](https://github.com/jjgomera/iapws)). Основні рівняння областей 1, 2, 3, 5 і насичення, включно з двофазними сумішами та близькими до меж станами.

| Величина | Максимальна відносна різниця | Стан |
|---|---:|---|
| h | 1.0238e-9 | px(22.063,1) |
| s | 7.4954e-10 | px(22.063,1) |
| v | 3.9598e-9 | px(22.063,1) |
| cp | 7.3803e-13 | pt(50,623.16) |
| cv | 2.2200e-12 | pt(100,623.16) |
| w | 1.1057e-12 | pt(100,623.16) |

Для сумішей порівняно лінійний масовий баланс за фазовими кінцями IAPWS97(P,x=0/1), які бібліотека уточнює за основними рівняннями. Прямий API IAPWS97(P,x=0.5) вище 623.15 K використовує зворотне наближення без такого уточнення. Його оригінальні значення також збережено у fixture як raw. Максимальні відносні різниці прямого API суміші: h=1.7214e-4, s=1.2586e-4, v=6.4851e-4. Це відома різниця методів, а не точність нашого результату.

Допуск для незалежної звірки: 2×10⁻⁷; перевищень: 0. Це звірка реалізацій одного стандарту, а не незалежне підтвердження фізичної точності. Офіційні контрольні таблиці перевіряються окремо в official.test.mjs. Інверсії перевірено поверненням до основних рівнянь (boundary-grid.test.mjs).

Python iapws має GPL-3.0, використано лише зовнішньо для отримання числових контрольних результатів. Код бібліотеки, SciPy й NumPy не включено в репозиторій, збірку або готовий сайт. Fixture містить числові результати; скрипт reference-iapws.py — власна обгортка. Регенерація fixture необов’язкова і потребує окремого Python-середовища; звичайні тести не потребують мережі.
